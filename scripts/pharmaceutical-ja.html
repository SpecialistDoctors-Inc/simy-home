漫画でわかる SIMY

会うたびに、わかることがある。
だから、練習も変わっていく。

登場人物・医師役・会話は架空の活用例です。実面談の記録とAIの演技は区別し、録音の利用条件・連携方法は導入時に確認します。

01 / 面談で、先生の気がかりを聞く

MR先生「比較の前提を確認したいんです」
その言葉を、次の準備につなげたい。

会社・施設のルールに沿い、必要な同意を得て実際の面談を録音。先生の言葉を、前後のやり取りとともに残します。

02 / 録音から、関心と宿題を整理

SIMY先生が確かめたいのは、ご自身の診療と対象集団が重なるか、という点ですね。

録音・文字起こしから発言、気がかり、持ち帰った宿題を整理。MRが元の会話と照らし、解釈を確認します。

03 / その先生の、次回の練習へ

SIMY前回の宿題を踏まえて、
比較で確認したい条件を聞く練習にしましょう。

公開情報や承認済み資料に、実際の面談で分かったことを組み合わせます。その先生の関心と次回の目的に合わせ、質問と反応を設定します。

04 / まず、声に出してみる

MRMR「比較の資料をお持ちしました」
AI医師「その前に、どの患者集団の話ですか？」

先生が確かめたい条件を聞く前に、説明を始めてしまった。練習の中で、自分のつまずきに気づきます。

05 / 質問を変えて、もう一度

MR「どの患者背景の違いが気になりますか？」
今度は、先生の確認したいことから聞こう。

同じ医師役で再挑戦。該当する発言を振り返り、質問の順序や根拠の伝え方を具体的に見直します。

06 / 次の面談で、新しい宿題が見える

MR先生「次は、導入時の院内の役割分担も確認したいです」
次に準備することが、見えてきた。

実際の面談では、練習と違う反応や新たな関心が出てくることも。そのやり取りを、同意・社内ルールに沿って記録します。

07 / 新しい会話で、練習も更新

SIMY次は、比較の話に加えて、
院内の役割分担を確かめる練習にしましょう。

新しい発言と宿題を反映し、次回の練習を更新。先生の関心を固定せず、面談を重ねながらパーソナライズしていきます。

08 / 個人の振り返りを、チームの育成へ

支店長・研修担当誰が、どの場面で支援を必要としているか。
次の育成にも活かしていこう。

共有範囲に応じて練習の傾向や課題を把握。支店長の個別支援と、研修担当者による教材の改善につなげる構成です。

FROM CONVERSATION TO PRACTICE

前回の言葉が、
次回の練習になる。

実際の面談で先生が話したことを、次の準備へ。録音から関心や判断基準、未解決の疑問を整理し、その先生のための練習に反映する流れです。

  1. 面談を録音・文字起こし
  2. 発言と宿題を確認
  3. 医師別に練習を設計
  4. 練習して次の面談へ
  5. 新しい会話から更新
面談から拾うこと

先生は、何を確かめたいのか。

  • 関心を示したテーマや繰り返した質問
  • 比較・安全管理など、判断で重視する条件
  • 前回の説明で解消しなかった疑問
  • 次回までに確認すると約束したこと
次の練習で変わること

その先生に、何をどう聞くか。

  • 面談の最初に確認する質問
  • 質問や説明に対する医師役の反応
  • 承認済み資料で確認する根拠・条件・限界
  • 振り返りで重点的に確かめる発言

録音は会社・医療機関のルールに従い、必要な同意を得て行います。利用する情報、保存先、閲覧権限を事前に確認し、患者の個人情報等の取り扱いは社内規程に従います。AIの整理・推測は元の発言と区別して担当者が確認し、有害事象などの安全性情報は所定の報告経路で速やかに連携します。

START WITH YOUR MATERIALS

録音を始める前も、
手元の教材から。

録音の運用が整うまでは、承認済み資料や社内ロールプレイの録画から始められます。実面談の記録を利用できる段階で、その先生の発言や宿題を加え、さらに個別化していく進め方をご相談いただけます。既存のAIロープレ向けのシナリオ設計支援も検討できます。

ご相談時にあると役立つもの

準備済みの素材を活かす。

  • 承認済みの研修資料・回答例
  • 設定済みの医師像・想定質問
  • 社内ロールプレイの録画・文字起こし
  • 練習で身につけたいこと・評価基準
一緒に具体化するもの

一つの場面から、試して確かめる。

  • 医師役の設定と練習の目的
  • 質問に応じた反応・会話の流れ
  • 評価する発言と振り返りの観点
  • 担当者による確認・試行後の改善

使用する資料の権限・機密情報の取り扱いを確認します。既存ツール向けの支援範囲は、入力形式や利用上の制約を伺って決定します。社内の優れた事例は、担当者が再現可能な質問や確認の進め方を選んで教材に反映します。

01 / PERSONALIZED ROLEPLAY

担当医師が違えば、
問いも、反応も変わる。

公開情報や研修素材に、実際の面談の録音から確認した発言・関心・宿題を組み合わせます。同じテーマでも、先生が重視する判断基準によって質問と反応を変え、次回の面談目的に合う練習を設計します。

A医師 / 根拠に厳しい

「どの患者集団の話ですか」

前回の宿題は、比較の前提。根拠を示すと、その限界を深掘りする医師役で練習します。

MR「前回の比較の件ですが、どの患者像を確認したいですか」
AI医師「前治療や対象集団が、私の診療と重なるかです」
練習の軸：確認したい条件を聞く。
B医師 / 安全管理に慎重

「誰が、何を確認しますか」

前回の宿題は、院内の役割分担。導入時の手順から家族への説明へと対話を進めます。

MR「前回の安全管理の件ですが、どの分担が未整理でしょうか」
AI医師「診療側と説明担当が、何を担うかを詰めたいです」
練習の軸：具体的な懸念を聞く。

医師設定・会話は架空です。参照元と仮説を分け、AIの演技を実面談の事実として扱いません。製品の説明は最新の承認済み資材で確認します。

MR 4場面・MSL 2場面から、研修を具体化。

MR / 医師の判断条件を聞く
  • 製品A：多忙で実務的な医師
  • 製品B：根拠に厳しい医師
  • 製品C：家族説明に慎重な医師
  • 製品D：安全管理に厳しい医師
MSL / 非販促の科学的対話
  • 製品A：研究方法に厳しい医師
  • 製品B：研究に協働的な医師

対象集団・根拠の限界・未解決課題を整理。販売や処方獲得を評価項目にしません。

製品A〜Dは練習例です。重点領域・承認資材・評価基準を貴社と確認し、MRとMSLの目的・評価を分けて設計します。
