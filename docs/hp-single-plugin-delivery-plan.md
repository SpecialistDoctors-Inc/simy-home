# HP編集プラグインの導入簡略化

2026年11月8日の配布候補は0.3.12です。現行の利用方法は[利用者ガイド](hp-single-plugin-customer-guide.md)、構成・更新・復旧・検証範囲は[運用ガイド](hp-local-editor-operator-guide.md)を参照してください。以下の日時付き記録は、その時点の検証結果です。

利用者は非エンジニア。CodexデスクトップアプリとHPプラグインを導入し、本人のGoogleログインとアクセス許可だけを行う。Python、別のCodex CLI、Git、Google Driveプラグインの追加導入を利用者の手順に含めない。

## 利用手順

1. 「診療時間を変更したい」など、変更内容をCodexへ伝える。
2. プラグインが対象HPと編集用ファイルを確認し、手元の確認画面を開く。
3. 利用者が手元の表示を確認する。修正中はdev・本番を変更しない。
4. 利用者が「確認用サイトに反映して」と依頼する。保存済みの版をdevへ反映し、URLを案内する。
5. 利用者がdevで表示を確認する。必要なら手元で修正して手順3へ戻る。
6. 利用者が確認済みの版の公開ボタンを押す。同じ成果物を本番へ反映し、実際の完了を確認する。

ローカル確認の承認はdev反映だけを許可し、本番公開の承認にはしない。各段階の間に編集した場合、変更後の内容を再確認する。通信が途切れた場合は同じ操作の状態を照合し、保存・配信・通知を重複させない。

## 実装範囲と確認基準

- 配布先: `simy-hp-skills`。公開元 `989228fc14e2a672840aea632af194b2199e49cb` から専用作業ツリーで変更する。
- 接続サービス: `simy-home`。開発元 `d65ea43f80cb7c4edab1040380013daadd33c2f1` から専用作業ツリーで変更する。
- 起動・パッケージ処理を実行環境込みで配布し、Pythonがない状態で起動・表示・変更検証ができること。
- デスクトップアプリ同梱のCodex実行ファイルを検出し、追加CLIを導入せず既存HP接続を使えること。
- HP接続だけで編集ファイルを取得・保存できること。Driveは運用側の内部保存先として残しても、利用者に追加プラグインを要求しない。
- 初回取得・既存作業の再開・同じ作業の二重起動・保存中の中断を検証すること。
- 認証主体・対象サイト・既存の正確な成果物の公開承認を維持すること。
- ローカル確認からdevへの明示的な進行と、dev確認後の本番確定を別々に検証すること。

この変更の実装とローカル検証を行う。プラグインの公開、接続サービスの配備、新たな本番コンテンツの公開はそれぞれ別の操作であり、この設計文書で完了を意味しない。停止済みSIMY監視ループおよび旧HP更新サーバーは再開しない。

## 2026年11月6日の実装・確認結果

- Mac Apple Silicon用に、Pythonと証明書データを同梱したプラグインをビルドした。追加CLIはインストールせず、実際のデスクトップアプリ同梱バイナリを使う。
- 接続先はホストのMCP接続情報から、HPサービスの正確な接続元と接続状態を検証して選ぶ。接続名の固定や、利用者による設定ファイル編集を前提にしない。
- 既存のHP認証を使ったプロフィールの読取りを、ソース版と配布バイナリの両方で確認した。この既存MacではCLI用の追加ログインは不要だった。
- HP認証の範囲内で、所有者と作業領域に限定したダウンロード・アップロード処理を実装した。署名にデータのハッシュと長さを含め、保存は従来の操作IDとワーカーで処理する。実クラウドへの新方式の配備・アップロードは未実施。
- ローカル側60件、サービス側281件、公開カード12件のテストが成功。署名生成は実botocore、プロバイダーへのファイル受け渡しはテスト用実装で検証した。
- 配布バイナリから、外部Python・Git・追加CLIのないPATHで初期化・変更の梱包・同一操作の再実行・保存結果の受理・後から行った編集の保持を確認した。
- 配布バイナリのHTTP経由で、ローカル起動、既存HP接続、ローカルファイル更新、3段階の案内を確認した。試験用のコピーだけを編集し、dev・本番・通知の変更は行っていない。
- Lambda用ZIPをビルドし、公式Python 3.12 x86_64コンテナで読込みを確認した。停止していた既存Docker Desktopはビルド検証のため起動した。共有サービスなので停止操作は行っていない。
- Claude Codeによる独立レビューを実施。ダウンロード中断からの復旧、受付前の権限バージョン更新後の再開、署名ヘッダーの検証を修正し、修正箇所の再レビューでblocker/P1/P2なし。
