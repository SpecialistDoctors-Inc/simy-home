# 保険相談の受付と引継ぎ

公開案内とメール下書きの相談準備に加え、認証した利用者ごとの相談記録、保存・再読込・更新・受付・出力・削除、同意記録、運用担当の設定と対応履歴を実装する。

提供された3社の質問116項目（25・35・56）は、設問の出典セル・資料の版・回答選択肢を保持する。「未確認」を「いいえ」に変換せず、公開Web診断から内部対策の回答を自動確定しない。医院URLに結び付ける相談は、その医院の管理権限を確認する。

通常のSIMY相談受付と、正式な代理店紹介・見積り・契約を別状態にする。紹介先、役割、提供項目・同意文言、保持期間、現行書式を確認した担当者設定が揃うまで、正式紹介へ進まない。設定が変われば以前の同意を流用せず、再確認する。担当者が実際に引き継いだ場合に参照番号等を記録する。記録の入力だけで、代理店や保険会社の受領を機械的に確認したとは表示しない。

相談は表示した保持期間（標準90日）で期限切れとし、定期処理で削除する。患者情報の入力欄は設けない。保険料の自動算出や自動契約は行わず、代理店による正式な手続を利用する。提供資料があることを、その版の有効性や提携契約の確認完了とは扱わない。

`?insurance=off` はページ・PDFの保険案内を省く配布設定。認証済み管理画面の保険相談は別機能として利用者が明示的に開く。
