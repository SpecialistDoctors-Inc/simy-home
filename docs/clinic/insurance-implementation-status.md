# サイバー保険の実装範囲

2026年11月5日。

| 項目 | 実装範囲 |
| --- | --- |
| 一般案内 | サイト・PDFで補償例、契約条件、公開Web診断の範囲を説明 |
| 相談準備 | 医院・担当者・連絡先と任意の対策状況4項目を入力し、確認・手元への保存・SIMYへのメール下書き作成 |
| 情報の取扱い | 準備フォームはサーバーへ入力を送信・保存しない。閉じると入力と下書きリンクを消去 |
| 配布先別表示 | `?insurance=off` でサイト・PDFから保険案内を省く |
| 正式紹介・告知 | 未実装。代理店の受付先・責任分界と、現行書式・回答の受領方法が未確認 |
| 見積り・契約 | 代理店側の手続。準備フォームやメール作成で完了したと扱わない |

公開する準備フォームは、正式告知書の代替ではない。患者情報・売上・詳しい事故情報は取得しない。4項目は相談のための任意の自己申告であり、提供資料の会社別設問を置き換えるものではない。診断結果から内部対策や加入可否を推測して回答を埋めない。

ユーザーから設計判断を委任されたため、受付先や条件を推測して代理店へ自動送信する方式ではなく、SIMYへの確認可能な相談下書きを公開する。代理店名・電話が資料にあっても、紹介先APIやメール、保存期間、第三者提供条件の確定とは扱わない。正式紹介機能を公開する際は、確認済みの宛先・同意文言・保存条件、最新版の質問と対応表を用い、受付→保存→再読込→担当引継ぎを別途検証する。
