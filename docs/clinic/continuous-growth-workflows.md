# 診療から記事・近隣医院の変化確認

管理画面はChatGPTでログインし、対象医院の管理権限を確認して使う。

録音は利用者の操作と同意確認で開始し、録音中・停止・消去・手元への保存を提供する。音声と文字起こしの処理は端末内で行い、音声を外部へ送信しない。初回は固定版のWhisper公開モデルをダウンロードする。患者情報を除いて確認した文章だけをAI記事案の作成へ渡す。原音声を診断・相談データとしてサーバー保存しない。

記事は下書き→先生の確認・承認→公開の順に進める。修正すると承認が失効し、再承認するまで公開できない。記事ページ・公開フィード・埋め込み用スクリプトを提供し、公開済みの現行版だけを配信する。既存の医院ホームページで表示するには、そのサイトへ埋め込みを設置する。設置していない外部サイトが変更されたとは扱わない。

近隣医院は公開トップページを対象に、初回の基準保存→次回の追加・削除の差分→AI要約を記録する。取得失敗は失敗として保存し、基準を上書きしない。差分だけで順位・集患効果・対策の成功を推測しない。日次確認は管理権限が有効な利用者の登録対象だけを実行し、同時実行をリースで防止する。

本番記録では、実音声処理、実際のマイク機器、記事の正式入力→API→保存→再読込→承認→公開→取下げ、外部医院への設置を別々に確認する。合成音声やマイク入力フィクスチャの成功を実際の診療録音・患者情報の匿名化受入とは扱わない。
