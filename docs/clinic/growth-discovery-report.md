# 集客診断：AI検索とホームページの案内

目的は「紹介されているか」と「正しい案内から受診へ進めるか」を分けて判断できること。

1. 結論。本文の記載数を集客スコアに置き換えない。
2. AI検索の実測。質問・紹介の有無・同じ回答に出た医院を一覧表示。測定先・日時・医院名を質問に入れたか・試行回数を明示する。
3. 公式サイトへの誘導。回答に医院名が出たことと、公式サイトの引用・到達先の確認を混同しない。
4. 公開本文の分析。案内の有無、医院固有の優先課題、改善案、掲載文をまとめる。

初期の実測記録はGoogle AIモード（うらちる、5問・各1回、2026-11-05 07:43–07:47 JST）。取得元はTinyFish実行 d25818c1-dd58-415f-926f-a846e2c4ce4e。ブラウザーエージェントが記録した回答からの転記であり、引用リンクの到達先は未検証。取得記録の異なるドメインを誤案内確定とは表現しない。

`clinic-ai-observations.js` の記録は完全一致のオリジンだけに適用する。今回の診断で新たに実行した検索とは表示しない。別医院へうらちるの数値・競合医院名を流用しない。測定失敗を紹介なし・0件へ変換しない。本文分析が失敗しても、取得済みの実測記録を消さない。

記録は診断レポートのスナップショットへ複写し、PDFも同じモデルを用いる。Google AIモードの自動検索をすべての診断へ追加した変更ではない。

## 表示と根拠リンク

- 「紹介なし」は赤、「紹介あり」は緑、未取得は中間色で区別する。取得失敗を紹介なしにしない。
- 所見本文のページ名を根拠URLへリンクし、本文に名称がない場合もカード末尾の出典から開けるようにする。PDFにもクリック可能な出典を含める。
- 「確認したこと：」の接頭辞は付けず、所見を直接記載する。

## 保険案内を載せない配布

`https://simy.one/hp-management/clinic.html?insurance=off` を配布する。この設定はページ全体の保険案内と、その画面から出力するPDFの保険ページを省く。指定なしは一般案内とSIMY相談導線を表示する。利用者の氏名や診断内容をURLパラメーターへ含めない。

保険の一般案内・相談準備は公開範囲。代理店の正式受付、保険会社ごとの告知受付、見積り、契約は別段階であり、メール下書き作成や確認用ファイルの保存を受付完了と表示しない。提供先・窓口・役割と書式の有効性を確認するまで、顧客データを第三者へ送信しない。

## 継続的な集患支援の訴求

うらちるの別途実測（6回答中5件に登場）から、日々の診療の知見を記事にする仕組みと近隣医院の公開サイトの変化確認を案内する。録音の同意・患者情報の除去・先生による承認後の公開を前提とし、地域の感染症動向などの公表情報とも照合する。これから構築する機能であることと、実施範囲・費用が個別相談であることを明示する。

CTAは既存の申込み画面を開き、対象医院と相談内容を引き継ぐ。個別構築の相談では連絡先を表示し、相談メール下書きを作成する。定額プランのStripe申込みへ切り替えた場合は元の決済導線に戻す。録音処理・自動記事生成・近隣医院の定期監視そのものを今回実装済みとは扱わない。
