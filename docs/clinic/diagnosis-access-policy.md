# 診断対象の権限確認

詳細診断・保存・PDF・編集は、Sitesの正式なChatGPTログインと、利用者に結び付いた医院ドメインの管理権限で制御する。匿名のURL入力には、公開トップページの接続・タイトルの簡易結果だけを返す。匿名NDJSONにも詳細レポートを含めない。

医院の確認はDNS TXTまたは指定ファイルの公開で行う。確認トークンは利用者・対象オリジン・期限に結び付けてハッシュ保存し、一度だけ使える。フリーメール・代理店・複数院は、権限を確認した運用担当が委任する。IPは本人判定や医院の権限の代わりにしない。同じ院内IPでも、別々の正当な利用者を拒否しない。

詳細レポートは利用者と医院に結び付け、30日間保存する。別利用者のIDは404、医院の確認が失効・解除された場合は取得と編集を拒否する。編集の時間あたり回数上限は復活させない。

近隣医院ウォッチは別用途として公開トップページだけを比較する。robots方針・公開IP・転送先・本文量を検証し、ログイン後や患者専用ページへ進まない。自院の管理権限を確認した利用者が対象を登録し、近隣医院の管理権限を持つと表明するものではない。

本番受入では、実際のSitesログイン、偽装認証ヘッダーの拒否、匿名APIの非開示、他人・失効後の取得拒否を分けて記録する。ローカルの認証フィクスチャを本番ログインの受入とは扱わない。
