# エンジニア向けページの6言語対応

2026-10-06。対象はサイトが対応する日本語・英語・スペイン語・フランス語・ヒンディー語・簡体字中国語。各言語のエンジニアが、画面内の作業、判断、成果、再発防止ルールを読めることを目的とする。

成功条件は、全6ページの9工程の画像、拡大リンク、代替テキスト、本文が各言語と一致し、ホームや言語切替から同言語ページへ到達できること。120%の品質として、再生成できる原稿、未翻訳を拒否する生成器、全言語の表示・操作証跡を保存する。アプリ本体の変更、依存追加、コミット、公開は範囲に含めない。

## 原稿と判断

- 日本語の5枚は維持し、5言語×5枚の翻訳画像を追加。全6言語のSNS画像も生成する。ページURLは日本語が `/for/engineers/`、他は `/for/<locale>/engineers/`。簡体字のURLは `zh-hans`、言語タグ・画像の接尾辞は `zh-Hans`。
- Threadsの3画面は `SIMY_Threads_全画面設計_20261005/SIMY_Threads_全画面プレビュー.html` の対応画面（進行、判断、成果）を静的DOMにした原稿。必要なスタイルを保持し、アプリJavaScriptを除去した。翻訳は `scripts/engineer-captures/*.json`、ページ本文は `scripts/engineering-copy.json`、工程説明は `scripts/engineering-experience.json` に保存する。
- 品質モニターの2画面は、日本語の固定合成データキャプチャーをもとにHTMLで再構成した説明用画像。セッション失効、原因は仮説・要確認、本人性の再確認、評価のサンプル数値、検出回数不明を保持する。各言語の実装を検証した証跡ではないため、画像内・本文・末尾に翻訳した説明用画像であることを明示する。
- 画像は自然な全高をキャプチャーし、ページのwidth/heightをPNGから取得。長い翻訳はメタ情報を折り返す。原因本文が見えるよう翻訳版の表示位置を下端にする。
- 工程の説明を共有グリッドへ重ね、最長の説明に合わせて枠の高さを安定させる。非表示工程はvisibility:hiddenとhidden属性で操作・読み上げの対象から除く。
- ホーム、共有ヘッダー、言語切替、相互hreflang、サイトマップ、ページ台帳を6言語に更新。共有JavaScriptのキャッシュキーも更新。多くの既存HTMLの差分は共通ヘッダーの参照更新だけ。
- リンク先のSIMY固有ガイド3件は日英のみ存在する。追加4言語では英語ページへリンクし、「英語」の注記を各言語で付ける。既存共通ヘッダーの英語ラベルは今回変更していない。
- この記録が過去のdesign-rationale.md / verification.mdにある「英語画像は日本語」という記述を更新する。過去の証跡は当時の記録として維持する。

## 再生成

既存のPlaywrightとChromeを使用し、新しい依存は追加しない。

```sh
NODE_PATH=<既存のPlaywrightがあるnode_modules> node scripts/capture-engineering-locales.cjs
python3 scripts/build-engineering-pages.py
# サイトをローカルで配信してからSNS画像を生成する
NODE_PATH=<既存のPlaywrightがあるnode_modules> node scripts/capture-engineering-social.cjs
python3 scripts/build-engineering-pages.py --check
node --test tests/*.test.cjs
```

画像生成器は未翻訳の文字列、画面外への文字のはみ出し、ボタンの文字の欠け、外部リクエストを拒否する。PNGの寸法とSHA-256はasset-manifest.jsonに記録する。SNS画像を更新した場合も画像生成器で台帳を更新する。

## 公開・ロールバック

公開操作は行っていない。通常デプロイの準備工程で画像と工程CSS/JS、ページindex、S3のスラッシュキーと新4言語の `.html` 互換キーを先に配置し、その後ホーム・ヘッダーの導線を公開する。後続のHTML削除同期は互換キーを除外する。

旧CloudFront関数は新4言語のディレクトリURLを `.html` へ転送するため、互換キーが必要。更新した関数とTerraformソースは全6言語をindexへ書き換える。関数の公開は通常の静的デプロイから独立しており、未実施。互換配信時は旧関数の既存動作によりクエリが落ちるため、正規URLとクエリ保持には更新関数の公開が必要。

戻す場合は関連する原稿・HTML・画像・共有導線・配信スクリプトを前版へ戻す。データ変更なし。公開後は6言語のページ、画像404、原寸リンク、言語切替、モバイルの工程切替とSNS画像を確認する。互換キーは新関数が安定してから削除できる。

6言語の読み手が画面を読み取れるという目的は、ローカルの表示と操作の証跡で達成した。アプリ本体・権限・データ・価格は変更していない。本番への反映と確認が残る。
