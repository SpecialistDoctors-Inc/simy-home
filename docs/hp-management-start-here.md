# ホームページの更新を始める

医院の担当者が、Codex に普段の言葉でホームページの修正を依頼するための案内です。プログラミングの知識は必要ありません。SIMY への登録も不要です。

**医院で行うのは「変更を伝える」「確認用ページを見る」「公開に同意する」の3つです。** 初回の接続や受付の設定は、運用担当が一緒に準備します。

## 初めて使うとき

1. 運用担当から、医院専用の受付表のリンクと問い合わせ先を受け取ります。
2. パソコンのアプリで Codex にログインし、医院用の Google アカウントを接続します。
3. 運用担当と1件の練習を行い、依頼の保存、確認用ページ、通知メールを確かめます。

詳しい操作とコピーして使える依頼文は、[医院向け手順書](hp-management-customer-guide.md)にあります。

## 普段の使い方

| 順番 | 医院で行うこと | その後に進むこと |
| --- | --- | --- |
| 1. 依頼する | Codex に「お知らせのこの文章を変えたい」などと伝える | Codex が必要なことを質問し、受付表に保存する |
| 2. 確認する | 準備完了メールのリンクを開き、文章や表示を確認する | 気になる点があれば、修正を依頼できる |
| 3. 公開を頼む | 対象を示した公開確認のメッセージに同意する | 運用担当が確認済みの内容を公開し、完了メールを送る |

受付表は、医院と運用担当が依頼を共有するための Google スプレッドシートです。通常は Codex が記入するため、医院の担当者が表の列や行を操作する必要はありません。

「確認用ページ」は公開前に内容を見るためのページです。そこで確認しただけでは、一般の方が見るホームページには反映されません。公開確認のメッセージに返答してください。
