# 公開ページの再現プレビュー

- 入口: クリニックページの移管3ステップ直後。診断結果の末尾から診断URLを引き継ぐ。
- API: 診断Sites版43の `POST /api/rebuild`。
- 入力: 公開URL1件と再制作権限の確認。認証情報・任意ポート・クエリ・内部IP等は既存ネットワーク検証で拒否。
- 出力: HTML5として再シリアライズした静的HTML。元サイトのCSS・画像は公開先から参照する。元サイトのJavaScript、イベント、iframe、フォーム送信、入力済み値は含めない。
- 表示: 空のsandbox属性を付けたiframe＋CSP。スクリプト・API通信・フォーム送信は禁止。HTMLファイルをダウンロードできる。
- 範囲: 入力URLのサイトのトップページ1件の静的な外観プレビュー。完全な移管・素材のローカル収集・外部予約等の機能接続・ソースコード納品・実運用の安全性保証ではない。JSのみで描画するサイトは取得できない場合がある。
- 上限: 入力4KiB、HTML500KiB、取得65秒（定義した一時的エラーに限り1回再接続）、同時4件、既存の時間別回数制限を使用。失敗は作成成功にしない。
- 監査: 成否、要求ID、ホスト、要素数、削除script件数を記録。フォーム内容・取得HTML本文はログに記録しない。
