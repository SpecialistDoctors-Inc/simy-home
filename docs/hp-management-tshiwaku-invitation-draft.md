# tshiwakuさん向け HP更新サービス試用の案内 下書き

2026年11月3日作成。送信前の確認用です。運用担当が初回設定を支援するサンプル試用の案内で、一般提供の開始案内ではありません。

## 送信用の本文

tshiwakuさん

Codexに普段の言葉で依頼すると、ホームページの更新を進められる仕組みを用意しました。まずは架空のクリニックのサンプルで、使い方を一緒に確認できればと思っています。

今回お願いしたいのは、既存の「お知らせ」の本文を1か所変え、確認用ページとメールを見ていただくことです。プログラミングの知識やSIMYへの登録は必要ありません。

使うときの流れは、次のとおりです。

1. Codexに、どの文章をどう変えたいか伝えます。
2. Codexが内容を整理し、確認後に受付表へ記入します。表の列や行を自分で操作する必要はありません。
3. サーバー側で作成とチェックが進み、準備ができるとメールが届きます。依頼の登録後はパソコンを閉じても処理が続きます。
4. メールのリンクから確認用ページを開き、依頼どおりになっているか確認します。

今回は確認用ページまでの練習です。公開中のホームページへ反映するときは、確認した内容を示すメッセージに対して、別途「この内容で本番公開する」と同意していただきます。

最初に、使用するパソコン、ChatGPTを使える環境、受付表に接続するGoogleアカウント、通知を受け取るメールアドレスを確認させてください。アプリや接続の準備は運用担当が一緒に行います。Googleアカウントとメールの受信先は別でも構いません。パスワードやログイン確認コードを送っていただく必要はありません。

現在、自動で対応できるのは、指定した既存のお知らせの本文変更です。画像やページの見た目の変更は今回の試用に含めません。途中で止まった場合の自動通知・復旧は整備中のため、初回は運用担当が見守りながら進めます。進み具合が分からない場合は、同じ依頼を繰り返さず、受付番号を添えて担当者へお知らせください。

- [公開前の確認用ページ](https://sample-clinic-dev.simy.one/#news)
- [現在公開中のサンプル](https://sample-clinic.simy.one/)

ご都合のよい時間と、ご利用になる端末・アカウントを教えていただければ、受付表と接続の案内を用意します。

## 同席時に使う練習文

運用担当が本人の接続、受付先、通知先を確認した後に使います。現在のお知らせに同じ文がある場合や同じ練習が既に受付済みの場合は、重複登録せず担当者が記録を確認します。

```text
サンプルクリニックのホームページ更新を練習したいです。
「Codexとスプレッドシートによる更新テスト」というお知らせの本文の最後に、
「これはtshiwakuによる使い方の確認です。」を1回だけ追加したいです。
それまでの本文、タイトル、日付、ほかのお知らせや画像は変えないでください。
今回は確認用ページだけで、本番公開はしません。

まず接続しているアカウントと受付先を確認し、依頼内容を整理してください。
既に同じ練習が登録済みなら、その受付番号と現在の状況を教えてください。
新しく登録する前に、内容を私に確認してください。
```

内容確認後の登録依頼は次のとおりです。

```text
この内容で受付表に登録してください。
保存した内容を読み戻して、受付番号と変更内容を教えてください。
```

## 運用担当が用意するもの

- 本人の確認済みGoogleアカウントで開ける受付表と、今回のサイトへの依頼権限。
- サービス側の受付者設定と通知先。既存の試験用通知先に届くだけでは本人の受信確認になりません。
- 固定版の受付スキルと、本人用の設定を記入済みの「利用開始メッセージ」。[設定ガイド](hp-management-setup-guide.md)のひな型を使います。
- 問い合わせ先、対応時間、同席日時。受付後の所要時間は確約せず、担当者が進捗を確認します。
- 本人向けの[操作手順書](hp-management-customer-guide.md)。GitHubを開けない場合は同じ内容を本人が読める形で渡します。

試用の完了は、本人のCodexからの受付・読戻し、PCとスマートフォンでの確認、本人の受信確認までです。ここまでを一緒に記録し、使いにくかった点を伺います。技術的な初回ログイン試験が済んでいても、本人の端末・アカウントでの確認は省略しません。

送信先、Googleアカウント、通知先、同席担当・日時はまだ本人確認前です。この下書きの準備だけでは共有権限やサービスの設定は変わりません。[残タスクと利用開始条件](hp-management-remaining-work.md)のR10〜R13で管理します。
