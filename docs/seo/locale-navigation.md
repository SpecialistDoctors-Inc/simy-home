# トップページとロゴの言語

日本語専用のクリニック・弁護士事務所ページでは、ロゴの静的リンクを `/ja.html` にします。本文や診断・料金・申込みの機能は変更しません。

共有ヘッダーはページの言語を維持します。英語のトップ・ロゴ・料金には `/?locale=en` を使います。本番の既存ルーティングは `lang` を正規化で取り除くため、保存禁止のブラウザでも英語の明示選択が残る `locale=en` を使います。既存 `i18n.js` のクリック装飾もこの指定を保持します。

汎用入口 `/`・`/index.html` は、明示した `lang`/`locale`、保存した手動言語、明示した地域、利用できる国のヒント・既知のOSタイムゾーン、ブラウザの優先言語の順に、公開中の6言語へ案内します。言語別のHTMLは自動判定で別の言語へ転送しません。日本の既知タイムゾーンは、英語ブラウザでも日本語へ案内します。タイムゾーンはIP所在地の証明ではなく、外部の位置判定サービスや位置情報の許可は使いません。取得不能・未対応の場合はブラウザの対応言語、最後に英語を使います。繁体字を簡体字と誤認しません。

`simy-home-locale` は既存の言語選択値です。`simy-lang`・`simy-language` はmanualフラグ付きだけを手動選択として読みます。2種類の言語UIは3キーとmanualフラグを揃えて保存します。自動判定を手動設定として保存しません。保存が拒否されても、静的な言語URLと英語の明示パラメーターで操作できます。

実装元は `site/locale-navigation.js`。`scripts/locale_navigation.py` が共有ページのheadへ同じコードを埋め込み、追加のネットワーク要求なしで本文の描画前に判定します。`site_header.py` が生成と適用を担い、共有JSと既存i18n.jsの参照は内容ハッシュで更新します。HPのロゴはJavaScriptが無効でも日本語へ進めます。

公開時は `scripts/locale_navigation_release.py --build` で一回分の有限な公開スナップショットを作り、SHAと差分をレビューします。専用手動ワークフローはそのSHAを照合し、所有するHTML・互換キー・3つのsupportだけを配信し、正確なパスを無効化して完了を待ちます。画像・料金設定・診断コード・サイトマップ・CloudFront Functionは書きません。スナップショットは過去の公開記録なので通常の本文変更時には再生成を要求しません。
