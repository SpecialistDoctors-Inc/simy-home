# 国別調査を踏まえたガイド導線の修正

## 目的・完了条件

検索から来た読者が、探しているツールの使い方・費用・比較・データの扱いを先に理解できるようにする。対象は既存15テーマ×6言語の90記事。成功条件は、検索タイトル・H1・Article見出しの整合、実用説明への最短導線、両目次と本文順序の一致、確認できた料金誤記の全言語修正、公開ページ全件の表示・技術SEO検証。既存本文を捨てず、無関係な語句や国名だけの重複ページを増やさない。

## 調査根拠と限界

`guide-country-observations.json`に、Ahrefs Keywords Explorerの国・記事別レポートURL、観測時刻、関連語と取得状態を保存した。110件中83件で使用可能な行を取得、21件はNo keywords found、6件は取得不可。最後に月間クレジット上限の表示を確認し、追加調査を止めた。取得不可を需要ゼロ・調査完了とは扱わない。生データはローカルの `artifacts/international-seo/guide-country-research.json`。

日本、米国、英国、インド、スペイン、メキシコ、フランスで記事別に確認。シンガポールはホーム向け既存調査のみ使用可能で、今回の記事別データは取得不可。日本のブランド単体と使い方クエリ、他国の英語ブランドクエリを使った標本調査であり、全現地語・全検索エンジンを網羅したものではない。中国本土・百度の調査は含まない。

共通して用途、アプリ、無料枠、コード、会議ツールなどの意図が現れた。PLAUDではフランスの enregistreur vocal、メキシコの cuánto cuesta、Notta・議事録では Google Meet / Microsoft Teams、Codexでは VS Code / GitHub Copilot、Qwenでは Alibaba / image が関連する。無関係なナビゲーション語や別製品名は採用しない。取得結果の全行を本文へ詰め込まず、既存の実用説明を先に見せる。

Search Consoleにも接続し、28日・https://simy.one/フィルターでクエリ、国、ページの基準値を取得。内部データは公開サイトやリポジトリへ含めずローカルに保存した。データ期間は公開前で、今回の改善効果を示すものではない。

## 実装と判断

- 90記事のH1を各言語の検索タイトルに合わせ、Article.headlineも一致させる。
- 通常ガイドは実用情報のreferenceを先頭へ、中国AI比較はcompare→choose→reference、自社運用はbasics→engines→hardware→build→checklist→mistakesを先頭へ。本文の内容と既存アンカーを維持し、目次・章番号を再配置する。
- 最初の実用説明を開いた状態にし、操作なしで説明が見えるようにする。生成処理は `scripts/organize-guide-intent.py` に保存し、CIで再生成一致を検査する。
- Codex・ChatGPTのFree/Go非対応という断定とPro 200新規停止の記述を修正。根拠は2026-10-03取得の https://developers.openai.com/codex/pricing と https://learn.chatgpt.com/docs/pricing 。Free/GoのデスクトップGPT-6 Lunaは段階提供と明示。SIMYクラウドの接続条件と混同しない。ChatGPTの料金表は確認した米ドル参考価格と公式購入画面への案内に統一し、未検証の換算額・広告・席種別断定を除く。各言語の修正内容は `codex-plan-corrections.json`。
- careers / how-it-works / integrations / security / statusの隠れたReactマウントを除去。静的本文とは別に404見出しを生成し、不要なアプリJSを読み込んでいた。問い合わせページのReactフォームは維持する。

## 検証と公開条件

1,137テスト、ホーム再生成一致、ガイド再生成一致、全148 HTML（公開122・noindex26）の静的SEO検査。ブラウザーでは公開122URLを390pxと1440pxで確認し、問題箇所を修正する。独立レビューと公開後のHTTP一致確認は別途行う。

独立レビューはAGENTS.md指定のgpt-5.5 / xhigh。ロールバックは今回のコミットをrevertしてサイトを再配信し、CloudFrontキャッシュを無効化する。DB・個人情報・IAM変更はない。

本番の旧?lang=転送更新は既存のCloudFront Function更新権限不足が残る。追加のAhrefs調査は利用枠不足が残る。この2点と未取得市場を隠して「全世界で最大化」「完全完了」とは報告しない。補助14ページの全6言語静的化や、公開後の順位改善はこの差分では達成していない。

## 実施した検証

- ローカルChrome Extensionで公開122ページ×390/1440pxの244表示を記録。全件でページ全体の横はみ出しなし、H1は1個、読み込み完了画像の破損なし。ガイド各セクションの左右端の差は0px。モバイルのデモ画像4点は遅延読み込み待ちとして区別した。
- 日本語Nottaのヒーロー内リンクから実用説明に移動し、固定ヘッダーの下に見出しが見えることを確認。Enterで説明を閉じる操作、日本語→フランス語の同記事への言語切替も確認。全ページで全操作を手作業した意味ではない。
- デモ画像4点にPNGの実寸2880×1800を指定し、読み込み前に領域を確保。
- 独立gpt-5.5/xhighレビューの空白・日付指摘を修正。90記事のbyline、Article.dateModified、article:modified_time、サイトマップlastmodを実際の更新日2026-10-03に統一。出典の料金確認日も揃えた。
- 再レビューは指摘なし。追加で見つけたCodexの5時間制限の過度な一般化を全6言語の本文・FAQで修正し、別途再レビューを実行。残っていた「初回利用から5時間・7日」の固定リセット説明も全6言語の可視FAQとJSON-LDで修正し、最終再レビューは指摘なし。Proの現在の5時間制限なし、Plus/標準Businessの枠、週上限は場合により適用という公式記述へ合わせた。
- Search Consoleで新しい日本語ホームはまだGoogleに未認識だったため、インデックス登録リクエストを実行し、優先クロールキューへの受付を確認。インデックス完了・検索順位改善とは別の状態。

Search Consoleの元データとスクリーンショット、ブラウザー観測値、独立レビュー出力は `artifacts/international-seo/` にローカル保存し、S3配信・コミットの対象外にする。
