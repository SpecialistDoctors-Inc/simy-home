# 本番開始前の受入と担当

## 実装済み・ローカル確認

- HOME4契約の既存価格・税・周期・言語と紹介メタデータ。
- 署名付き紹介cookie、日英の固定遷移先、広告表記付きリンクとバナー。
- 初回請求、無料期間、返金、争議、webhook再試行・順序、所有者隔離。
- 整数通貨台帳、最低額、振込先版の固定、差替え防止、額・通貨・受取人照合、二重精算防止。

## 管理された環境で必要な受入

1. DB運用担当がsimy-backendの紹介台帳migrationと振込先検証migrationを、既存migrationと統合した専用devへ適用。エージェントは共有DBへ直接接続しない。適用後にRPC・RLS・既存課金機能への影響を確認。
2. Web担当が4つのHOME Price IDと設定を対象環境に配置。各Priceがactive・USD・正しい月額／年額・税別であることを確認。秘密値はレポートしない。
3. Stripeテストモードで、日英×2プラン×2周期の紹介→登録→Checkout→無料期間→初回支払い→50日期限→申請→振込先確認→準備→模擬振込記録を実行。実送金はしない。
4. 部分／全額返金、争議、既存顧客、自己紹介、無料請求、更新、追加オプション混在、再送・順不同、権限外閲覧を確認。
5. 運用責任者が利用する振込先管理・送金サービス、担当者と代行者、月次締め処理と障害時の問い合わせ窓口を指定。実際の本人確認と支払いは人が行う。
6. 本番運用担当が同じ構成を本番へ適用し、開始条件を確認してから受付を有効化。最初の紹介帰属・支払い記録を読み戻す。

この受入を実行する前に「紹介制度が本番稼働済み」とは報告しない。
