## 撮影の根拠

公式リリースv1.2.11のソースコミット `9146fe2ced9f79571210f087665d7e94795dfdb9` から
SIMY_DEVネイティブアプリをビルドし、同版のCLI公式fixtureと組み合わせた。
`capture-cli-ui.py --locale ja|en --source-commit …` で実際のアプリの言語設定を切り替えて撮影。
日本語の説明用fixtureは翻訳し、英語は公式fixtureの内容を使用。画像の文字の後加工はしていない。
両言語とも2360×1600。各言語のmanifestと統合manifestに版・コミット・寸法・ハッシュを記録。
実顧客のデータや本番の成果ではなく、サンプルデータであることを各ページに明記。

紹介制度画像はローカル開発用 `/e2e/affiliate/?lang=ja|en` の実装表示。
1190×893の画像全体に写る制度説明・統計・報酬欄を各言語で確認。
写っていないブログHTML編集欄など、アプリ全体の翻訳完了を意味しない。
受付・課金・送金は開始していない。

## 文字認識と目視

macOS Visionの日本語・英語認識を補助として使用。集計は `ocr-summary.json`。
英語のネイティブ画面にはOCRがアイコンを「日」「入」「へ」「司」「・」と誤認する箇所がある。
原寸画像と照合したところ、アーカイブの箱、外部リンク矢印、折り畳み矢印、区切り点だった。
英語画面内に日本語の説明文やラベルは残っていない。英語の紹介制度・SNS・Google PlayはCJK検出0行。
日本語版では説明と操作ラベルを日本語で確認。SIMY / Delivery Loop / SQM / Codex / Claude Code / NVIDIA / Next.js、
リポジトリ名・コード・ファイル名・URL・端末の固有名・数値・単位は意図的に保持。
文字化けの置換文字や豆腐文字を全画像の目視で認めなかった。

## ブラウザ

日英それぞれ320・390・768・1440px幅で横はみ出しなし。全7吹き出しの本文は20px。
`browser-measurements.json` は各幅の実測値。画面外の遅延画像には未読込が含まれるため、
このJSONのloaded=falseを破損と判断せず、別途スクロール表示・原寸画像・ファイルハッシュで確認。
`mobile-ja.jpg` / `mobile-en.jpg` は390px幅の実表示。`badges-ja.jpg` は日本語バッジの実表示。
