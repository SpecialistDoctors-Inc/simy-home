# SIMY公式サイトのロセンズ紹介ページ

## 参照するページと実装

| 参照ページ | ロセンズに適用するルール |
| --- | --- |
| [日本語トップ](https://simy.one/ja.html)・[職業別の活用](https://simy.one/for/) | 共通ヘッダーを使用する。日本語トップと日本語の職業・業種別ページの「活用シーン」→「SIMYの業務活用」に「ロセンズ（路線価評価）」を1件置く。現在のページは `aria-current` で示す。 |
| [エンジニア向け](https://simy.one/for/engineers/)・[ファイナンシャルプランナー向け](https://simy.one/for/financial-planners/) | 最初に仕事と利用場面が分かる見出し、漫画、主操作を置く。次に操作と用途を説明し、料金と導入相談へつなげる。狭い画面では説明を先に読める順序で縦に並べる。 |
| [新料金の総合案内](https://simy.one/pricing-2026-11.html)・上記のサービス別料金 | 新料金の状態と適用条件を最初に示す。サービス、課金単位、円・ドルの料金列、利用範囲を区別する。円・ドルの各列の中で月払いと年払いを分ける。料金と課金条件の出典は既存の料金仕様と生成処理を使う。 |

## 画面の仕様

- ヘッダーは `scripts/site_header.py` と `site/site-header.css` に従う。幅961px以上はヘッダーから直接メニューを開く。幅960px以下はハンバーガーから開く。項目の順序、ラベル、余白、キーボードフォーカスは共通ヘッダーに揃える。
- 本文と料金は同じ左右の端に揃える。ロセンズの本文枠は最大1,200pxで、幅681px以上は左右32px、680px以下は左右16pxの余白を確保する。漫画、動画、利用場面、料金の要素はこの枠の中に配置する。
- 色は `site/site-theme.css` を基準にする。白い面は `--paper-light`、切り替え背景は `--paper`、本文は `--ink`、補足は `--ink-soft`、リンクは `--blue-deep`、表の見出し面は `--mint-soft` を使う。ロセンズは日本語の本文16px、H1 32px、H2 24px、カード見出し18pxを基準とする。価格は等幅数字で表示する。
- 総合料金案内とサービス別料金は、`pricing-rate-tables.css` の `.pricing-rate-table` を共用する。デスクトップはサービス、単位、JPY、USD、範囲の5列。見出し面、16pxの本文、罫線、角丸、セル余白はこのCSSで定義する。円・ドルそれぞれの列で、月払い、年払い、年額の月相当額を続けて読める順に示す。従量表は利用範囲の列を省く。
- 幅768px未満はサービスごとの行をカード表示にし、課金単位と利用範囲は全幅、JPYとUSDは共通の2列に置く。セルに通貨ラベルを表示し、スクリーンリーダーには表の列見出しを残す。税区分のキャプションには全幅を使う。
- ロセンズでは基本込みの月額例を料金表の前に置く。日本語トップの料金欄で使うような青系の淡い面と強い数字で、最初に合計を見せる。税込・税別、年額と月額を一つの数字に混ぜない。
- 主操作は「実際の操作を見る」、料金への導線は「料金を見る」、下部の問い合わせは「ロセンズの導入を相談する」。リンクの行き先と操作名を一致させる。動画は停止・再視聴でき、試算の内訳はテキストでも読める。

## 受け入れ確認

幅320・390・780・960・961・1,440pxで確認する。780pxはPCの分割表示を想定する。メニューからロセンズを開けること、税区分の文字が一行で読めること、料金表と本文の外枠の左右差が1 CSS px以内であること、JPYとUSDの列位置がサービス間で揃うこと、ページに水平方向のスクロールが生じないことを確認する。PCではキーボードでもメニューを開き、フォーカスの位置を確認する。
