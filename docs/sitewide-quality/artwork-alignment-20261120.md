# 元画像を保持したホームの位置合わせ

2026-11-20、ユーザーから「元の絵がなくなる」「縦と水平のラインが揃わない」との指摘を受けて本番とソースを照合。

主要6ページ（HOME・エンジニア・FP・製薬・医院・法律）のPC/390px実画面では、本文画像の読み込み失敗は再現しなかった。閉じたナビ内のストアバッジは意図的な非表示として区別。最初の全サイト品質変更前 `d90aa842^` と現行の既存HTMLのimg srcを比較し、削除された参照はなかった。特定の絵の消失を復旧済みとは主張しない。問題を確認したURL・場所をユーザーへ照会しつつ、実測できた位置ずれを修正した。

ホームの冒頭と末尾は32pxの個別余白・異なる列幅、中段は共通のsection-x余白・等幅列を使っていた。全6場面を同じ余白と2列構成にそろえ、モバイルでは同じ余白の1列にする。並列のMy AI/My Actionsカードは共通行のsubgridで見出し・画面・外枠の上下端を共有する。固定高さで翻訳文を切らない。

日本語1440pxの実測:

| 対象 | 修正前 | 修正後 |
| --- | ---: | ---: |
| 6場面の画像の右端の最大差 | 25.59375px | 0px |
| 並列カードの下端の差 | 74.75px | 0px |

元画像のバイナリ、6言語のimg src/alt/srcset、漫画の6場面は変更していない。CSSは内容hash付きURLへ更新し、キャッシュされた旧CSSが残らないようにした。HOMEの固定hash baselineはstylesheet URLの変更分だけ更新。料金データ・checkout JSON/JSのhash検査は保持。

検証: 全1,650 tests、6言語×1440/1024/768/720/390/320pxの36ケース。画像decode、全6場面の可視領域、右端の差1px以内、並列カードと画面の上下端1px以内、はみ出し、見出し、3つのデモ、キーボード操作、現行料金/言語の引継ぎを検査。詳細は evidence/home-artwork-alignment-browser.json。Linuxで再現できるよう既存ブラウザー検査はPlaywright同梱Chromiumを既定にし、HOME_MANGA_BROWSER_CHANNELでChromeも選択可能。

## ダウンロードページの添付画像への対応

ユーザーの添付は /download.html の途中までスクロールした画面。先頭表示でH1はナビゲーションより下にあり、見出し欠けは初期表示では再現しなかった。本文の画像要素は以前から0件で、画像消失とは区別する。実測では1180pxのwrap内に980pxの本文を左寄せし、左右カードを0.8:1.2・上端だけ合わせていた。

6言語の本文コンテナ自体を980pxで中央寄せし、登録案内とダウンロードを上下に配置して左右端を共通化した。PCではプラットフォームを等幅3列、共通subgridで名称・ボタン・メタ情報・注意文の行を共有。860px以下は1列。文面・リンク・画像参照・スクリプトは変更していない。

検証: 既存1,650テスト、全199HTMLのSEO検査、tests/download-layout-browser.cjs による6言語×1440/1100/861/860/390/320pxの36ケース。本文中央寄せ、セクション両端、カードとボタンの上下端1px以内、ナビによる初期H1隠れなし、はみ出し・ボタン文字切れなし、3プラットフォーム保持を検査。
