# 元画像を保持したホームの位置合わせ

2026-11-20、ユーザーから「元の絵がなくなる」「縦と水平のラインが揃わない」との指摘を受けて本番とソースを照合。

主要6ページ（HOME・エンジニア・FP・製薬・医院・法律）のPC/390px実画面では、本文画像の読み込み失敗は再現しなかった。閉じたナビ内のストアバッジは意図的な非表示として区別。最初の全サイト品質変更前 `d90aa842^` と現行の既存HTMLのimg srcを比較し、削除された参照はなかった。特定の絵の消失を復旧済みとは主張しない。問題を確認したURL・場所をユーザーへ照会しつつ、実測できた位置ずれを修正した。

ホームの冒頭と末尾は32pxの個別余白・異なる列幅、中段は共通のsection-x余白・等幅列を使っていた。全6場面を同じ余白と2列構成にそろえ、モバイルでは同じ余白の1列にする。並列のMy AI/My Actionsカードは共通行のsubgridで見出し・画面・外枠の上下端を共有する。固定高さで翻訳文を切らない。

元画像のバイナリ、6言語のimg src/alt/srcset、漫画の6場面は変更していない。CSSは内容hash付きURLへ更新し、キャッシュされた旧CSSが残らないようにした。HOMEの固定hash baselineはstylesheet URLの変更分だけ更新。料金データ・checkout JSON/JSのhash検査は保持。
