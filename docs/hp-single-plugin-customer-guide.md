# HP ローカル編集の使い方

プラグイン 0.3.12 / 2026年11月8日版

ホームページを開き、右下のチャットで修正します。手元で確認した後に確認用サイトへ反映し、もう一度確認して公開します。

## 1 初めて使うとき

MacのApple Silicon（M1以降）に対応しています。Codexが使えるデスクトップアプリに、ご自身のChatGPTアカウントでログインしてください。[アプリの入手先](https://chatgpt.com/download/)

運用担当から、プラグインのZIPとHP用Googleアカウントの案内を受け取ります。サイトへのアクセスは運用担当が事前に設定します。

### ZIPから導入する

1. 配布セットを解凍し、中の `hp-local-editor-0.3.12-mac-apple-silicon.zip` をCodexの会話に添付します。添付できない場合はFinderでファイルを選び、Option + Command + Cで場所をコピーして貼り付けます。
2. 次の依頼文を送ります。

```text
このHPプラグインを導入して、編集を始めたいです。
導入済みなら、作業中の変更を引き継いで更新してください。
```

3. Codexがプラグインの導入状態を確認します。本人の操作が必要な場合は、案内に従って「HP ローカル編集」を追加します。今回の版が読み込まれず再起動を案内された場合は、作業を保存して再起動します。
4. HPプラグインを選び、画面に案内されたGoogleログインを完了します。元の会話で「続けて」と送ると、依頼済みの編集開始を続行します。

Codexの返信に医院名と確認用・公開中のURLが表示されます。サイトが1件ならそのサイトで編集画面を開き、複数ならCodexがどれを編集するか尋ねます。

展開や登録はCodexに任せられます。利用者が追加でGit、Python、別のCodex CLIをインストールする操作はありません。GitHub・SIMYへの利用者登録も不要です。

ChatGPT用とHP用Googleのメールアドレスは異なっていても使えます。パスワードや確認コードは、各サービスのログイン画面で入力してください。

運用担当からプラグインの導入リンクが案内された場合は、リンク先のインストールとGoogle接続を進めてください。利用できる導入方法はアプリ・アカウントによって異なります。[公式のローカルプラグイン導入方法](https://developers.openai.com/plugins/build/plugins#install-a-local-plugin-manually)

## 2 編集画面を開く

初回導入の続きを進めると、編集画面がブラウザーに開きます。次回からは、CodexでHPプラグインを選び、次のように伝えます。

> ホームページの編集を始めたいです。確認画面を開いてください。

ブラウザーに手元の確認ページが開きます。右下のマークを押すとチャットが開きます。複数のサイトを使える場合は、Codexの案内に沿って編集する医院を選びます。

ローカルページのURLは起動ごとに変わることがあります。次回は同じようにCodexへ依頼してください。

## 3 右下のチャットで修正する

> 診療時間の「18時まで」を「19時まで」に変えてください。

変更が終わると、手元のページが更新されます。文章・日付・表示を確認し、必要なら続けて指示します。

> 見出しを少し小さくしてください。
>
> さっきの診療時間の変更を元に戻してください。

Enterで送信、Shift + Enterで改行できます。日本語変換を確定するEnterでは送信しません。

ブラウザー内のチャットは、そのHPの編集用の会話です。Codexアプリの別の会話で伝えた内容が必要な場合は、こちらにも伝えてください。

## 4 確認用サイトへ反映する

手元の内容がよければ **「確認用に反映」** を押します。保存と反映が終わるまで待ち、表示された **「確認用サイトを開く」** を押します。

確認用サイトで、文章・リンク・画像とスマートフォンでの見え方を確認します。修正が必要なら手元のチャットに戻り、修正してからもう一度反映します。

### 版番号の見方

| 表示例 | 意味 |
| --- | --- |
| 確認用 v2 / 公開中 v1 | 確認用サイトに次の版が用意されています |
| 確認用 v2 / 公開中 v2 | 同じ版が公開されています |
| — | 版番号をまだ取得できていません |

番号は確認用サイトへの反映が完了した内容に付きます。公開すると、確認した版の番号を引き継ぎます。各表示にカーソルを重ねると反映日時を見られます。

## 5 内容を確認して公開する

1. 確認用サイトを確認したら、チャット下の **「公開する」** を押します。
2. 開いた画面でサイト名、公開前後の版番号、変更概要を確認します。文章の変更前・変更後や、追加・削除の内容が表示されます。
3. **「変更後を見る」** で確認用サイトを見られます。内容がよければ、この確認画面の **「公開する」** を押して確定します。
4. 「公開済みの内容」と表示されたら、**「公開サイトを開く」** で結果を確認します。

処理状況は自動で更新されます。設定済みの通知先には、確認用サイトの準備完了・公開完了をメールでも案内します。

概要は長い文章を短くし、多い場合は最初の5件と残りの件数を表示します。画像やデザインなどは変更種別の概要になる場合があります。確認用サイトの表示もあわせて確認してください。

## 6 次回の編集・困ったとき

| 状況 | 操作 |
| --- | --- |
| 次回の編集を始めたい | Codexで「前回のHP編集を再開し、確認画面を開いて」と伝えます |
| 直前の修正を戻したい | チャットで、どの変更を戻すか伝えます |
| 修正が途中で止まった | 表示された「修正を再開」「中断した変更を再開」を使います。解消しなければCodexに続きの確認を依頼します |
| 反映・公開の結果を確認中 | 自動確認を待ちます。長く続く場合はCodexへ「前回の処理がどこまで完了したか確認して」と伝えます |
| 「同じ依頼で再確認」が表示された | 同じ依頼の受付結果を確認するボタンです。押して結果を待ちます |
| 「処理を再開」が表示された | 止まっている元の処理を再開するボタンです。繰り返し止まる場合はCodexに原因の確認を依頼します |
| 「公開結果を見る」が表示された | 前回の公開結果と変更概要を開けます |
| Macが起動を止める・セキュリティ警告が出る | 表示内容を運用担当に伝え、配布物と実行環境を確認してもらいます |
| 確認期限が切れた | 確認画面を閉じ、チャット下の「公開する」から開き直します |
| ログインや接続で止まる | 運用担当に登録したGoogleアカウントを確認し、案内に従って再接続します |
| プラグインの更新ZIPを受け取った | 導入時と同様にZIPをCodexへ渡し、「作業中の変更を引き継いで更新して」と依頼します。案内に従って作業を保存しアプリを再起動したら、新しい会話でHPプラグインを選びます |

画像の追加など、ブラウザー内のチャットで扱えない変更は、Codexアプリへファイルと依頼内容を渡してください。
