# 医院向け: ホームページ更新の手順書

Codex に話しかけて、ホームページの修正を依頼します。医院で行うのは、変更内容を伝え、確認用ページを見て、公開に同意することです。プログラミングの知識や SIMY への登録は必要ありません。

## 1. 最初の準備をする

初回は運用担当と一緒に進めてください。担当者から、次のものを受け取ります。

- 医院専用の「受付表」のリンク
- 設定後に Codex へ貼り付ける「利用開始メッセージ」
- 問い合わせ先と、依頼に対応する時間帯

手元にはパソコン、利用する ChatGPT アカウント、医院用の Google アカウント、通知を受け取るメールアドレスを用意します。Google アカウントと通知先が同じである必要はありません。担当者に、どちらを使うか伝えてください。

### アプリを開く

1. [公式のダウンロード・開始案内](https://learn.chatgpt.com/docs/quickstart?setup=app)を開き、パソコンに合ったデスクトップアプリを入れます。公式案内では「ChatGPT desktop app」と表示されます。
2. アプリを開き、利用する ChatGPT アカウントでログインします。
3. 新しいチャットのモードを選ぶメニューから「Codex」を選びます。

### 受付表を使えるようにする

1. アプリの「Plugins」を開き、「Google Drive」を探します。
2. 詳細を開いて追加ボタンを押し、接続を求められたら、医院用の Google アカウントでログインします。
3. アカウント名と許可する内容を確認して接続します。どのアカウントか分からないときは、運用担当と確認してください。
4. 運用担当が「HP更新の受付手順」を Codex に設定します。これが「受付スキル」です。
5. 新しい Codex チャットを開き、担当者から受け取った「利用開始メッセージ」をそのまま貼り付けて送ります。

画面の名称が違う、または Google Drive が表示されない場合は、運用担当に画面を見てもらってください。[公式のプラグイン案内](https://learn.chatgpt.com/docs/plugins)でも操作を確認できます。

**医院名と受付表が正しいことを確認し、運用担当と練習の依頼が1件保存できたら準備完了です。** 練習する内容は事前に担当者と決めます。ログイン時のパスワードはご自身で入力してください。

## 2. 変更したいことを伝える

準備した Codex のチャットで、変更したい場所と内容を伝えます。例えば、次の文章をコピーして、医院の内容に書き換えます。

```text
ホームページのお知らせを更新したいです。
タイトルは「年末年始の休診について」にしてください。
本文は「12月29日から1月3日まで休診します。」です。
年や掲載する期間など、足りないことは質問してください。
まず公開前の確認用ページを用意してもらいたいです。
```

これは記入例です。実際の日付や休診予定は、ご自身の医院のものにしてください。文章が決まっていなくても、目的を伝えて相談できます。写真を変える場合は、使いたい写真も添えてください。

Codex から質問があれば答え、整理された依頼内容が合っているか確認します。合っていれば、次のように伝えます。

```text
この内容で受付表に登録してください。
保存できたら、受付番号と依頼内容を教えてください。
```

「保存しました」という返答と、保存された内容を確認します。受付番号は問い合わせに使います。表の番号や設定を自分で書き換える必要はありません。

受付表への記入は Codex が行います。依頼の登録が終わっても、ホームページはまだ公開されません。受付時間や作業予定は、運用担当の案内に従ってください。

## 3. 準備完了メールから確認する

確認用ページができると、登録したメールアドレスへ「確認用ページの準備ができました」というメールが届きます。

1. メールの確認用リンクを開きます。
2. 依頼した文章・日付・写真・リンク先を確認します。
3. スマートフォンでも開き、文字が読みやすいか確認します。

修正したいところがあれば、同じ Codex のチャットで具体的に伝えます。

```text
先ほどの休診のお知らせを修正したいです。
本文の「1月3日まで」を「1月4日まで」に変えてください。
修正後の確認用ページを見てから、公開を判断します。
```

依頼が複数ある場合は、メールに書かれた受付番号も添えてください。修正後は、新しく届いた確認用ページをもう一度確認します。

## 4. 確認した内容の公開を頼む

問題がなければ、運用担当に公開の確認を依頼します。

```text
確認用ページの内容を確認しました。
この内容を公開するための確認メッセージをお願いします。
```

運用担当は、**どの依頼の、どの確認済みの内容を公開するか**を示したメッセージを用意します。依頼名・確認用リンク・変更内容が合っていることを確認し、そのメッセージに対して次のように返答します。

```text
この内容で本番公開する。
```

これが、一般の方が見るホームページへ反映する同意です。メールや確認ページを開くだけでは、公開への同意にはなりません。

確認メッセージに長い英数字が表示されることがあります。確認した内容を取り違えないための管理番号で、運用担当と Codex が照合します。ご自身で入力・転記する必要はありません。どの内容への同意か不明な場合は、返答する前に運用担当へ確認してください。

公開完了メールが届いたら、メールの公開先リンクを開いて確認します。ここまで終われば、その依頼は完了です。

## 5. 困ったとき

| 状況 | すること |
| --- | --- |
| 受付表を開けない | 表のリンクと使っている Google アカウントを運用担当に伝える |
| 「保存できません」と表示された | 表示された文を運用担当に伝える。受付済みか確認してから再依頼する |
| メールが届かない・進み具合が分からない | 迷惑メールを確認し、受付番号を添えて運用担当に問い合わせる |
| 依頼した内容を変えたい | 同じチャットで、どの依頼の何を変えるか伝える |
| 公開を待ってほしい・依頼を取り消したい | 受付番号を添えて運用担当に連絡し、停止できたか返答を確認する |
| 新しいチャットで医院が分からないと言われた | 最初に受け取った「利用開始メッセージ」を貼り付ける |

問い合わせには、受付表の「ご利用ガイド」に記載された連絡先を使います。表示されたエラー文を伝えるときも、パスワードやログイン確認コードは送らないでください。
