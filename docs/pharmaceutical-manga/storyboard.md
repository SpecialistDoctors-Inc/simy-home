# 製薬企業向け漫画：原画制作仕様

## 見直した根拠

参照原画：`site/assets/engineer-manga/release-crew-ja.webp`。
構成：`scripts/engineering_manga.py`。
現状の製薬企業向け原稿：`scripts/pharmaceutical-ja.html`。

SE向け原画は、異変の発見→依頼→原因の特定→人の判断→検証→次の仕事という展開を、人物の動き、画面の変化、距離と視点の切替で描いている。背景、手元、相手、仲間が物語を担っている。

製薬企業ページは3つの顔の切り抜きを8場面で反復している。台詞は進んでも、場所・行動・表情・相手との関係が変わらず、録音や練習の更新も文章にしか存在しない。「同じキャラクターを使う」という要望は、同じ顔画像を繰り返すことではなく、同じ登場人物による別の物語として扱う。

## 中心に置く変化

担当医師の言葉を残す→関心と未解決の問いを確かめる→その医師役で練習する→実面談で新しい課題に出会う→その情報で練習を更新する。

主役の成長は、説明を急いでいたMRが、先生の確認したいことから質問できるようになること。録音はこの変化を次の面談へつなぐ材料として描く。

## 登場人物

- 主人公MR：SE向け主人公の青黒い髪、顔立ち、ゴーグルの特徴を維持。医療機関を訪問する服装に整え、ポーズと表情を新しく描く。
- 同僚・育成担当：SE向けの丸眼鏡と巻き毛の人物。終盤で具体的な支援を考える。
- SIMY：既存の青いキャラクター。情報を整理する相棒。すべての場面で正面顔を出す必要はない。
- 担当医師：新しい架空の医師。1・6場面で同じ顔と服装、同じ診察室を使い、同じ相手との続きと分かるようにする。
- AI医師役：同じ医師を想起できるが、端末の青い枠・AI表示で実面談と明確に区別する。

## 新しく描く8場面

| 場面 | 原画の構図・行動 | 絵で分かる変化 | 台詞の核 |
| --- | --- | --- | --- |
| 1. 先生の問いに、説明が止まる | 医師の肩越しにMRを捉える病院の面談室。比較資料を開いたMRの手が止まる。机上に同意を得て使用中の録音端末。 | 一般的な説明と、その医師の確認したい点とのずれ。 | 医師「その患者集団は、私の診療と重なりますか？」 |
| 2. 録音の中に、次の手がかり | 面談後の静かな作業場所。MRの手元と端末を上から捉え、録音の再生位置、元の発言、未解決の問いを近接して見せる。SIMYは小さく補助する。 | 感覚的な振り返りから、実際の言葉に基づく確認へ。 | MR「比較の数字より、患者背景を確かめたかったんだ」 |
| 3. この先生との練習ができる | 自宅またはオフィスのデスクを斜めから。先生の公開情報と前回の発言が、次回の練習設定へ集まる。MRが設定を確認する。 | 録音の内容が、医師役の質問と反応に具体的に反映される。 | SIMY「今回は、患者背景の条件を聞く練習にしましょう」 |
| 4. 練習でも、説明を急いでしまう | スマートフォンとの音声練習。画面越しのAI医師とMRを横から描く。MRは言葉に詰まり、片手の資料を見直す。 | 実面談の課題が、練習で再現される。 | AI医師「先に、どの患者さんの話か教えてください」 |
| 5. 聞き方を変えて、再挑戦 | 4と同じ場所。カメラをMRの正面寄りに変え、資料を置き、相手を見て問いかける姿を描く。端末には振り返りで選んだ質問。 | 同じ場面でも、説明中心から質問中心へ行動が変わる。 | MR「どの患者背景の違いが気になりますか？」 |
| 6. 次の実面談で、新しい宿題 | 1と対になる構図、同じ医師と同じ面談室。MRは聞き取った条件を確認し、医師は次の論点を示す。録音は再度ルールに沿って使用。 | 練習の暗記で終わらず、実際の対話が次の課題を生む。 | 医師「次は、院内で誰が何を担うかも確認したいです」 |
| 7. 新しい会話で、練習が変わる | 録音の新しい発言と、更新前後の練習を大きく描く画面中心のコマ。「患者背景の確認」に「院内分担」が追加される。人物は画面を見守る。 | 会うたびに更新するパーソナライズの仕組みそのもの。 | SIMY「次は、院内の役割分担を確かめる練習へ」 |
| 8. 一人の変化を、次の育成へ | オフィスの引きで、MRと丸眼鏡の育成担当が同じ画面を指さす。練習での課題と次の支援を確認。 | 個人の練習が、チームの具体的な支援へつながる。 | 育成担当「次は、この聞き方をチームでも練習しよう」 |

## 演出と制作の条件

- 見開きごとに、場所・カメラ距離・人物の動作・画面の主役を変える。顔のアップを連続させない。
- 1と6、4と5の対比で、同じ人物がどう変わったかを見せる。
- 2・3・7は、録音を示すだけでなく「拾った言葉→設定した問い→追加した練習」を具体的に描く。
- 医師の顔と関心を固定的な性格診断として断定しない。MRが発言の解釈を確かめる場面を含める。
- 処方増加や売上の成功を架空の結末にしない。確認する条件と次の宿題が明確になることを到達点にする。
- 新規原画は8場面を別ファイルで制作。スマートフォンでも1場面ずつ読める横長の画面を基本とする。
- 絵の中に翻訳が必要な台詞を焼き込まず、吹き出し・説明・UIの重要ラベルはHTMLで重ねる。絵に描く文字や数値が意味を担う場合も、各言語で同じ意味を確認できるようにする。
- 既存の6言語の原稿と結びつける。漫画を文章で読める代替も維持する。

## 次に必要な成果物

1. 参照原画を使った人物設定と、8場面のラフ原画。
2. 人物の同一性、医師とAI医師の区別、場面・行動・感情の変化を原画で確認。
3. 完成した8原画を6言語共通の漫画レイアウトに組み込み、台詞と説明を対応させる。
4. PC・スマートフォンで順に読んだとき、説明文を読まなくても面談→録音→練習→面談→更新が追えるか確認。
