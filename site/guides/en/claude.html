What is Claude: who makes it and what it can doWriting, long summaries, Excel, PDF, code, research

Who makes Claude

Claude is made by Anthropic, an AI company based in San Francisco and founded in 2021 by former OpenAI members. You can use it on the web (claude.ai), in desktop apps for Mac and Windows, in iOS and Android apps, and through a Chrome extension.

Where it runs, and how well it handles languages

Anthropic is a US company, and Claude is a cloud service. It writes naturally in many languages and is often praised for consistent, polished business writing. Turning a transcript into meeting notes or summarizing a foreign-language document works even on the free plan. If your company is adopting it, check data location and contract terms in the Team and Enterprise materials.

What it can do at work

  • Writing and editing: drafts of emails, proposals and reports. Clear, careful prose is a strength.
  • Reading and summarizing long text: hand it a long contract or meeting transcript at once and pull out key points and decisions.
  • Working with files: ask questions about PDFs, Excel, Word files and images. Good for reading tables and organizing numbers.
  • Artifacts: builds documents, diagrams and simple apps in a side panel that you can edit and take with you.
  • Projects and connectors: save instructions and reference files in a Project to reuse, and connect tools like Google Drive and Slack.
  • Code and automation: Claude Code edits files and runs commands from the terminal, and Cowork lets you hand off desktop work (compared below).

Every one of these does the work when you ask. Starting before you ask is the only part left outside Claude.

How to use Claude: 5 things to set up firstApp, Projects, connectors, model, where results go
  1. Install the app and just talk to it. claude.ai on the web is enough, but the desktop app adds a shortcut and is where Cowork lives. The mobile app is handy on the go, and the Chrome extension reads the page you have open.
  2. Put instructions and files in a Project. Store your standing instructions ("notes in this format," "replies in this tone") and reference files in a Project so every new chat starts from the same context. Many people add a glossary and past proposals.
  3. Use connectors for the places Claude should look. Connect Google Drive, Gmail, Slack or Notion and you can say "read last week's Client B notes" without pasting files. Follow your company admin's policy.
  4. Leave the model on default; move up when needed. The default model is fine for daily work. Switch to Opus only for comparing long contracts or polishing key proposals.
  5. Decide where results go. Claude's answers stay inside the chat. Decide that emails go to Gmail drafts, notes to Notion and updates to Slack, so you never have to search later. SIMY takes on exactly this "move it where it belongs" part.

Prompting tips

State the role, goal, reader and format up front and answers become more consistent. One line is enough: "As the account rep, write a thank-you email to Client B's director proposing next meeting dates, under 120 words." Include the source material to reduce made-up details (hallucinations).

Connecting a connector

Go to Customize → Connectors → "+" in the sidebar, pick something like Google Calendar, and allow access (menu names may change).

Even when connected, you still ask Claude to go read it every time. SIMY picks up work from meetings and chat, so nothing waits on you asking.

Asking for slide decks

In side-by-side tests, Claude tends to produce calm, well-designed slides. Give the goal, audience, slide count and tone in one sentence.

Example: "Five slides for next week's Client B sync, updating their director on this month's progress. Calm tone, numbers in tables."

Still, you're the one asking for the deck each time. SIMY picks up "make the deck" from the meeting, drafts it your way, and comes back only for review.

Claude Code, Cowork, and API pricing

Claude Code and Cowork are included in Pro and Max at no extra monthly cost. Usage is shared across the plan, though, so long Claude Code sessions use it up faster. Max widens that allowance several times over. The API that developers call from code is billed separately by usage, with different rates per model. If your company plans to use the API, estimate monthly volume first.

Free plan limits

The free plan caps how many messages you can send in a given period, and limits come sooner at busy times. If you have Claude read long files repeatedly, you may hit the cap before lunch. For daily work use, Pro is the realistic minimum.

SIMY is priced separately from your Claude plan. See the pricing page for SIMY itself. The Codex usage behind SIMY's cloud runs comes out of your ChatGPT plan. Think of it not as upgrading Claude, but as a separate line item for cutting the work after the answer.

For beginners: Claude Code can edit and delete files. Start in a dedicated folder and keep the setting that asks for confirmation. If you're not an engineer, try Cowork first.

Using Cowork (for non-engineers)

Cowork is a desktop feature Anthropic released in 2026, and it spread quickly among non-engineers as the way to hand work to AI. Chat answers when you ask; Cowork does the work when you ask. It's often compared with Copilot's similar feature, and both focus on local files and scheduled tasks.

Open Cowork in the desktop app, pick a folder it may work in, and ask in plain language, such as "make a list from this folder of invoices." Cowork reads the files, uses the browser if needed, and saves the result to the folder. Weekly work can be set as a scheduled task that runs the same instruction at a set time. It needs a paid plan and the desktop app, and as of October 2026 runs on Mac and Windows.

Using Claude Code (first steps)

Start Claude Code in a terminal, point it at a working folder and ask, for example, "total this CSV by month." It asks before editing files or running commands, so read and then approve. More non-engineers now use it to automate expense entry or daily reports, but avoid settings that skip confirmation at first.

Cowork and SIMY don't compete. Cowork clears your desk; SIMY picks up the follow-up work born in meetings and chat. SIMY learns repeat steps from your Claude Code chats and runs the same WorkFlow with either Codex (ChatGPT) or Claude Code. For more on Cowork, see the Claude Cowork guide.

Example: automating expense entry

  1. Export card transactions to a spreadsheet.
  2. Claude Code sorts them into expense, excluded, or unsure.
  3. A person checks only the "unsure" ones.
  4. The confirmed items go into your accounting software.

In the example shared, two hours a month dropped to about ten minutes (just one case). "Send back only what can't be decided" is the same shape as SIMY's "return only decisions." SIMY extends the starting point to meetings and chat.

Training opt-out and securityClaude's settings, and what SIMY commits to

On Claude's side

  • Opting out of training: on personal plans (Free, Pro, Max), the privacy settings let you choose whether your chats help improve models. Check this before using it for work.
  • Team, Enterprise, API: by default, your data is not used to train models under these contracts. For confidential material or contracts, this is the standard choice.
  • Claude Code permissions: it can read and write files and run commands, so use a separate working folder and keep confirmations on.
  • Confidential data and contracts: before adding material with client names or prices, check your company's data rules and your plan's terms. As a rule, don't handle company secrets in a personal account.
  • Guarding against hallucinations: include the source material, and check numbers and names against it before use. Reviewing before sending is a human job on every plan.

On SIMY's side

  • Chat text isn't stored: Claude Code and Codex chat history is used only during analysis. SIMY keeps only abstracted steps, checks and completion criteria.
  • Range and opt-out: history reading covers 90 days by default and can be turned off in settings. Turning it off also deletes the derived data.
  • Writing outside needs approval: Gmail stops at saving drafts. Posting to Slack and writing to Notion wait for your approval.
  • Delivery Loop hooks: the Claude Code plugin does not upload chats, tokens or prompts.
  • Desktop app sessions: SIMY desktop app logins expire after 48 hours and need a fresh login. Deleting your account also deletes your personal workspace.

For details, see Security, the Privacy Policy and the Terms of Service.

09 / FAQ

Frequently asked questions

Who makes Claude, and where can I use it?

Claude is made by Anthropic, based in San Francisco. You can use it on the web, in desktop and mobile apps, and through a browser extension.

How much work can I do on Claude's free plan?

Writing, summarizing, asking about attached files and building documents with Artifacts all work on the free plan. Usage is capped, and limits come sooner at busy times. Claude Code and Cowork need a paid plan.

How do I choose between Opus, Sonnet, Haiku and Fable?

As a rule of thumb: Sonnet for daily work, Opus for hard judgment calls and long documents, Haiku for fast short routine tasks, and Fable when you need the latest all-round strength. If unsure, start with the default and move up only when the answers fall short.

What is Claude Cowork, and how is it different from Claude Code?

Cowork lets you hand off work inside the desktop app using your local files and a browser, and it's good at desk tasks and scheduled tasks. Claude Code works from the terminal, running commands and editing files on your computer. Both need a paid plan.

Is Claude Code safe for non-engineers?

Yes, but it can edit and delete files, so start in a dedicated folder with confirmations turned on. When it runs work for SIMY, anything sent or posted outside still needs your approval.

ChatGPT or Claude: which is better for work?

A common split is Claude for reading and writing long documents, and ChatGPT if you want image generation and broad integrations in one tool. Whichever you use, SIMY handles the work left after the answer the same way.

Can I stop Claude from training on what I enter?

Yes. On personal plans you choose in the privacy settings whether your data helps improve models; for company use, consider Team or Enterprise. SIMY uses Claude Code chat text only during analysis and does not store it on its servers.

Do I need a paid Claude plan to use SIMY?

Not for SIMY itself. With the SIMY desktop app, you can bring your Claude Code chats into SIMY and run Claude Code from SIMY. That uses your existing Claude Code login and plan. The only thing you can't do is use your Claude tokens (your plan's usage) for SIMY's cloud runs. Cloud runs use your ChatGPT account (Codex), and Gemini token support is in development.

Does my work stop when Claude is down or I hit the usage limit?

No. SIMY can run work with both Codex (ChatGPT) and Claude Code on your computer, so when one isn't available it continues with the other. Usage on each counts against its own plan.

How is Claude Cowork different from SIMY? Can I use both?

Cowork runs the work you assign at your desk, plus scheduled tasks, inside Claude. SIMY picks up work born in meetings and chat before you ask, does it your way, and returns only decisions. You can use both, and SIMY takes over from what Cowork finishes.

What gets sent before my Claude Code chats become "Suggestions from SIMY"?

The SIMY desktop app reads 90 days of Claude Code and Codex chat history on your computer by default, then abstracts the steps and checks you repeat into WorkFlow candidates. Chat text is used only during analysis and is not kept on our servers. You can turn this off in settings at any time.

I share and log Claude drafts the same way every week. Can that be automated?

Yes. SIMY learns that routine from your conversations and suggests it as a WorkFlow. Once approved, it runs automatically from meetings and chat; Gmail stops at drafts, and Slack or Notion writes wait for your approval.
