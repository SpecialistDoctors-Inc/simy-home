01 / REFERENCE

GPTs・設定・料金・Work と Codex・セキュリティ（詳しく知りたい人向け）

ここから下は、ChatGPT 本体のことを確かめたいときに開いてください。SIMY との接続には、どれも影響しません。

GPTs・プロジェクト・カスタム指示：毎回頼まないための工夫と、その限界ChatGPT の中でできること、できないこと

ChatGPT の中で「毎回書かない」ための3つの工夫

  • カスタム指示：職種、業界、よく作る文書、避けたい言い回しを設定しておくと、毎回のプロンプトが短くなります。「メールは敬体で、結論から」「金額は税込で併記」のような、あなたが良い仕事で守っている基準を書きます。
  • プロジェクト：顧客や案件ごとにプロジェクトを作り、資料と会話をまとめておくと、Chat も Work も同じ前提で動けます。
  • GPTs（カスタム GPT）：「議事録を、うちの型に直す GPT」のように、1つのタスクの型を固めて保存します。GPT ストアで公開されている GPTs は無料プランでも使えますが、作成できるのは Plus 以上です。ワークスペースの中だけで共有する社内限定の GPTs は、Team や Business 以上で作れます（2026年10月時点）。

GPTs の作り方：4ステップ

  1. 「GPT を作成」を開く。作成は Plus 以上の有料プランで、無料プランは使うだけです（2026年10月時点）。
  2. 指示・知識ファイル・会話のきっかけ・機能を設定する。指示文は ChatGPT に「こういう GPT の指示を書いて」と下書きさせてかまいません。
  3. 公開範囲を選ぶ。自分だけ、リンクを知っている人、社内（Team・Business 以上のワークスペース）から選びます。
  4. 使う。例：自社資料を読ませた相談役、URL を渡すとニュースを要約する GPT。

それでも、GPT を開くのも、資料や URL を貼るのも、頼むのも毎回あなたです。会議とチャットから仕事を拾うところから、SIMY が引き受けます。

入力待ちプロンプト：無料プランでもできる工夫

最初に「これから送る箇条書きを、このルールで文章にして。わかったら『はい』と答えて」とルールを固め、あとはデータだけを送ります。

会話が長くなると最初の指示を忘れていくので、崩れてきたら新しいチャットで固め直します。

それでも、チャットを開いてルールを貼り直し、データを運ぶのは毎回あなたです。SIMY は、あなたのやり方を会話から学び、毎回の指示なしで進めます。

それでも残ること

GPTs は「1タスクの型」です。起点を決めるのはあなたで、文字起こしを貼るのも、できた文面を置き場所に運ぶのも、次の会議でまた同じ GPT を開くのもあなたです。長い会話では最初の指示が効かなくなり、新しいチャットでやり直すこともあります。

ChatGPT を仕事で使う前に整える5つの設定学習させない設定、カスタム指示、プロジェクト、メモリ、置き場所
  1. 「学習させない」設定を確認する 既定はオン
    設定 → データコントロール → 「すべての人のためにモデルを改善する」をオフにします。Free、Go、Plus、Pro の個人プランでは既定でオンになっているので、顧客名や金額を入力する前に確認します。Business と Enterprise の業務データは、既定では学習に使われません。
  2. カスタム指示に、あなたの基準を書く。職種、業界、よく作る文書、避けたい言い回し。「メールは敬体で、結論から」のように、あなたが良い仕事で守っている基準を書きます。
  3. プロジェクトで、案件ごとに分ける。顧客や案件ごとに資料と会話をまとめておくと、Chat も Work も同じ前提で動けます。
  4. メモリの範囲を決める。メモリを有効にすると過去の会話を踏まえて答えてくれますが、顧客名や金額まで覚えさせたくない場合もあります。プロジェクト単位に絞るか、オフにするかを最初に決めます。
  5. 回答の置き場所と、次の仕事の起点を決める。回答をコピーして終わりにせず、Notion、Google ドライブ、Slack のどこに置くかを決めます。置き場所が決まっていることが、SIMY と仕事をつなぐ入口になります。

頼み方の型：目的・相手・構成・制約

メールなどを頼むときは、4つを書いてから頼むと手直しが減ります。

例：「目的：打ち合わせ日程の再調整。相手：取引先の部長。構成：お詫び→候補日3つ→返信のお願い。制約：200字以内、敬体」。

それでも、型を書いて頼むのは毎回あなたです。SIMY は会議とチャットから「誰に、何を送るか」を拾い、あなたの型で下書きまで進めます。

ChatGPT Work の使い方

ChatGPT Work は、2026年7月9日に公開された、長く込み入った作業のためのエージェントです。連携したアプリとファイルを横断して調査・分析し、資料、スプレッドシート、プレゼン、レポート、Sites を仕上げます。以前の「エージェントモード」で始まった、ChatGPT が自分で作業を進める流れは、いまは Work が担っています。

  1. モードを Work に切り替える。デスクトップアプリでは左上のメニューから、Web とモバイルではドロップダウンから選びます。デスクトップアプリは macOS と Windows で使えます。
  2. 実行場所を選ぶ。PC の中のファイルやアプリを使わせたいときは「Work locally」をオンに。PC を閉じても続けたいときはクラウドで実行します。
  3. プラグインをつなぐ。Slack、Google Drive、メール、カレンダーなどはプラグインで接続します。以前の App Directory は Plugin Directory に置き換わりました。
  4. 指示に「止める条件」まで書く。「見積もりの金額を入れる前に止めて、確認を求める」のように、承認してほしい地点を先に決めておくと、やり直しが減ります。
  5. 計画を確認して、承認する。Work は作業計画を示してから動きます。途中の質問に答え、重要な操作は承認します。

Scheduled Tasks と利用枠

Work は、1回限りの実行、毎週月曜9時のような繰り返し、変更の監視を予約できます。2026年8月以降は、対応するプラグインの MCP イベントで自動化を始められるようになりました。Work と Codex は同じ利用枠を使い、5時間ごとの上限があります。Pro は Plus の5倍、Business のプレミアムシートには5時間ごとの上限がありません。Work 自体に追加料金はありません。

SIMY との関係：Work と Codex は「頼まれた1件を仕上げる実行役」、SIMY は「会議やチャットから仕事を拾い、実行役を動かし、判断だけ返す管理役」です。SIMY は Codex を実行役として使うので、置き換えではなく重ねて使います。

セキュリティ・情報漏洩対策と社内ガイドライン学習設定、共有リンク、プラグインの権限、SIMY 側の考え方
  • 学習に使われるか：Business と Enterprise の業務データは、既定ではモデルの学習に使われません。個人プランは既定でオンなので、設定 → データコントロールで「すべての人のためにモデルを改善する」をオフにします。
  • 情報漏洩の主な経路：会話の共有リンク、学習設定の放置、プラグインに与えた権限、ローカル実行で許可したファイルの範囲。この4つを最初に決めておきます。
  • Work の権限：Work Cloud、Work Local、Codex Local は個別に設定できます。法人プランでは、ワークスペースの管理者の方針に従ってください。
  • ガイドラインに入れる5項目：入力してよい情報の区分、学習設定、共有リンクの扱い、プラグインとローカル実行の許可範囲、成果物を確認する責任者。
  • SIMY 側の考え方：Gmail は下書き保存まで。Slack への投稿と Notion への書き込みは承認付きです。PC 上の会話履歴から提案を作るときも、会話の本文はサーバーに保存しません。詳細はセキュリティとプライバシーポリシーで公開しています。
02 / AFTER THE ANSWER

ChatGPT のあと、こうなっていませんか

答えは返ってきた。それでも、ChatGPT のタブを閉じたあとに起きていること。

1 答えが出た直後 コピペして戻る

回答をコピーして、メール、Notion、Slack に貼りに行く。置き場所は毎回自分で。

2 次の案件で 毎回、同じ前置き

「うちの型で」「敬体で、結論から」。指示とデータを、新しいチャットにもう一度。

3 送る前に 結局、自分で直す

ざっくりした文面を自分の言い回しに直す。決めて、選んで、確認するのは自分だけ。

聞けば答える。頼めば作る。でも「頼む」も「戻る」も、まだあなたの仕事です。

09 / FAQ

よくある質問

ChatGPT に同じ指示を毎回書かないようにする方法はありますか？

ChatGPT の中では、カスタム指示、プロジェクト、GPTs の3つが「毎回書かない」ための工夫です。ただし、どれも始めるのはあなたで、頼んだ1件の回答が返ってくるところで終わります。会議やチャットから仕事を拾い、あなたのやり方で進めて判断だけ返すのが SIMY で、ChatGPT の工夫と置き換えではなく重ねて使います。

ChatGPT に入力した内容を学習に使わせない設定（学習オフ）の手順は？

設定を開き、「データコントロール」で「すべての人のためにモデルを改善する」をオフにします。個人向けプラン（Free・Go・Plus・Pro）では既定でオンなので、顧客名や金額を入力する前に確認してください。Business と Enterprise の業務データは、既定では学習に使われません。

無料プランで GPTs は使えますか？作れますか？

無料プランでも GPT ストアにある GPTs を使うことはできますが、自分で GPTs を作成できるのは Plus 以上の有料プランです（2026年10月時点）。

社内限定の GPTs を作るには、どのプランが必要ですか？

ワークスペースの中だけで共有する GPTs は、Team や Business 以上の法人向けプランで作れます。個人プランで作った GPTs は、リンクを知っている人か全体への公開になります。

ChatGPT の Go と Plus、どちらを選べばいいですか？

2026年10月3日確認：Free・GoにもデスクトップアプリでGPT-6 Lunaを標準速度で使える枠があり、順次提供中です。Plus以上とは利用環境・モデル・上限が異なります。APIキー利用は別料金です。SIMYのクラウド連携条件とは分けて確認してください。

ChatGPT Work とは何ですか？

2026年7月9日に OpenAI が公開した、長く込み入った作業のためのエージェントです。連携したアプリとファイルを横断して調査・分析し、資料、スプレッドシート、プレゼン、レポート、Sites を仕上げます。Scheduled Tasks で1回限り・繰り返し・変更の監視といった実行もできます。

ChatGPT Work と Codex の違いは何ですか？

Work は調査、分析、資料やレポートの作成など仕事全般の成果物を仕上げるエージェントで、Codex はソフトウェア開発のためのエージェントです。同じ実行・権限の仕組みと利用枠を共有していて、GPT-6 Sol と Luna は Work と Codex 専用のモデルです。

ChatGPT Work と SIMY の違いは何ですか？

Work は、あなたが指示した1件を最後まで仕上げる実行役です。SIMY は、会議や Slack の会話から仕事を拾い、あなたのやり方で進めて、判断だけを返す管理役です。SIMY はお使いの ChatGPT アカウントの Codex を実行役に使うので、置き換えではなく重ねて使います。

ChatGPT Business は1人でも使えますか？

Business は従業員2〜200名のチーム向けのプランで、管理コンソール、SAML／SSO、業務データが既定では学習に使われない設定が最初から含まれます。1人で使う場合は Plus か Pro が基本で、学習に使わせない設定は個人プランでも行えます。

SIMY を使うと、AI の利用料が別にかかりますか？

SIMY はお使いの ChatGPT アカウントをつなぎ、Codex App Server 経由で仕事を進めます。Codex の利用は、お使いの ChatGPT プランの範囲で行われます。SIMY 自体の料金は料金ページをご覧ください。

ChatGPT 以外の AI でも SIMY を使えますか？

クラウドでの実行は、お使いの ChatGPT アカウント（Codex）で行います。PC 上では、SIMY のデスクトップアプリや CLI が、Codex のほかに Claude Code も実行役にできます。どちらかが不調なときや利用枠の上限に当たったときの備えになります。

ChatGPT で Excel の関数やマクロ（VBA・GAS）を作れますか？

作れます。やりたいことを日本語で書くと数式やコードが返ってくるので、Excel や Apps Script に貼って実行します。社外秘のデータは貼らず、学習に使わせない設定も確認してください。毎回 ChatGPT に頼んでいる定型の仕事は、SIMY が会議とチャットから拾って進めます。
