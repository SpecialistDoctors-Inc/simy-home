01 / REFERENCE

Claudeの使い方・料金・モデル・Cowork（詳しく知りたい人向け）

ここから下は、Claude本体のことを確かめたいときに開いてください。SIMYとの接続には、どれも影響しません。

Claude（クロード）とは：読み方・開発元・できること文章・長文要約・Excel・PDF・コード・リサーチ

読み方と開発元

Claudeは「クロード」と読みます。開発元は米国サンフランシスコのAnthropic（アンソロピック）で、OpenAIの元メンバーが2021年に設立したAI企業です。Web（claude.ai）、Mac／Windowsのデスクトップアプリ、iOS／Androidアプリ、Chrome拡張から、日本語でそのまま使えます。

どこの国のサービスで、日本語はどこまで通じるか

Anthropicは米国の会社で、Claudeは米国のサーバーで動くクラウドサービスです。日本語は入力も出力も自然で、敬語の使い分けや「です・ます」調の統一など、ビジネス文書に求められる言い回しに強いと評価されることが多いです。日本語の文字起こしを渡して議事録にする、英語の資料を日本語で要約する、といった使い方は無料版からできます。会社として導入する場合は、データの保存場所と契約条件をTeam・Enterpriseの資料で確認してください。

仕事でできること

  • 文章の作成と推敲：メール、提案書、報告書の下書き。丁寧で読みやすい日本語が得意です。
  • 長文の要約と読み込み：長い契約書や会議の文字起こしを一度に渡し、要点や決定事項を抜き出せます。
  • ファイルを渡す：PDF、Excel、Word、画像を添えて質問できます。表の読み取りや数値の整理にも使えます。
  • Artifacts：資料、図、簡単なアプリを画面右側に作り、そのまま編集して持ち出せます。
  • プロジェクトとコネクタ：指示と資料をプロジェクトに保存して繰り返し使い、Google DriveやSlackなどの外部ツールをコネクタでつないで参照できます。
  • コードと自動化：Claude Codeがターミナルからファイル操作やコマンド実行を行い、Coworkがデスクトップで仕事を任せる入口になります（下の項目で比較）。

どの機能も「頼めばやってくれる」ものです。頼む前に始まる、という部分だけが、Claudeの外側に残っています。

Claudeの使い方：仕事で最初にやる5つのことアプリ・プロジェクト・コネクタ・モデル・成果物の置き場所
  1. アプリを入れて、日本語で話しかける。Webのclaude.aiで足りますが、デスクトップアプリを入れるとショートカットで呼び出せ、Coworkもここから使います。スマートフォンアプリは移動中の確認に、Chrome拡張は開いているページをそのまま読ませるときに向いています。
  2. プロジェクトに、指示と資料をまとめる。「議事録はこの型で」「返信はこの口調で」という毎回の前置きと、参照してほしい資料をプロジェクトに入れておくと、新しいチャットでも同じ前提から始まります。社内の用語集や過去の提案書を入れておく人が多いです。
  3. コネクタで、見てほしい場所をつなぐ。Google DriveやGmail、Slack、Notionなどをコネクタで接続すると、ファイルを貼らずに「先週のB社の議事録を読んで」と頼めます。接続は会社の管理者の方針に従ってください。
  4. モデルは既定のまま、困ったら上位へ。日常の作業は既定のモデルで十分です。長い契約書の読み比べや重要な提案書だけ、Opusに切り替えます。
  5. 成果物の置き場所を決める。Claudeの回答はチャットの中に残ります。メールはGmailの下書きへ、議事録はNotionへ、共有はSlackへ、と置き場所を決めておくと、あとから探さずに済みます。SIMYは、この「置き場所に運ぶ」部分を引き受けます。

プロンプトのコツ

役割・目的・読み手・形式の4つを先に書くと、回答の精度が安定します。「営業担当として、B社の部長宛てに、お礼と次回の日程調整を、300字以内のメールで」のように、1文にまとめて渡すだけで十分です。元の資料も一緒に渡すと、作り話（ハルシネーション）が減ります。

コネクタの接続手順

左の「カスタマイズ」→「コネクタ」→「＋」→ Googleカレンダーなどを選んで許可します（画面の名前は変わることがあります）。

つないでも、読みに行くよう頼むのは毎回あなたです。SIMYは会議とチャットから仕事を拾うので、頼む一言から始まりません。

スライド資料の頼み方

使い比べでは、Claudeはデザインが落ち着いた資料が得意という結果が出ています。目的・相手・枚数・トーンを1文で渡します。

例：「来週のB社定例で、先方の部長に今月の進捗を伝える資料を5枚で。落ち着いたトーンで、数字は表に」

それでも、資料を頼むのは毎回あなたです。SIMYは会議で決まった「資料を作る」を拾い、あなたの型で下書きして、確認だけ返します。

Claude CodeとCoworkの料金、APIの料金

Claude CodeとCoworkは、ProまたはMaxに含まれ、追加の月額はかかりません。ただし利用枠はプランで共有され、Claude Codeを長時間回すと上限に早く達します。Maxは、その枠をProの数倍から数十倍に広げたプランです。開発者がプログラムから呼ぶAPIは、プランとは別の従量課金で、モデルごとに単価が違います。会社としてAPIを使うなら、月の利用量を見積もってから選んでください。

無料版の制限

無料版は、一定時間あたりの利用回数に上限があり、混雑する時間帯は上限が早く来ます。長いファイルを何度も読ませる使い方だと、午前中に上限に当たることもあります。仕事で毎日使うなら、Proが現実的な最低ラインです。

SIMYの料金は、Claudeのプランとは別です。SIMY自体の料金は料金ページをご覧ください。SIMYのクラウド実行に使うCodexの利用は、お使いのChatGPTプランの範囲で行われます。つまり「Claudeのプランを上げる」のではなく「回答のあとの作業を減らす」ための出費として、別枠で考えるのが分かりやすいです。

Coworkの使い方（非エンジニア向け）

Coworkは、Anthropicが2026年に公開したデスクトップ向けの機能で、「AIに仕事を任せる」入口として非エンジニアの間で急速に広まりました。チャットが「聞けば答える」相手だったのに対し、Coworkは「頼めば手を動かす」相手です。Copilotの同種の機能と比較されることも多く、どちらもPC内のファイルと定期タスクが中心です。

デスクトップアプリでCoworkを開き、作業してよいフォルダを選び、「この請求書のフォルダから一覧表を作って」のように日本語で頼みます。Coworkはファイルを読み、必要ならブラウザを操作し、結果をフォルダに保存します。毎週同じ作業なら定期タスクとして登録でき、指定した時刻に同じ指示が走ります。有料プランとデスクトップアプリが必要で、2026年10月時点ではMacとWindowsで使えます。

Claude Codeの使い方（最初の一歩）

ターミナルでClaude Codeを起動し、作業フォルダを指定して「このCSVを月別に集計して」と頼みます。ファイルの書き換えやコマンド実行の前に確認が入るので、内容を読んでから許可してください。freeeなどの経費登録や日次レポートの自動化に使う非エンジニアの実例も増えていますが、権限を広げる設定（確認をスキップする設定）は最初は使わないのが安全です。

CoworkとSIMYは競合しません。Coworkで机の上の仕事を片づけ、会議やチャットで生まれる「そのあとの仕事」はSIMYが拾います。SIMYは、Claude Codeの会話から繰り返しの手順を学び、Codex（ChatGPT）とClaude Codeのどちらでも同じWorkFlowを実行します。Coworkの詳しい使い方はClaude Cowork活用ガイドにまとめています。

例：freeeへの経費登録を自動化する

  1. カード明細をスプレッドシートに書き出す。
  2. Claude Codeが「経費／除外／判断できない」の3つに分ける。
  3. 「判断できない」ものだけ、本人が確認する。
  4. 確定した分をfreeeへ登録する。

紹介された例では月2時間が約10分になっていました（あくまで一例です）。「判断できないものだけ人に戻す」は、SIMYの「判断だけ返す」と同じ形です。SIMYはその起点を、会議とチャットに広げます。

スキルを作る：毎回の説明を省く手順書

最初に作ると便利なのは、音声入力を自然な日本語に整える「日本語スキル」、フィードバックを残す「メモスキル」、資料の「デザインスキル」です。

  1. やり方を一度、Claudeの前でやってみせる。
  2. その流れを手順書（スキル）として保存させる。
  3. 次からは名前で呼び出す。

説明は省けても、呼び出すのは毎回あなたです。SIMYは会議とチャットから、呼ぶ前に仕事を拾います。

CLAUDE.mdに、やり方を残す

  • CLAUDE.md：毎回守ってほしいルール。
  • progress.md：作業の進み具合。
  • 別ファイル：その他の知識や資料。

書いて保存する手間は、あなたに残ります。SIMYは書かなくても会話からやり方を学びます（SIMYデスクトップアプリがClaude Codeの会話を取り込みます）。

学習させない設定とセキュリティClaude側の設定と、SIMY側で約束していること

Claude側

  • 学習させない設定：個人向けプラン（Free・Pro・Max）では、設定のプライバシー項目で、会話をモデル改善に使うかどうかを自分で選べます。会社で使う前に一度確認してください。
  • Team・Enterprise・API：入力したデータを既定でモデルの学習に使わない契約です。機密情報や契約書を扱うなら、こちらを選ぶのが基本です。
  • Claude Codeの権限：ファイルの読み書きとコマンド実行ができるため、作業フォルダを分け、確認を求める設定のまま使ってください。
  • 機密情報と契約書：顧客名や金額を含む資料を入れる前に、会社の情報管理ルールと、使っているプランの契約条件を確認してください。個人のアカウントで会社の機密を扱わない、が基本です。
  • 作り話（ハルシネーション）への備え：元の資料を一緒に渡し、数字と固有名詞は元資料と突き合わせてから使ってください。送る前の確認は、どのプランでも人の仕事です。

SIMY側

  • 会話本文は保存しない：Claude CodeとCodexの会話履歴は解析中だけ使い、SIMYが持つのは抽象的な手順・確認事項・完了条件だけです。
  • 期間と停止：履歴の読み取りは既定90日分で、設定で止められます。止めると派生データも削除されます。
  • 外部への書き込みは承認制：Gmailは下書き保存まで。Slackへの投稿、Notionへの書き込みは、あなたの承認を待ちます。
  • Delivery Loopのフック：Claude Code側のプラグインは、会話・トークン・プロンプトをアップロードしません。
  • CLIのセッション：SIMYデスクトップアプリのログインは48時間で失効し、再ログインが必要になります。アカウントを削除すると、個人のワークスペースも削除されます。

詳しくはセキュリティとプライバシーポリシー、利用規約をご覧ください。

02 / EVERY TIME

Claudeを使っていて、こうなっていませんか

回答の質に不満はない。それでも、Claudeを閉じたあとに起きていること。

1 会議のあと プロジェクトに保存したのに

議事録の型はプロジェクトに入れた。でも、文字起こしを貼るのは毎回自分。

2 回答を読んだあと コネクタで読ませたのに

GmailもDriveもつないだ。でも「返信を書いて」と頼むのは、やっぱり自分。

3 翌日 判断がチャットに埋もれる

「この金額でいいか」の確認が長い回答の途中にある。どのチャットだったかを探す。

回答はClaudeが一瞬で出す。頼むこと、貼ること、共有すること、判断を探すことは、あなたに残っています。

03 / WHAT YOU REALLY WANTED

本当は、こうしたかった：Claudeの回答のあと

同じClaude。同じ会議。会議室を出たときに、こうなっていてほしかった。

✓ 頼む前に 言う前に動いている

会議が終わった時点で、返信の下書きと顧客メモの更新案がもう届いている。

✓ 指示しなくても あなたの型で、毎回

議事録の粒度、返信の文面の癖、共有先。保存した指示を呼び出さなくても、いつもの形。

✓ 週に1回 提案が届く

「この手順、毎週やっていますね」。繰り返している仕事が、WorkFlowの候補として届く。

! あなたに戻るのは 判断だけ

09 / FAQ

よくある質問

Claudeの読み方と、開発元はどこの会社ですか？

読み方は「クロード」です。開発元は米国サンフランシスコのAnthropic（アンソロピック）で、Web、デスクトップアプリ、スマートフォンアプリ、ブラウザ拡張から日本語で使えます。

Claudeの無料版では、どこまで仕事に使えますか？

文章の作成や要約、ファイルを添えた質問、Artifactsでの資料づくりは無料版でも使えます。利用回数に上限があり、混雑時は制限が早く来ます。Claude CodeやCoworkは有料プランが必要です。

Opus・Sonnet・Haiku・Fableは、どう選べばいいですか？

日常の仕事はSonnet、難しい判断や長い資料の読み込みはOpus、短い定型処理を速く回したいときはHaiku、最新の総合力が必要ならFableが目安です。迷ったら既定のモデルで始め、回答に不満が出たときだけ上位に切り替えてください。

Claude Coworkとは何ですか？Claude Codeとは何が違いますか？

Coworkは、デスクトップアプリの中でPC内のファイルやブラウザを使って仕事を任せる機能で、机の上の指示と定期タスクが得意です。Claude Codeは、ターミナルからPC上でコマンドやファイル操作を実行する実行役です。どちらも有料プランで使えます。

Claude Codeは、非エンジニアでも安全に使えますか？

使えますが、ファイルを書き換えたり削除したりできる権限を持つため、最初は専用のフォルダで、確認を求める設定のまま使ってください。SIMYの実行役として使う場合も、外部への送信や投稿はあなたの承認が必要です。

ChatGPTとClaude、仕事で使うならどっちがいいですか？

長い文書を読んで書く仕事はClaude、画像生成や幅広い連携を含めて1つで済ませたいならChatGPT、という選び方が一般的です。SIMYはどちらを使っていても、回答のあとに残る仕事を同じやり方で進めます。

入力した内容をClaudeに学習させない設定はありますか？

あります。個人向けプランでは設定のプライバシー項目でモデル改善への利用を自分で選べ、会社で使うならTeamやEnterpriseを検討してください。SIMYは、Claude Codeの会話本文を解析中だけ使い、サーバーに保存しません。

SIMYを使うには、Claudeの有料プランが必要ですか？

SIMYだけなら不要です。SIMYデスクトップアプリを入れると、Claude Codeの会話をSIMYに取り込み、SIMYからClaude Codeを動かせます。このときは、あなたのClaude Codeのログインとプランがそのまま使われます。できないのは、Claudeのトークン（プランの利用枠）をSIMYのクラウド実行に連携することだけです。クラウド実行はお使いのChatGPTアカウント（Codex）で動き、Geminiのトークン連携は開発中です。

Claudeが不調なときや利用上限に達したとき、仕事は止まりますか？

止まりません。SIMYはCodex（ChatGPT）とPC上のClaude Codeの両方を実行役にできるため、片方が使えないときはもう片方で進められます。どちらの利用量も、それぞれのプランの範囲で計上されます。

Claude CoworkとSIMYは、何が違いますか？併用できますか？

Coworkは、あなたが机の上で指示した仕事と定期タスクをClaudeの中で進めます。SIMYは、会議やチャットで生まれた仕事を頼まれる前に拾い、あなたのやり方で進めて判断だけ返します。併用でき、Coworkで仕上げた成果物の先をSIMYが受け持ちます。

Claude Codeの会話が「SIMYからの提案」になるまで、何が送られますか？

SIMYデスクトップアプリが、PC内のClaude CodeとCodexの会話履歴を既定で90日分読み、繰り返している手順と確認事項を抽象化してWorkFlow候補を作ります。会話本文は解析中だけ使い、サーバーには残りません。この取り込みは設定でいつでも止められます。

Claudeで作った下書きを、毎週同じ手順で共有・記録しています。自動化できますか？

できます。SIMYが会話からその手順を学び、WorkFlowとして提案します。承認すると、次回からは会議やチャットを起点に自動で進み、Gmailは下書き保存まで、SlackやNotionへの書き込みはあなたの承認を待ちます。
