01 / AFTER THE TASK

タスクのあと、こうなっていませんか

Cowork は、指示したとおりに終えてくれる。それでも、タスクが完了した次の日に起きていること。

1 完了の直後 フォルダ整理は、できた

営業資料は片付いた。でも、会議で決まった宿題は誰も拾っていない。

2 翌週の月曜 スケジュールは、組んだ

毎週のレポートは定期実行。ただし、何を組むかは毎回自分で設計する。

3 会社の方針で Copilot しか使えない会社

Cowork は試せない。それでも会議の宿題は、毎週生まれる。

Cowork は、あなたが指示した仕事を終わらせる。会議とチャットで生まれた仕事は、誰も指示していません。

08 / REFERENCE

Claude Cowork の使い方・料金・安全性・比較（詳しく知りたい人向け）

ここから下は、Cowork 本体のことを確かめたいときに開いてください。SIMY の使い方には、どれも影響しません。

Claude Cowork とは：非エンジニア向けに、ひとことでチャットとの違い、2026年の統合、できることの要点

ひとことで言うと

Claude Cowork（クロード・コワーク）は、Anthropic が提供する作業代行のエージェントです。チャットの Claude は「質問に答える」のが仕事でしたが、Cowork は「目的を伝えると、あなたが選んだフォルダやツールの中で作業し、仕上がりをレビューに戻す」のが仕事です。コードを書く人のための Claude Code とは別に、資料・表・フォルダを相手にする一般の業務向けに作られています。

チャットの Claude と何が違うか

チャットは、回答をコピーしてファイルに貼る作業があなたに残ります。Cowork は、ファイルを直接開いて書き、終わったら「できました」と報告します。どのファイルを開き、どのツールを使い、何を選んだかが手順として見えるので、途中で止めたり、やり直させたりできます。

2026年のチャット統合について

Anthropic の公式ページは、2026年10月1日時点で「Claude Cowork is now just Claude」として、Cowork をチャットと別のメニューではなく Claude 本体の機能として、Pro・Max から順次提供すると案内しています。2026年9月に始まったこの統合は進行中のため、メニューの位置や名称は変わる可能性があります。最新は公式の案内で確認してください。

できることの要点

  • PC 内の指定フォルダのファイルを読み、作成・編集する
  • 専用ブラウザを開いて調べ、フォームに入力する（あなたのブラウザとは別）
  • 必要なときだけ画面を操作する（Computer Use）
  • 毎日・毎週・毎月のスケジュールで、同じ仕事を実行する
  • 大きな仕事を分けて、並行して進める
  • スキル・コネクタ・プラグインで、あなたの業務に合わせる

公式が示している使い方の例

Anthropic の製品ページには、非エンジニアの仕事を想定した例が並んでいます。毎週月曜の朝に先週のマーケティング数値を集めて比較し、資料にまとめて Drive に保存するレポート。月次決算のフォルダから各地域の書き出しを1つの表に集計し、予算との差が大きい行に印をつける集計。契約書フォルダを自社の方針書と照らし、条項番号つきのメモを契約ごとに書く一次レビュー。四半期分の商談メモを読み、案件ごとの状況と繰り返し出てくる反対意見をまとめる読み返し。どれも「フォルダを指して、目的を伝える」形で、仕上がりがレビュー待ちとして戻ってきます。

この記事での呼び分け

チャットの Claude、作業代行の Cowork、コード向けの Claude Code は、同じ Claude のモデルを使う3つの入口です。この記事では、机の上の仕事を終わらせる機能を Cowork、会議とチャットで生まれた仕事を拾って回す側を SIMY と呼び分けます。Claude そのものの使い方は、別のガイドで扱います。

始め方：デスクトップアプリから、最初の1タスクインストール、フォルダの選び方、最初に任せる仕事
  1. Claude デスクトップアプリを入れる。macOS と Windows（arm64 を含む）、ChromeOS、Linux 向けのダウンロードが公式に用意されています（2026年10月1日時点）。Web とモバイルでも順次提供中で、モバイルはベータです。Windows での対応範囲や機能の差は、最新の公式ページで確認してください。
  2. 有料プランでログインする。Cowork は有料プラン向けの機能です。詳しくは次の「料金・対応環境」へ。
  3. Cowork を開き、フォルダを選ぶ。Claude が触れるのは、ここで選んだフォルダと接続したツールだけです。最初は「整理されていない資料フォルダ」のように、壊れても困らない範囲から。
  4. 「何を」だけ伝える。「このフォルダを提案書・見積・議事録に分けて、命名規則の手順書を作って」のように、手順ではなく目的を書きます。
  5. 手順を眺めて、仕上がりをレビューする。削除には、あなたの承認が必要です。

慣れたら、毎週の仕事をスケジュールに登録します。ノートパソコンを閉じていても実行され、戻ったときに結果が待っています。

最初の指示を書くコツ

  • 対象を1つのフォルダに絞る。「デスクトップ全部」ではなく「営業資料」のように、範囲が見える単位から。
  • 仕上がりの形を1行で書く。「提案書・見積・議事録・その他の4フォルダ」「表は地域ごとに1タブ」のように、受け取り方を決めておくとレビューが速くなります。
  • やってほしくないことを書く。「削除はしない」「社外に送らない」。承認の仕組みはありますが、指示に書いておくと安心です。
  • 報告を求める。「できなかったことと、判断が要ることを最後にまとめて」。この一文で、確認待ちが一覧になります。

プランの選び方の目安

個人で机の上の仕事を任せるなら Pro から。1日に何件も走らせる、長い作業を並行させるなら、利用上限の大きい Max が候補になります。チームで使い、誰がどのフォルダやツールに触れるかを管理したいなら Team、部門別の権限や利用額の上限、活動ログの外部連携まで必要なら Enterprise です。各プランの利用上限と金額は変わることがあるため、ここには書かず、公式の料金ページで確認してください。

SIMY との関係：SIMY だけなら Claude の有料プランは不要です。SIMY CLI を入れると Claude Code の会話を取り込み、SIMY から Claude Code を動かせます。Claude のトークンはクラウド実行に連携できず、クラウド実行はお使いの ChatGPT アカウント（Codex）で動きます。SIMY の料金は料金ページへ。

業務活用事例：スキル・コネクタ・プラグインで、何ができるか手順書の自動作成、フォルダの振り分け、Excel・PowerPoint

まず任せやすい4つ

  • フォルダの振り分け：溜まったファイルを種類ごとに分け、重複を候補として報告。削除は承認してから。
  • 手順書の自動作成：やってもらった作業の手順を、そのまま社内向けの手順書に。
  • Excel の集計：複数の書き出しファイルを1つの表にまとめ、差分が大きい行に印をつける。
  • PowerPoint の作成：毎週同じ構成の報告資料を、数字を入れ替えて定期的に。

そのまま使える指示の例

  • 「営業資料フォルダを、提案書・見積・議事録・その他に分けて。重複は削除せず一覧にして」
  • 「いま整理した手順を、新しく入った人向けの手順書として Word で書いて。保存先と命名規則を入れて」
  • 「経費フォルダの4つの CSV を1つの Excel にまとめて、前月比で10%以上動いた行に色をつけて」
  • 「毎週月曜 8:00 に、先週の数字を入れ替えた週次報告の PowerPoint を作って、報告フォルダに保存して」

スキル・コネクタ・プラグイン

スキルは「うちの報告書の書き方」のような業務知識を Claude に持たせる仕組み、コネクタは Microsoft 365 や Google Drive、Slack など既に使っているツールへの接続、プラグインはスキル・コネクタ・サブエージェントを1つにまとめた導入パッケージです。法務・財務・ブランドボイスなどのプラグインが公開されていて、Team・Enterprise では管理者が社内向けのマーケットプレイスを作れます。

どれも「あなたが指示した仕事を、より早く正確に終わらせる」ための仕組みです。会議で決まった宿題を誰かが拾う仕組みではありません。そこは、SIMY の仕事です。

議事録作成からレポート、メール対応まで：毎回同じ指示を繰り返す構造Cowork で回る仕事と、指示そのものが残る仕事

Cowork に議事録フォルダを渡して「決定事項と宿題を抜き出して」と頼めば、きれいに出てきます。週次レポートはスケジュールに乗り、メールの返信案も下書きまで作れます。ここまでは、Cowork が得意です。

残るのは構造です。会議が終わるたびに、文字起こしを保存し、Cowork を開き、同じ指示を打つのはあなたです。スケジュールにしても「どの会議の、どの宿題を、誰に」は毎回設計し直すことになります。メールを下書きで止めるのは、Codex でも Cowork でも同じ安心材料で、どれかの売りではありません。

SIMY は、この「指示する」工程をなくします。会議の記録やチャットから仕事を拾い、一度あなたの型で仕上げたやり方を学んで、次から同じ形で用意し、判断が要るところだけを My Actions に並べます。Cowork の仕上がりを受け取って次を回す、並べて使う前提です。

安全性：権限・フォルダの範囲・削除Cowork が触れる範囲と、あなたが握るもの
  • フォルダの範囲：Claude が触れるのは、あなたが選んだフォルダと接続したツールだけ。それ以外には届きません。
  • 削除：何かを削除するには、あなたの承認が必要です。
  • 事前確認：権限設定を有効にすると、重要な操作の前に計画を示して承認を待ちます。途中で止めたり、方向を変えたりできます。
  • 専用ブラウザ：Web の作業は Cowork 内の別のブラウザで行われ、あなたのブラウザのログインやタブとは分かれています。
  • Team・Enterprise：管理者がチーム別のアクセス、利用額の上限、部門別のツール権限を設定でき、活動ログを SIEM に流せます。

最初は壊れても困らないフォルダから。慣れるまでは、削除と送信は自分の手で。SIMY 側では、Gmail は下書き保存まで、Slack への投稿と Notion への書き込みは承認付きです。データの扱いはセキュリティとプライバシーポリシーで公開しています。

Claude Code との使い分け

Claude Code は、ターミナルやエディタからコードとリポジトリを扱うための入口で、エンジニア向けです。非エンジニアが資料・表・フォルダを相手にするなら Cowork で足ります。両方を使う人は、コードは Claude Code、机の上は Cowork、会議の宿題は SIMY と分けると迷いません。SIMY は Claude Code の会話履歴から繰り返している仕事を見つけて「SIMY からの提案」として出すので、Claude Code で手作業になっていた定型の仕事を、そのまま WorkFlow に変えられます。

Copilot Cowork を選ぶ会社でも

会社の方針で Microsoft 365 と Copilot に揃えている場合、Claude Cowork は試せないことがあります。それでも、会議で決まった宿題や、チャットで生まれた依頼は毎週生まれます。SIMY は Copilot の代わりではなく、会議とチャットから仕事を拾って回す側なので、Copilot Cowork と並べて使えます。SIMY の実行役はお使いの ChatGPT（Codex）か PC 上の Claude Code で、Copilot の契約とは別です。

選び方：会社が Microsoft 365 中心なら Copilot Cowork、PC のフォルダや複数のツールをまたぐなら Claude Cowork、コードなら Claude Code。どれを選んでも、会議で決まった宿題を拾うのは別の仕事で、そこに SIMY を重ねます。SIMY は Codex と Claude Code のどちらも実行役にできるので、一方の不調や利用上限への備えにもなります。Copilot Cowork の仕様は Microsoft の公式案内で確認してください。

09 / FAQ

よくある質問

Claude Cowork の読み方は？

「クロード・コワーク」と読みます。Cowork は co-work（一緒に働く）から来ていて、Anthropic が提供する Claude の作業代行エージェントの名前です。

Claude Cowork は無料で使えますか？

いいえ。2026年10月1日時点の公式案内では、Cowork は有料プラン向けの機能で、Pro・Max から順次提供されています。金額は Claude 公式の料金ページで確認してください。

Claude Cowork は Windows で使えますか？

2026年10月1日時点で、Claude 公式には Windows（arm64 を含む）向けのデスクトップアプリのダウンロードが用意されています。対応範囲や機能の差は、最新の公式ページで確認してください。

Claude Cowork はスマホで使えますか？

公式は、Cowork を Web とモバイルにも順次提供中（モバイルはベータ）と案内しています。デスクトップで始めた仕事を、スマホから確認したり指示を足したりする使い方が想定されています。

Claude Cowork はいつから使えますか？

2026年10月1日時点で、有料プランなら Claude デスクトップアプリから使えます。提供プランや環境は段階的に広がっているため、お使いのプランでの開始時期は公式のお知らせで確認してください。

Claude Cowork で何ができますか？

あなたが選んだフォルダのファイルを読み書きし、表や資料を作り、専用ブラウザで調べてフォームに入力し、必要なときだけ画面を操作します。毎日・毎週・毎月のスケジュール実行と、スキル・コネクタ・プラグインで業務に合わせる調整ができます。

Claude のチャットと Cowork は統合されたのですか？

公式は「Claude Cowork is now just Claude」として、Cowork を Claude 本体の機能として Pro・Max から順次提供すると案内しています（2026年10月1日時点）。統合は進行中のため、メニューの位置や名称は最新の公式で確認してください。

Cowork のスケジュール実行と SIMY の Autorun は何が違いますか？

起点が違います。Cowork のスケジュールは、あなたが設計した仕事を決めた時刻に繰り返し、SIMY の Autorun は、会議やチャットから拾った仕事をあなたの型で進めて判断だけを返します。定期実行そのものは、どちらにもあります。

Copilot Cowork との違いは？

Copilot Cowork は Microsoft が Copilot として提供する業務エージェントで Microsoft 365 の中の仕事に、Claude Cowork は Anthropic のエージェントで PC のフォルダや複数のツールをまたぐ仕事に向いています。どちらも起点はあなたの指示です。詳細は各社の公式案内で確認してください。

SIMY を使うには Claude の有料プランが必要ですか？

SIMY だけなら不要です。SIMY CLI を入れると、Claude Code の会話を SIMY に取り込み、SIMY から Claude Code を動かせます。このときは、あなたの Claude のログインとプランがそのまま使われます。Claude のトークンを SIMY のクラウド実行に連携することはできず、クラウド実行はお使いの ChatGPT アカウント（Codex）で動きます。Gemini のトークン連携は開発中です。SIMY の料金は料金ページをご覧ください。

Claude Code と Cowork は、どちらを使えばいいですか？

コードとリポジトリを扱うなら Claude Code、資料・表・フォルダを扱うなら Cowork です。SIMY は Claude Code の会話履歴から「SIMY からの提案」を作り、ローカルでは Claude Code を実行役にできます。

Cowork に PC のフォルダを触らせるのは安全ですか？

Claude が触れるのは、あなたが選んだフォルダと接続したツールだけで、削除にはあなたの承認が必要です。権限設定を有効にすると、重要な操作の前に計画を示して承認を待ちます。最初は、壊れても困らないフォルダから始めてください。
