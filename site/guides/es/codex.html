01 / REFERENCE

OpenAI Codex a fondo: instalación, precios, límites, comparativa y seguridad

Abre estas secciones cuando quieras comprobar algo de Codex en sí. Nada de esto afecta a la conexión con SIMY.

Qué es OpenAI Codex: diferencias con ChatGPT y con el Codex antiguoEl agente incluido en los planes de ChatGPT

Qué es Codex

OpenAI Codex es un agente de IA de OpenAI. Si ChatGPT responde cuando preguntas, Codex trabaja cuando se lo pides. Lee archivos, ejecuta comandos, maneja el navegador y crea entregables en tu PC o en un entorno en la nube. Nació para el desarrollo de software, pero en 2026, con la app de escritorio y los plugins, se extendió a trabajo sin código, como preparar documentos o redactar correos.

Diferencias con ChatGPT

ChatGPT devuelve respuestas en la conversación. Codex no devuelve una respuesta, sino algo hecho. Si pides «investiga al cliente A y prepara una propuesta», ChatGPT te da una estructura en texto y Codex termina creando el archivo de Slides. Ambos se usan con la misma cuenta de ChatGPT y comparten el uso disponible.

Cuidado con los nombres parecidos

  • El Codex antiguo (2021): un modelo de lenguaje para autocompletar código que se usó en las primeras versiones de GitHub Copilot. Dejó de ofrecerse en 2023 y es un producto distinto del OpenAI Codex actual.
  • Nombres de modelo como GPT-5-Codex: son modelos que puedes elegir dentro de Codex. Codex como producto y GPT-5-Codex como modelo están en niveles distintos.

Diferencias con ChatGPT Work

La app de escritorio de ChatGPT tiene tres modos: Chat, Work y Codex. Work es un agente que entrega resultados de trabajo general, como investigaciones o documentos; Codex es un agente fuerte en tareas con archivos y comandos. Ambos comparten el mismo uso disponible. Si no programas y dudas: si necesitas leer y escribir archivos o manejar Chrome, Codex; si quieres un entregable como continuación de la conversación, Work.

¿Funciona en español?

Sí. La interfaz está sobre todo en inglés, pero las instrucciones y los entregables pueden ser en español sin problema. AGENTS.md y las skills también pueden escribirse en español.

Instalación: inicio de sesión, AGENTS.md y modos de aprobaciónCon la app de escritorio, basta con descargar e iniciar sesión

Empezar con la app de escritorio (si no programas)

  1. Descárgala e instálala. Instala la versión para Windows o Mac desde la página de Codex de OpenAI.
  2. Inicia sesión con tu cuenta de ChatGPT. Con un plan Plus o superior, no necesitas clave de API. Se abre el navegador y, al autorizar, listo.
  3. Elige la carpeta de trabajo. Indica en qué carpeta puede leer y escribir Codex. Basta con una carpeta de Drive o una con tus materiales.
  4. Elige el modo de aprobación. Empieza con «confirmar antes de cambiar» y, cuando te acostumbres, pasa a «automático».
  5. Pide una tarea con tus palabras. Algo como «usa los casos de esta carpeta y prepara una propuesta para el cliente A», igual que se lo pedirías a una persona.

Empezar con la CLI (para ingenieros)

Con Node.js instalado, ejecuta npm install -g @openai/codex en la terminal y escribe codex para iniciar sesión. En Windows el soporte nativo avanza, pero es más estable usarlo sobre WSL.

AGENTS.md: el archivo donde escribes tu manera de trabajar

Si dejas un archivo de texto AGENTS.md en la carpeta de trabajo, Codex lee cada vez las reglas que contiene (nombres, estructura, prohibiciones) antes de trabajar. También puedes describir formatos de trabajo, como «propuestas de 12 diapositivas que terminan con los próximos pasos». Con SIMY, ese formato se aprende de las conversaciones, así que puedes empezar sin escribirlo.

Cómo pedir bien la primera tarea

  • Di dónde están los materiales. Si empiezas con «usa la carpeta "Casos" de Drive», reduces el tiempo de búsqueda y el uso.
  • Muestra un ejemplo del resultado. Adjunta la propuesta anterior o un correo modelo y la estructura y el tono saldrán iguales.
  • Decide dónde puede parar. Si escribes «no enviar» o «solo hasta el borrador», habrá menos aprobaciones y podrás delegar con tranquilidad.
  • Recibe el resultado como archivo. Mejor un archivo de Slides o Docs que un texto largo en el chat: así lo compartes directamente.

Modos de aprobación y sandbox

Codex puede alternar entre un «modo de confirmación», que pide aprobación antes de cambiar archivos u operar hacia fuera; un «modo automático», que avanza dentro de la carpeta de trabajo; y «acceso total», que lo delega todo. En cualquier modo trabaja dentro de un sandbox, que limita las operaciones fuera de la carpeta indicada y en la red.

Qué puede hacer: skills, MCP, Chrome, plugins y programaciónBorradores de Gmail, Drive, Sheets, Slides, Notion, Calendar, Slack

Apps de trabajo que se conectan con plugins (a octubre de 2026)

  • Gmail: lee correos y guarda respuestas o correos nuevos como borrador. El botón de enviar lo pulsas tú.
  • Google Drive, Sheets y Slides: lee archivos de carpetas, actualiza tablas y crea presentaciones.
  • Notion: lee y escribe páginas y bases de datos. Útil para guardar actas o notas de clientes.
  • Google Calendar: lee la agenda, propone fechas y prepara invitaciones.
  • Slack: lee canales y crea borradores de mensajes.
  • Chrome: abre Chrome para investigar sitios, rellenar formularios y leer pantallas. También sirve para revisar sistemas internos que requieren inicio de sesión.

Skills, MCP y subagentes

Las skills son conjuntos reutilizables de instrucciones con pasos y criterios. Si conviertes en skill «cómo hacer el informe semanal» o «el formato de actas», te ahorras explicarlo cada vez. MCP (Model Context Protocol) es un estándar común para conectar herramientas y datos externos a Codex; los servicios sin plugin (Figma, bases de datos internas, etc.) se añaden por aquí. Las tareas largas pueden repartirse entre subagentes que avanzan en paralelo.

Programación, modo plan y revisión

La programación de tareas repite una tarea a partir de una hora, por ejemplo: «cada viernes, cruza los correos, Slack y registros comerciales de la semana y prepara para Slack el borrador del informe al responsable». El modo plan te muestra solo los pasos y el alcance antes de ejecutar, para que lo revises. La revisión de código hace que Codex revise PR de GitHub; está pensada para equipos de desarrollo.

Cómo usarlo en trabajo sin código (ejemplos)

  • Investigar empresas: lee en Chrome la web y las noticias de la empresa y resume puntos clave en Docs.
  • Propuestas: con los casos y la tarifa de Drive, 12 diapositivas en Slides, con la estructura de la propuesta anterior.
  • Actas e informes: le das la transcripción, crea el acta con acuerdos, responsables y plazos, y deja un resumen para el responsable como borrador en Slack.
  • Fijar reuniones: propone tres huecos libres del calendario y guarda la invitación como borrador en Gmail.
  • Actualizar tablas: lee la tabla de avance en Sheets, aplica los cambios decididos en la reunión y lista las diferencias.

Relación con SIMY: la programación parte de una hora, y la primera instrucción la sigues escribiendo tú. SIMY toma como punto de partida las reuniones y los chats. Precisamente porque los plugins de Codex crean borradores de Gmail o Slides, SIMY puede centrarse en decidir «cuándo, qué y hasta dónde».

Cómo funcionan los límites

  • Plus y Business estándar tienen cuotas de cinco horas; también pueden aplicarse límites semanales. Pro no tiene actualmente límite de cinco horas. El consumo depende del modelo y la tarea: consulta la cuota restante y los reinicios en el panel de uso.
  • El consumo depende del modelo y la tarea: los modelos más capaces, las conversaciones largas y los archivos grandes gastan más rápido. Para documentos del día a día suele bastar el modelo estándar; cambia a uno superior solo para investigaciones difíciles y el uso te durará más.
  • Si lo agotas: espera al reinicio, sube a Pro, pasa a pago por uso con una clave de API o combínalo con otro ejecutor, como Claude Code.
  • Dónde ver el uso: en el medidor de uso de la app de escritorio y la CLI; en los ajustes de ChatGPT verás el uso por plan.

Trucos para que el uso dure más

Indica en una sola instrucción dónde están los materiales y cómo debe quedar el resultado, separa las conversaciones largas en hilos nuevos y divide investigar y crear en tareas distintas. Con estas tres cosas, el mismo trabajo consume visiblemente menos. El modelo es la destreza del pintor; el nivel de razonamiento, el tiempo que dedica al cuadro. Si te preocupa el uso, baja el nivel de razonamiento. Cuando SIMY le pide algo a Codex, le pasa directamente el formato aprendido, así que se repite menos trabajo.

Por qué combinarlos

Codex y Claude Code funcionan con planes distintos. Cada vez más gente se acostumbra a ambos para que el trabajo no se pare cuando un modelo falla o se agota el uso. Si usas las dos CLI, puedes alternarlas en la misma carpeta.

Dónde encaja SIMY: SIMY puede usar como ejecutor tanto Codex como Claude Code. En la nube pone a trabajar a Codex con tu cuenta de ChatGPT, y en tu PC la app de escritorio de SIMY también puede usar Claude Code. Funcione con el que funcione, a ti solo vuelve la decisión. Para ChatGPT en sí, consulta la guía de ChatGPT.

Seguridad y precauciones: entrenamiento, sandbox y aprobacionesTres puntos antes de usarlo en el trabajo
  • No usar tus datos para entrenar: en los ajustes de ChatGPT → «Controles de datos», desactiva «Mejorar el modelo para todos» y tus conversaciones de Codex tampoco se usarán para entrenar. Por defecto está activado. En Business y Enterprise, por contrato, los datos de trabajo no se usan para entrenar por defecto.
  • Sandbox: Codex trabaja en un entorno que limita la carpeta indicada y el acceso a la red. No toca archivos fuera de la carpeta ni sitios que no hayas permitido.
  • Aprobaciones: antes de operaciones irreversibles como borrar, enviar o publicar, Codex pide aprobación. Evita la aprobación automática total (el llamado YOLO) salvo en entornos desechables.
  • Chrome: si lo usas con sesión iniciada en sistemas de trabajo, crea un perfil de Chrome dedicado y que opere con una cuenta de pocos permisos.
  • Fuga de información: lo básico es no indicar como carpeta de trabajo las que contienen datos personales o confidenciales. Si tu empresa limita el uso de ChatGPT, valora usar Business o superior.
  • Conexión con SIMY: SIMY se conecta iniciando sesión en tu cuenta desde la pantalla de autenticación de ChatGPT y autorizando el acceso. Al crear propuestas a partir del historial, el texto no se guarda en el servidor. Más detalles en Seguridad y la Política de privacidad.

07 / BY ROLE

Por puesto: qué delegar en Codex y de dónde lo recoge SIMY

OpenAI Codex también ejecuta trabajo que no es código. Qué toma SIMY como punto de partida y qué le pide a Codex.

Ventas Chrome, Slides, borradores de Gmail

  • El CRM duplica el trabajo→La reunión pasa a ser el registro
  • Retocas el prompt cada vez→Borrador de seguimiento por destinatario
  • Investigar antes de la reunión, a mano→Puntos clave y material antes de verte

Dirección y mandos Slack, Sheets, Notion

  • Preguntas «¿cómo va aquello?»→Solo suben las decisiones pendientes
  • Reúnes los informes semanales→Informe semanal desde los acuerdos
  • Copias cifras a mano→Sheets actualizado y cambios explicados

Back office y planificación Drive, Sheets, Calendar

  • Las peticiones se pierden en el chat→Se recogen y avanzan hasta el borrador
  • Rehaces el material del seguimiento→Mismo formato, solo datos nuevos
  • Idas y vueltas para fijar fechas→Fechas propuestas e invitación lista

Ingeniería y desarrollo CLI, VS Code, junto a Claude Code

  • Vuelves a pedir lo decidido en la reunión→Lo acordado se vuelve tarea de Codex
  • Te preguntan por el avance→Estado de PR y revisión, solo decisiones
  • Agotas el uso de Codex→Sigue con Claude Code como ejecutor

09 / FAQ

Preguntas frecuentes

¿Se puede usar OpenAI Codex gratis?

Comprobado el 3 de octubre de 2026: Free y Go incluyen GPT-6 Luna a velocidad Standard en la app de escritorio, con despliegue gradual. Los entornos, modelos y límites difieren de Plus y planes superiores. El uso con clave de API se factura aparte. Consulta por separado los requisitos de conexión de SIMY.

¿Cuánto puedo usar Codex con ChatGPT Plus?

Plus y Business estándar tienen cuotas de cinco horas; también pueden aplicarse límites semanales. Pro no tiene actualmente límite de cinco horas. El consumo depende del modelo y la tarea: consulta la cuota restante y los reinicios en el panel de uso.

¿Cuándo se reinicia el uso de Codex?

Los reinicios dependen del plan y la cuota. Consulta el uso restante y la hora de reinicio en el panel de uso de Codex o con /status en la CLI. No todas las cuotas se reinician a un plazo fijo desde el primer uso.

Claude Code o Codex: ¿cuál elijo?

No hace falta quedarse con uno. Codex funciona con el plan de ChatGPT y Claude Code con el de Claude, así que cada vez más gente se acostumbra a ambos por si uno falla o se agota el uso. SIMY puede usar como ejecutor tanto Codex como Claude Code.

¿Qué es el modo plan de Codex?

Es un modo que, sin cambiar archivos, te muestra primero solo los pasos y el alcance. Antes de un trabajo grande, revisas el plan y, cuando estás de acuerdo, pasas a ejecutarlo. Combinado con los modos de aprobación, puedes decidir con detalle qué y hasta dónde delegar.

¿Puedo usar Codex si no soy ingeniero?

Sí. OpenAI explica que más del 20 % de los usuarios de Codex no son ingenieros (en 2026). Si se lo pides con tus palabras en la app de escritorio, llega hasta investigar empresas, preparar propuestas, actas y borradores de Gmail, casi sin ver código.

¿En qué se diferencian la programación de tareas de Codex y SIMY?

La programación de Codex repite una tarea fija a partir de una hora. SIMY parte de reuniones y chats, encuentra el trabajo que nace ahí y hace que Codex lo avance. Puedes usar la programación de Codex para lo fijo de cada mañana a las 9 y SIMY para lo que cambia con cada reunión.

¿Es seguro dejar que Codex maneje Chrome?

Codex funciona dentro de un sandbox y pide aprobación antes de operaciones con efecto externo, como iniciar sesión o enviar formularios. Para el trabajo, ten en cuenta tres cosas: no dejar el modo de aprobación en automático, usar un perfil de Chrome dedicado y revisar el ajuste para no entrenar con tus datos.

¿Se usa lo que escribo en Codex para entrenar la IA?

Si en «Controles de datos» de los ajustes de ChatGPT desactivas «Mejorar el modelo para todos», tus conversaciones de Codex tampoco se usan para entrenar. En Business y Enterprise, por contrato, los datos de trabajo no se usan para entrenar por defecto.

Si uso SIMY, ¿pago aparte por el uso de Codex?

SIMY se conecta a tu cuenta de ChatGPT y avanza el trabajo a través de Codex App Server. El uso de Codex corre a cargo de tu plan de ChatGPT. El precio de SIMY está en la página de precios.

¿Puedo usar Codex desde el móvil?

Desde las apps de ChatGPT para iOS y Android puedes revisar las tareas de Codex Cloud y pedir tareas nuevas. Con la app de SIMY para iOS, solo te llegan al móvil las decisiones pendientes del trabajo que avanzó Codex, y las apruebas desde ahí.
