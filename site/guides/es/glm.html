01 / AFTER THE CODE

¿Te pasa esto después de escribir con GLM?

El código y la descripción salieron de golpe con GLM. Aun así, esto es lo que ocurre después.

1 El mes con Coding Plan PR enviado, ¿y ahora?

La implementación terminó pronto. Nadie anotó quién hace los cambios acordados en la revisión.

2 La semana con la API barata ¿Cuál adoptamos?

Salieron muchas propuestas. Lo decidido quedó enterrado en el chat y el historial de la terminal.

3 El día que lo usaste en local Solo tú vas rápido

Resumiste sin sacar nada de la empresa. Los encargos de la reunión se quedaron en tus notas.

Escribir con GLM es cuestión de segundos. Que el trabajo avance se decide después de escribir.

08 / REFERENCE

Qué es GLM: modelos, GLM Coding Plan, Claude Code, API y seguridad (para saber más)

Abre estas secciones cuando quieras comprobar algo sobre GLM en sí. Los nombres de modelos, precios y especificaciones son de octubre de 2026.

Qué es GLM, de qué país es y en qué se diferencia de otros «GLM»El LLM de Zhipu AI. Su nombre internacional es Z.ai

GLM, Z.ai y Zhipu

GLM es la serie de modelos de lenguaje grandes (LLM) que desarrolla Zhipu AI (智譜), con sede en Pekín, China. Zhipu opera los servicios para China y, fuera de China, ofrece bajo el nombre «Z.ai» un chat (chat.z.ai), una API y planes de tarifa fija para programación. Z.ai internacional lo opera una sociedad de Singapur (JINGSHENG HENGXING TECHNOLOGY PTE. LTD.).

En Hugging Face publica los modelos con el nombre de organización «zai-org». En noticias y artículos se mezclan «Zhipu», «智譜», «Z.ai» y «GLM», pero se refieren a los modelos y servicios de la misma empresa.

Otros «GLM»

La sigla «GLM» se usa también fuera de los modelos de IA. Al buscar, añade palabras según lo que busques.

  • Modelo lineal generalizado (Generalized Linear Model): un método estadístico que engloba la regresión logística y la de Poisson, muy presente en tutoriales de estadística con R o Python. No tiene relación con el GLM de esta página.
  • GLM en el sector del automóvil: a veces se usa como abreviatura de nombres de empresas o modelos de vehículos. Tampoco es el GLM de esta página.
  • GLM de IA: los modelos de Zhipu AI. Llevan número de generación y variantes como «Flash», por ejemplo «GLM-5.3» o «GLM-4.7-Flash».

Qué se puede hacer con GLM

  • Chat: responder preguntas, redactar, traducir y resumir.
  • Programación: llamarlo desde herramientas como Claude Code, Cline u OpenCode para escribir, corregir o explicar código.
  • Comprensión de imágenes y reconocimiento de texto: GLM-5.3-Flash es multimodal y acepta imágenes. También existe GLM-OCR para leer el texto de documentos.

Lo que lo diferencia de los modelos principales de ChatGPT o Claude es que publica los pesos de modelos cercanos a su modelo principal, de modo que, si se cumplen las condiciones, puedes ejecutarlos en tu propio servidor o PC.

GLM Coding Plan: tarifa fija desde herramientas de programaciónLite cuesta 18 dólares al mes (octubre de 2026, según la web oficial)

GLM Coding Plan es un plan para usar GLM con tarifa fija desde herramientas de programación como Claude Code, Cline u OpenCode. A diferencia de la API, que se paga por token, se usa dentro de una cuota mensual, así que quien programa a diario puede prever mejor el gasto.

  • Lite: 18 dólares estadounidenses al mes (octubre de 2026, según la web oficial; consulta el tratamiento fiscal en la pantalla de compra).
  • Planes superiores: hay planes con más uso. Consulta su contenido y precio en la descripción oficial y en la página de compra.
  • Cuánto se puede usar: hay límites de uso (créditos) cada 5 horas y por semana, según el plan.
  • Modelos disponibles: GLM-5.3 y GLM-5.3-Flash. Si indicas GLM-5.2 se redirige a GLM-5.3, y si indicas GLM-4.7, a GLM-5.3-Flash.
  • Herramientas compatibles: herramientas de programación en las que se puede cambiar el destino de conexión, como Claude Code, Cline u OpenCode.

Pago por uso de la API o Coding Plan

  • Conviene Coding Plan: a desarrolladores que usan herramientas de programación a diario y a quien quiere un gasto mensual fijo.
  • Conviene la API: si lo integras en tus sistemas, procesas en bloque por la noche o tu uso varía mucho de un mes a otro.

Ninguno de los dos se encarga de lo que viene después del código: quién lo revisa y cuándo se publica. Si eso lo sigues persiguiendo tú cada vez, mira cómo se conecta SIMY.

Usar GLM en Claude Code: API compatible con AnthropicCambia el destino y la clave de API con variables de entorno

Z.ai ofrece una API compatible con Anthropic (https://api.z.ai/api/anthropic). Como Claude Code permite cambiar el destino de conexión con variables de entorno, puedes seguir usando Claude Code igual y que por detrás trabaje GLM.

  1. Emite una clave de API en Z.ai. Si vas a usar Coding Plan, suscríbete primero y luego crea la clave.
  2. Configura las variables de entorno. Pon la URL de arriba en ANTHROPIC_BASE_URL y la clave de API en ANTHROPIC_AUTH_TOKEN. No escribas la clave directamente en el código ni en documentos compartidos.
  3. Inicia Claude Code. Según la guía oficial, las llamadas equivalentes a Opus y Sonnet van a GLM-5.3, y las equivalentes a Haiku, a GLM-5.3-Flash. Esa correspondencia se puede cambiar con variables de entorno.
  4. Prueba con tareas pequeñas. Al cambiar de modelo cambian también su estilo y cómo entiende las instrucciones. Empezar con algo pequeño, como corregir pruebas, da más tranquilidad.

Los valores concretos pueden cambiar, así que sigue los pasos oficiales de Z.ai. En Cline u OpenCode se configura igual, con el destino y la clave.

SIMY y GLM: por ahora, SIMY no se conecta con claves de API de GLM (Z.ai). La ejecución en la nube de SIMY funciona con tu cuenta de ChatGPT (Codex).

Cómo empezar con la API

  1. Crea una cuenta en Z.ai. La ventanilla internacional es una sociedad de Singapur. Lee antes los términos de uso y la política de privacidad.
  2. Emite una clave de API. Guárdala en variables de entorno.
  3. Apunta a un destino compatible con OpenAI o con Anthropic. Con tus SDK o herramientas actuales, basta con cambiar la URL y el nombre del modelo.
  4. Prueba con el Flash gratuito y luego amplía. Comprueba el flujo con GLM-4.7-Flash y cambia a GLM-5.3 solo donde necesites más calidad; así contienes el gasto.
Licencias y uso local: GLM-4.7-Flash con OllamaFlash con licencia MIT y GLM-5.3 con licencia propia

Diferencias de licencia

No se puede decir sin más que «GLM es código abierto». GLM-5.3-Flash usa la licencia MIT, que facilita también el uso comercial. GLM-5.3 usa su propia «GLM-5.3 License», un permiso amplio parecido a MIT, pero las empresas con ingresos muy grandes por ofrecer modelos como API deben pasar una revisión de seguridad de Z.AI antes del uso comercial. Para el uso interno de una empresa normal no suele influir, pero antes de usarlo en el trabajo lee el texto de la licencia.

Ejecutarlo en tu PC

  • GLM-4.7-Flash: con Ollama, ollama run glm-4.7-flash. La versión cuantizada (q4_K_M) ocupa unos 19 GB y funciona en un PC con memoria de sobra.
  • GLM-5.3 y GLM-5.3-Flash: en la biblioteca oficial de Ollama solo tienen la etiqueta «cloud». Es la versión que se ejecuta en la nube de Ollama, no en tu PC.
  • En tus propios servidores: los pesos de GLM-5.3 están en Hugging Face, pero con cientos de miles de millones de parámetros hay que contar con varias GPU grandes.

Ojo con «local = no sale de casa»: si el objetivo es que los datos no salgan de tu empresa, los modelos con etiqueta cloud no sirven. Lo que funciona en tu equipo son modelos pequeños como GLM-4.7-Flash.

Trabajo que encaja con el uso local

Resumir documentos que no quieres sacar de la empresa, trabajar sin conexión o generar a diario muchos borradores rutinarios: ahí destaca el uso local. Los modelos pequeños no son tan capaces como los grandes, así que úsalos para el primer borrador y no para la versión final; así habrá menos sorpresas.

GLM en otros idiomas: hasta dónde llegaPuedes pedírselo en tu idioma, pero los idiomas indicados oficialmente son inglés y chino

Si le preguntas a GLM en tu idioma, responde en ese idioma. Pero la ficha oficial del modelo en Hugging Face solo indica inglés y chino, así que la calidad en otros idiomas no está garantizada oficialmente.

  • Donde rinde bien: generar y corregir código, resumir documentos en inglés o chino y redactar borradores de explicaciones técnicas.
  • Qué comprobar: el registro y el tono, los nombres propios locales y lo que diga sobre leyes o costumbres comerciales de tu país. Relee siempre los textos que vayan a salir de la empresa.
  • Con modelos pequeños: los modelos pequeños en local pueden sonar poco naturales en textos largos en idiomas distintos del inglés y el chino.

Lo más fiable para conocer la calidad en tu idioma es probarlo con varios documentos reales de tu trabajo.

Preguntas frecuentes

¿Qué es GLM?

GLM es una serie de modelos de lenguaje grandes (LLM) desarrollada por Zhipu AI (智譜), de China. Fuera de China se ofrece con el nombre Z.ai, con chat, API y planes de tarifa fija para programación. En estadística, «modelo lineal generalizado» también se abrevia GLM, pero es otra cosa.

¿De qué país es GLM (Z.ai)?

Su desarrollador, Zhipu AI, es una empresa de Pekín, China. Z.ai internacional lo opera una sociedad de Singapur y, según su política de privacidad, los datos personales se procesan en principio en Singapur.

¿Cuál es el modelo más reciente de GLM?

A octubre de 2026, los modelos principales son GLM-5.3 y GLM-5.3-Flash, más ligero y rápido. Los nombres cambian cada pocos meses, así que consulta la lista oficial.

¿Se puede seguir usando GLM-5.2?

Sí. A octubre de 2026, GLM-5.2 figura en la tarifa de la API de Z.ai con el mismo precio que GLM-5.3. En GLM Coding Plan, si indicas GLM-5.2 se redirige a GLM-5.3.

¿Qué es GLM Coding Plan?

Es un plan para usar GLM con tarifa mensual fija desde herramientas de programación como Claude Code, Cline u OpenCode. A octubre de 2026, la web oficial indica que el plan más pequeño, Lite, cuesta 18 dólares estadounidenses al mes. Consulta en la web oficial el precio de los planes superiores Pro y Max.

¿Se puede usar GLM en Claude Code?

Sí. Z.ai ofrece una API compatible con Anthropic, y si cambias el destino de conexión y la clave de API de Claude Code con variables de entorno, puedes llamar a GLM desde Claude Code. Los pasos están en la documentación oficial de Z.ai.

¿GLM se puede usar gratis?

Puedes probarlo en el chat web chat.z.ai. En la API, a octubre de 2026, la página oficial de precios indica que GLM-4.7-Flash y GLM-4.5-Flash son gratuitos. Los modelos principales, como GLM-5.3, son de pago por uso.

¿Se puede ejecutar GLM en local (en mi PC)?

Algunos modelos, sí. GLM-4.7-Flash en Ollama ocupa unos 19 GB en versión cuantizada y funciona en un PC con memoria de sobra. GLM-5.3 y GLM-5.3-Flash solo tienen en Ollama la etiqueta de ejecución en la nube y no funcionan en tu PC.

¿La licencia de GLM permite el uso comercial?

GLM-5.3-Flash tiene licencia MIT. GLM-5.3 tiene una licencia propia, en general de uso libre, pero los proveedores de API con ingresos muy grandes deben pasar una revisión antes del uso comercial. Antes de usarlo en el trabajo, lee el texto de la licencia de cada modelo.

¿GLM funciona en otros idiomas además del inglés y el chino?

Si le preguntas en otro idioma, responde en ese idioma, pero la ficha oficial del modelo solo indica inglés y chino. Para textos importantes, comprueba la calidad con documentos reales de tu trabajo antes de usarlo.

¿SIMY funciona con GLM?

No. Por ahora, SIMY no se conecta a GLM (Z.ai). SIMY funciona con tu cuenta de ChatGPT (Codex) y con Claude Code en tu PC. Puedes llevar tal cual a tus reuniones y chats el código y los borradores escritos con GLM.

¿Tengo que pedirle a SIMY cada vez el trabajo que queda tras escribir con GLM?

No. SIMY recoge por sí mismo lo decidido, los responsables y los plazos de tus notas de reuniones y chats. Aprende tu forma de trabajar de tus conversaciones y solo te devuelve lo que necesita tu decisión.
