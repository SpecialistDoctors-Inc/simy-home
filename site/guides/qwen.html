01 / REFERENCE

Qwenとは：使い方・モデル・API・ローカル実行・安全性（詳しく知りたい人向け）

ここから下は、Qwen本体のことを確かめたいときに開いてください。モデル名と仕様は2026年10月時点の情報です。

Qwenとは：読み方とどこの国のAIかクウェン。中国のAlibabaグループが開発

Qwenの読み方と正式名

Qwenは「クウェン」と読みます。中国語の正式名は「通義千問（Tongyi Qianwen）」で、Qwenはその略称です。チャットAIの名前であると同時に、文章・画像・音声・コードなどを扱う大規模言語モデル（LLM）のシリーズ全体を指します。

どこの国のAIか

Qwenは中国のAIで、Alibaba（アリババ）グループのQwenチームが開発しています。国際版のQwen Chat（chat.qwen.ai）はシンガポールの法人Alibaba Cloud (Singapore)が提供し、プライバシーポリシーでは入力をシンガポールで処理すると案内されています。APIはAlibaba CloudのModel Studioから提供され、東京を含む複数のリージョンを選べます。

3つの使い方

  • Qwen Chat：ブラウザやスマホアプリで、無料で話しかけて使う。個人の調べものや翻訳に向いています。
  • API：Alibaba CloudのModel Studioから、自社のシステムやツールに組み込んで使う。使った分だけ支払います。
  • オープンウェイト：Hugging FaceやModelScopeで公開されたモデル（重みのファイル）を、自分のPCやサーバーで動かす。データを外に出さずに使えます。

Qwenでできること

  • チャット：質問への回答、文章の作成、翻訳、要約。Web検索やDeep Researchもあります。
  • 画像・動画：画像や動画の理解、画像の生成と編集。
  • 音声：音声合成やリアルタイム翻訳のモデルがあります。
  • コード：コーディング向けモデルと、ターミナルで動くQwen Code。

中小規模のモデルの多くがオープンウェイトで、自分のPCやサーバーで動かせることが、ChatGPTやClaudeとの大きな違いです。

Qwen Chatの使い方：Webとスマホアプリ無料。ログインして、話しかけるだけ
  1. chat.qwen.aiを開く。ブラウザから使えます。スマホならiOSとAndroidの「Qwen」アプリがあります。
  2. ログインする。アカウントを作ってログインします。
  3. モデルを選ぶ。画面のモデル選択で切り替えられます。迷ったら既定のままで構いません。
  4. 話しかける。日本語で質問できます。ファイルや画像を添えて「要約して」「表にして」と頼めます。
  5. 機能を切り替える。Web検索、Deep Research、画像生成、Web Dev（Webページの試作）などを選べます。

Qwen Chatは無料で使えます。2026年10月時点で、ChatGPT PlusのようなQwen Chatの個人向け有料プランは確認できませんでした。

仕事で使うときのコツ

  • 役割と出力の形を先に伝える：「取引先への返信として、敬語で、3段落で」のように、誰に向けた何かを最初に書くと、手直しが減ります。
  • 翻訳は原文と並べて確かめる：金額、日付、型番、人名は、訳文だけを読まずに原文と照らし合わせてください。
  • 長い資料はファイルで渡す：貼り付けるより、PDFや文書ファイルを添付したほうが、表や見出しの構造が崩れにくくなります。
  • 会話を分ける：案件ごとに新しい会話を始めると、前の話題に引きずられた答えを避けられます。

こうして出した答えを「誰が・いつまでに・何をするか」に変えて追いかけるのは、Qwen Chatの外の仕事です。そこを毎回自分でやっているなら、SIMYのつなぎ方を見てください。

Qwen Image Editの使い方

Qwen Chatで画像を添付し、「背景を白にして」「看板の文字を日本語に」のように文章で指示します。オープンウェイト版は、ComfyUIなどの画像生成ツールに組み込んで使う人が多いモデルです。

QwenのAPIと料金：Alibaba Cloud Model StudioOpenAI互換。料金はモデルとリージョンで変わる
  • 入口：Alibaba CloudのModel Studio（DashScope）でAPIキーを発行します。OpenAI互換のAPIなので、既存のツールの接続先を差し替えて使えます。
  • リージョン：Qwen3.8-Maxなら北京、シンガポール、フランクフルト、バージニア、東京、香港から選べます。選べるリージョンはモデルごとに違い、データをどこで処理するかはここで決まります。
  • 料金：入力と出力のトークン数に応じた従量課金です。2026年10月時点で、qwen3.8-maxは100万トークンあたり入力1.65ドル・出力4.951ドル（東京など。シンガポールは2.00ドル・6.00ドル）と公式に表示されています。モデル、思考モード、キャッシュでも単価が変わるため、最新の金額は公式の料金ページで確認してください（税の扱いも同ページで確認）。
  • Coding Plan：Claude CodeやQwen Codeなどのコーディングツールから、Qwenなどのモデルを定額で使うプランです。2026年10月時点ではPro（月額50ドル）のみで、5時間・週・月ごとのリクエスト上限があります。詳しくは公式の説明をご覧ください。

APIを使い始める手順

  1. Alibaba Cloudのアカウントを作る。Model Studioのコンソールを開き、使うリージョンを選びます。
  2. APIキーを発行する。キーは環境変数に入れ、コードや共有ドキュメントに直接書かないでください。
  3. OpenAI互換のエンドポイントに向ける。OpenAIのSDKや既存のツールなら、接続先のURLとモデル名を差し替えるだけで呼び出せます。
  4. 小さく試して、使用量を見る。思考モードや長い文脈はトークンを多く使います。コンソールで日々の使用量を確認してから、本番の量に広げてください。

SIMYとの関係：現時点では、SIMYにQwenのAPIキーはつなげません。SIMYのクラウド実行は、お使いのChatGPT（Codex）アカウントで動きます。

Qwenをローカルで動かす：Ollama・LM Studioデータを外に出さずに使える。ライセンスはモデルごとに違う
  • Ollama：インストールして、ターミナルでollama run qwen3.8と打つと、27Bのモデル（ダウンロード約18GB、テキストと画像を入力できる）が動きます。目安として、メモリに余裕のあるPCが必要です。
  • LM Studio：画面からモデルを検索してダウンロードできます。コマンドが苦手な人向けです。
  • そのほか：llama.cpp、Jan、vLLM、SGLangなど。vLLMやSGLangを使うと、社内向けのOpenAI互換サーバー（OpenAIと同じ形で呼べるAPI）を立てられます。

ライセンスの違い

「Qwenはオープンソース」と一括りにはできません。Qwen3.8-27Bなど中小規模のモデルの多くはApache 2.0で、商用利用もしやすいライセンスです。最大級のQwen3.8-2.4T-A95Bは独自ライセンスで、MaxなどAPI専用のモデルは重みが公開されていません。

ローカル実行が向いている仕事

データを外に出したくない社内文書の要約、オフラインでの作業、毎日大量に回す定型の下書きは、ローカル実行の得意分野です。一方、小さなモデルは大きなモデルほど賢くはないため、最終版ではなく「たたき台」を作る役として使うと、期待とのずれが少なくなります。使い道を1つに決めてから試すと、どのモデルの大きさで十分かが判断しやすくなります。

必要なメモリ、量子化の選び方、モデルの大きさの目安は、Qwenをローカルで動かす方法にまとめています。

Qwen Code：ターミナルで動くコーディングエージェントオープンソース。Qwen以外のモデルにもつなげる

Qwen Codeは、Qwenチームがオープンソース（Apache 2.0）で公開しているコーディングエージェントです。ターミナルで動き、コードを読んで修正し、コマンドを実行します。

  • インストール：Node.js 22以上でnpm i -g @qwen-code/qwen-code@latest。MacならHomebrewでも入れられます。
  • つなげるモデル：Qwenのほか、OpenAI、Anthropic、Geminiの各API、OllamaやvLLMで動かすローカルモデル。
  • 向いている人：Claude CodeやCodexと同じ使い方を、Qwenのモデルや自前のサーバーで試したい開発者。

使い始めの流れ

  1. 作業したいフォルダでqwenを起動する。最初に、使うモデルと認証の方法を選びます。
  2. やりたいことを日本語で伝える。「このフォルダの構成を説明して」「テストが落ちる原因を探して」のように、目的から頼みます。
  3. 変更は確認してから受け入れる。ファイルの書き換えやコマンドの実行は、内容を見て許可します。最初は小さな修正から試すと安心です。

Qwen Codeで書いたコードのあと、レビューの会議で決まった修正や担当の割り振りは、SIMYが会議から拾って一覧にします。

Qwenの日本語：どこまで使えるか翻訳・要約・下書きは日本語で頼める

Qwen3世代の発表では、日本語を含む119の言語・方言に対応するとうたっています（3.8世代のモデルカードには言語数の記載がありません）。第三者の評価でも、同じくらいの大きさのモデルの中で日本語の性能が高いという報告があります。

  • 得意なこと：中国語・英語・日本語の間の翻訳、長い資料の要約、メールや報告の下書き、表の整理。
  • 気をつけたいこと：日本の固有名詞、敬語の細かい使い分け、日本の法令や商習慣の記述は、確かめてから使ってください。
  • 小さなモデルの場合：ローカルで動かす小さなモデルは、長い日本語の文章で言い回しが不自然になることがあります。大事な文面は大きなモデルで仕上げると安心です。

中国の取引先とのやり取りでは、会議の要約をQwenで日本語にし、決まったことの担当と期限、返信の下書きをSIMYに任せる、という分け方ができます。上の会議1件の比較がその例です。

02 / AFTER THE ANSWER

Qwenの答えのあと、こうなっていませんか

翻訳も要約も下書きも、Qwenで一瞬で出た。それでも、そのあとに起きていること。

1 翻訳した翌日 誰が返すんだっけ

中国語の議事メモは訳せた。でも宿題と期限は訳文に埋もれ、返事が遅れる。

2 下書きを量産した週 どれを採用した？

APIで案は大量に出た。決まったことはチャットとファイルに散らばったまま。

3 ローカルで動かした月 自分だけ速い

OllamaのQwenで手元は速くなった。会議で決まった依頼は、自分のメモ止まり。

答えを出すのは、Qwenで一瞬で終わる。仕事が進むかどうかは、答えのあとで決まっています。

03 / WHAT YOU REALLY WANTED

本当は、こうしたかった：Qwenの答えのあと

同じ会議。同じQwen。答えが出た瞬間に、こうなっていてほしかった。

✓ 会議が終わったら 担当と期限が一覧に

翻訳と要約はQwenのまま。決まったことと担当・期限は、もう並んでいる。

✓ 期限の前に 止まった仕事が届く

返事待ち・期限間近の仕事を、次の会議の前にSIMYが先に知らせてくれる。

✓ どのAIで出しても 結論は一か所に

採用した結論と次の行動が、モデルやチャットをまたいで1つに残っている。

! あなたに戻るのは 判断だけ

「この単価改定を受けるか」。戻ってくるのはその一問だけ。

これは、SIMYに会議とチャットをつないだ次の会議から起きることです。Qwenは、得意な仕事にそのまま使えます。

09 / FAQ

よくある質問

Qwenとは何ですか？

Qwen（クウェン）は、中国のAlibaba（アリババ）グループが開発する大規模言語モデル（LLM）のシリーズです。無料のチャット「Qwen Chat」、クラウドのAPI、自分のPCで動かせるオープンウェイトの3つの使い方があります。

Qwenの読み方は？

「クウェン」と読みます。中国語の正式名は「通義千問（トンイー・チェンウェン）」で、Qwenはその略称です。

Qwenはどこの国のAIですか？

中国のAIです。Alibabaグループが開発し、国際版のQwen ChatはシンガポールのAlibaba Cloud (Singapore)が提供して、入力をシンガポールで処理するとプライバシーポリシーで案内しています。

Qwenは無料で使えますか？

はい。WebのQwen Chatとスマホアプリは無料で使えます。APIは使った分だけの従量課金で、オープンウェイトのモデルは自分のPCで動かせば利用料はかかりません（PCの費用や電気代は別）。

Qwenは日本語に対応していますか？

対応しています。Qwen3世代の発表で、日本語を含む119の言語・方言をうたっています。翻訳や要約、メールの下書きも日本語で頼めます。

Qwenはローカル（自分のPC）で動かせますか？

動かせます。Ollamaならollama run qwen3.8で27Bのモデル（約18GB）が動き、LM Studioでも公開モデルを使えます。モデルごとにライセンスと必要なメモリが違うので、Qwenをローカルで動かす方法で確認してください。

Qwen Chatに入力した内容は、AIの学習に使われますか？

使われる場合があります。プライバシーポリシーでは、匿名化した内容をモデルの改善に使うことがあり、メールで申し出れば学習への利用を止められると案内されています（2026年10月時点）。機密を扱うなら、リージョンを選べるAPIか、データが外に出ないローカル実行を検討してください。

QwenのAPIの料金はいくらですか？

モデルとリージョンで違い、2026年10月時点の最上位qwen3.8-maxは100万トークンあたり入力1.65ドル・出力4.951ドル（東京など）です。Alibaba Cloud Model Studioの従量課金で、思考モードやキャッシュでも変わるため、公式の料金ページで確認してください。

Qwen Codeとは何ですか？

Qwenチームが公開している、オープンソースのコーディングエージェントです。ターミナルからコードを読み書きでき、Qwenのほか他社のモデルやローカルのモデルにもつなげます。

QwenとChatGPT、Claude、DeepSeekはどう違いますか？

大きな違いは、モデルを自分のPCで動かせるかと、データの行き先です。Qwenは中小規模のモデルをオープンウェイトで公開しており、ローカルでも動かせます。DeepSeekとの違いは中国のAI（LLM）比較にまとめています。

SIMYはQwenで動きますか？

いいえ。現時点では、SIMYはQwenには接続せず、お使いのChatGPT（Codex）アカウントと、SIMYデスクトップアプリ経由でPC上のClaude Codeで動きます。翻訳や下書きはQwenのまま使い、決まったことの段取りをSIMYに任せる、という分け方ができます。

Qwenで出した答えのあとの仕事は、毎回SIMYに頼む必要がありますか？

いいえ。SIMYは会議の記録やチャットから、決まったことと担当・期限を自分で拾います。あなたのやり方を会話から学び、判断が必要なところだけをあなたに返します。
