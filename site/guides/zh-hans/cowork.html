01 / AFTER THE TASK

任务做完后，是不是这样

Cowork 会照你的指令把事做完。可任务完成后的第二天，还是会发生这些事。

1 刚完成时 文件夹整理好了

销售资料收拾干净了。可会议上定下的待办，没有人接。

2 下周一 定时任务排好了

每周报告定时执行。但排什么，每次都得自己设计。

3 公司规定 公司只让用 Copilot

没法试 Cowork。可会议待办，每周照样产生。

Cowork 会完成你交代的工作。会议和聊天中产生的工作，却没有人交代过。

02 / WHAT YOU REALLY WANTED

其实你想要的是这样：Cowork 任务之后

✓ 走出会议室时 会后就已排好

✓ 不用开口 每次都是你的格式

✓ 下指令之前 收到建议

! 回到你手上的 只有判断

这些，从注册 SIMY 后的下一场会议就会发生。

06 / BY INDUSTRY

按行业：交给 Cowork 的工作，与 SIMY 的产出

桌面上的工作交给 Cowork，会议和聊天中产生的工作交给 SIMY。行业不同，分法一样。

销售 Cowork：商谈前的企业调研、资料文件夹整理

  • 销售会议→按负责人和期限列出待办
  • 商谈之后→感谢邮件草稿、客户备忘更新
  • 周末→不用追问，先给出待判断清单

后台、财务 Cowork：月结汇总、发票文件夹整理

  • 月结会议→给各部门的确认请求草稿
  • 报销规则变更→通知文案和流程更新草案
  • 咨询聊天→回复草案，只交需判断的

经营会议、1on1 Cowork：定期生成周报

  • 经营会议→决定事项与负责人一览、分享给相关人
  • 1on1→只有进度和待判断的事会报上来
  • 季度复盘→汇总多场会议的报告

制作、咨询 Cowork：交付文件夹整理、资料格式统一

  • 例会→下次之前的待办与负责人
  • 客户的需求聊天→报价前提和确认事项
  • 评审会→修改清单，只交需判断的
07 / START

开始使用：用不用 Cowork，都是 3 步

  1. 把桌面上的工作交给 Cowork在 Claude 桌面应用中打开 Cowork，选好文件夹并说明目的。每周的工作放进定时。不用 Cowork 的人，也可以从第 2 步开始。 前往下载
  2. 注册 SIMY，接上执行者云端用你自己的 ChatGPT 账户，本地用电脑上的 Claude Code。连接方法见上文。
  3. 开完一场会定下的待办附上负责人和期限列出，分享文案也会送到。审阅、决定，就这么简单。

注册流程：选择方案 → 邮箱验证 → 银行卡付款。没有免费方案。查看价格。电脑端应用请从下载页面获取。

在用 Claude Code 的人，会根据对话记录收到“来自 SIMY 的建议”。重复的工作，可以直接作为 WorkFlow 跑起来。

08 / REFERENCE

Claude Cowork 的用法、价格、安全性、对比（想深入了解的人）

以下内容是想确认 Cowork 本身时再展开看的。它们都不影响 SIMY 的用法。

Claude Cowork 是什么：写给非工程师的一句话说明与聊天的区别、2026 年的整合、能做的事

一句话说

Claude Cowork 是 Anthropic 提供的代办工作智能体。聊天里的 Claude 的工作是“回答问题”，Cowork 的工作则是“你说明目的，它就在你选定的文件夹和工具中动手，把成果交回给你审阅”。它和面向写代码的人的 Claude Code 不同，是为处理资料、表格、文件夹的一般业务而做的。

和聊天里的 Claude 有什么不同

用聊天，把回答复制粘贴进文件的工作留给了你。Cowork 会直接打开文件写入，做完后报告“完成了”。它打开了哪个文件、用了哪个工具、做了什么选择，都以步骤的形式可见，所以可以中途叫停或让它重做。

关于 2026 年与聊天的整合

截至 2026 年 10 月 1 日，Anthropic 官方页面以“Claude Cowork is now just Claude”为题，说明 Cowork 不再是与聊天分开的菜单，而将作为 Claude 本体的功能，从 Pro、Max 开始陆续提供。这项整合始于 2026 年 9 月、仍在进行中，菜单位置和名称可能变化。最新情况请以官方说明为准。

能做的事要点

  • 读取电脑内指定文件夹的文件，进行创建和编辑
  • 打开专用浏览器做调研、填写表单（与你自己的浏览器分开）
  • 只在需要时操作屏幕（Computer Use）
  • 按每天、每周、每月的定时执行同样的工作
  • 把大任务拆开并行推进
  • 用技能、连接器、插件贴合你的业务

官方给出的用法示例

Anthropic 的产品页面列出了以非工程师工作为设想的示例：每周一早上收集上周营销数据做对比、整理成资料存进 Drive 的报告；从月结文件夹把各地区的导出汇总成一张表、标出与预算差距大的行的汇总；把合同文件夹对照公司方针、为每份合同写带条款编号备注的初审；阅读一个季度的商谈笔记、整理各案件状况和反复出现的反对意见的回顾。都是“指定文件夹，说明目的”的形式，成果以待审阅的状态交回。

本文中的称呼

聊天里的 Claude、代办工作的 Cowork、面向代码的 Claude Code，是使用同一 Claude 模型的三个入口。本文把完成桌面工作的功能称为 Cowork，把接住会议和聊天中产生的工作并推动起来的一方称为 SIMY。Claude 本身的用法，见另一篇指南。

上手：从桌面应用开始第一个任务安装、文件夹怎么选、先交给它什么
  1. 安装 Claude 桌面应用。官方提供 macOS、Windows（含 arm64）、ChromeOS、Linux 的下载（截至 2026 年 10 月 1 日）。网页版和移动端也在陆续提供，移动端为测试版。Windows 上的支持范围和功能差异，请在最新官方页面确认。
  2. 用付费方案登录。Cowork 是面向付费方案的功能。详见下一项“价格与支持环境”。
  3. 打开 Cowork，选择文件夹。Claude 能接触的只有你在这里选的文件夹和已连接的工具。一开始先从“没整理过的资料文件夹”这类弄坏也无妨的范围开始。
  4. 只说明“做什么”。像“把这个文件夹分成提案、报价、纪要，再写一份命名规则的操作手册”这样，写目的而不是步骤。
  5. 看着步骤，审阅成果。删除需要你的批准。

熟悉后，把每周的工作登记为定时。即使合上笔记本也会执行，回来时结果已在等你。

写第一条指令的诀窍

  • 把对象限定在一个文件夹。不是“整个桌面”，而是“销售资料”这样看得见范围的单位。
  • 用一行写出成品形状。像“提案、报价、纪要、其他 4 个文件夹”“表格按地区各一个标签页”这样先定好接收方式，审阅会更快。
  • 写下不希望它做的事。“不要删除”“不要发到公司外”。虽有审批机制，写进指令更放心。
  • 要求它汇报。“最后汇总没做成的事和需要判断的事”。这一句话，就能把待确认事项列成清单。

选方案的参考

个人要把桌面工作交出去，从 Pro 开始。一天跑好几件、并行跑长任务的，可以考虑用量上限更大的 Max。团队使用、想管理谁能碰哪些文件夹和工具的，选 Team；需要按部门设权限、用量费用上限、把活动日志接到外部系统的，选 Enterprise。各方案的用量上限和金额可能变化，这里不写，请在官方价格页面确认。

与 SIMY 的关系：只用 SIMY 的话，不需要 Claude 付费方案。装上 SIMY 桌面应用后，可以导入 Claude Code 的对话，并从 SIMY 驱动 Claude Code。Claude 的令牌不能接入云端执行，云端执行使用你自己的 ChatGPT 账户（Codex）。SIMY 的价格见价格页面。

业务应用案例：技能、连接器、插件能做什么自动写操作手册、文件夹分类、Excel、PowerPoint

最容易先交出去的 4 件事

  • 文件夹分类：把堆积的文件按类型分开，把重复文件作为候选报告。删除要你批准后才执行。
  • 自动写操作手册：把它做过的作业步骤，直接写成内部操作手册。
  • Excel 汇总：把多个导出文件合成一张表，标出差异大的行。
  • 制作 PowerPoint：每周结构相同的汇报资料，替换数字后定期生成。

可以直接用的指令示例

  • “把销售资料文件夹分成提案、报价、纪要、其他。重复的不要删，列成清单。”
  • “把刚才整理的步骤，写成给新同事看的 Word 操作手册。写上存放位置和命名规则。”
  • “把报销文件夹里的 4 个 CSV 合成一个 Excel，环比变动 10% 以上的行标上颜色。”
  • “每周一 8:00，替换上周数字生成周报 PowerPoint，存进报告文件夹。”

技能、连接器、插件

技能是让 Claude 掌握“我们公司的报告怎么写”这类业务知识的机制；连接器是接入 Microsoft 365、Google Drive、Slack 等你已在用工具的连接；插件是把技能、连接器、子智能体打包在一起的导入套件。法务、财务、品牌语调等插件已经公开，Team、Enterprise 的管理员还能搭建公司内部的插件市场。

这些都是“让你交代的工作完成得更快更准”的机制，而不是让人接住会议待办的机制。那部分，是 SIMY 的工作。

从会议纪要、报告到邮件处理：每次都要重复同样指令的结构Cowork 能跑的工作，与指令本身仍留下的工作

把纪要文件夹交给 Cowork，说“提取决定事项和待办”，就能得到整齐的结果。周报可以放进定时，邮件回复也能做到草稿。到这里为止，都是 Cowork 的拿手活。

剩下的是结构。每次会议结束，保存转录稿、打开 Cowork、敲同样指令的，是你。就算做成定时，“哪场会议的、哪项待办、交给谁”每次都得重新设计。把邮件停在草稿，Codex 和 Cowork 都一样，是让人放心的保障，而不是谁的卖点。

SIMY 去掉的正是“下指令”这道工序。它从会议记录和聊天中接住工作，学习你按自己方式完成过一次的做法，之后以同样的形状备好，只把需要判断的事列进 My Actions。前提是两者并用：收下 Cowork 的成果，再推动下一步。

安全性：权限、文件夹范围、删除Cowork 能碰的范围，与你掌握的东西
  • 文件夹范围：Claude 能接触的只有你选的文件夹和已连接的工具，其他地方够不到。
  • 删除：删除任何东西都需要你的批准。
  • 事前确认：启用权限设置后，重要操作前会先展示计划并等待批准。可以中途叫停或改变方向。
  • 专用浏览器：网页作业在 Cowork 内的另一个浏览器中进行，与你自己浏览器的登录和标签页分开。
  • Team、Enterprise：管理员可以按团队设置访问、用量费用上限、按部门设工具权限，并把活动日志接入 SIEM。

一开始从弄坏也无妨的文件夹开始。熟悉之前，删除和发送都自己动手。在 SIMY 这边，Gmail 只到保存草稿为止，发布到 Slack、写入 Notion 都需要批准。数据的处理方式公开于安全和隐私政策。

与 Claude Code 的分工

Claude Code 是从终端或编辑器处理代码和仓库的入口，面向工程师。非工程师处理资料、表格、文件夹，用 Cowork 就够了。两者都用的人，按代码交给 Claude Code、桌面交给 Cowork、会议待办交给 SIMY 来分，就不会纠结。SIMY 会从 Claude Code 的对话记录中找出重复的工作，作为“来自 SIMY 的建议”提出，所以在 Claude Code 里还靠手动的固定工作，可以直接变成 WorkFlow。

选择 Copilot Cowork 的公司也一样

如果公司规定统一用 Microsoft 365 和 Copilot，可能没法试 Claude Cowork。即便如此，会议上定下的待办、聊天中产生的请求，每周照样会有。SIMY 不是 Copilot 的替代，而是从会议和聊天中接住工作并推动起来的一方，所以可以与 Copilot Cowork 并用。SIMY 的执行者是你自己的 ChatGPT（Codex）或电脑上的 Claude Code，与 Copilot 的合同无关。

怎么选：公司以 Microsoft 365 为中心就选 Copilot Cowork，跨电脑文件夹和多个工具就选 Claude Cowork，写代码就选 Claude Code。无论选哪个，接住会议待办都是另一项工作，在那里叠加 SIMY。SIMY 可以让 Codex 和 Claude Code 都作为执行者，也能防备一方不稳定或达到用量上限。Copilot Cowork 的规格请以 Microsoft 官方说明为准。

09 / FAQ

常见问题

Claude Cowork 可以免费使用吗？

不可以。根据截至 2026 年 10 月 1 日的官方说明，Cowork 是面向付费方案的功能，从 Pro、Max 开始陆续提供。所在地区的价格请在 Claude 官方价格页面确认。

Claude Cowork 能在 Windows 上用吗？

截至 2026 年 10 月 1 日，Claude 官方提供面向 Windows（含 arm64）的桌面应用下载。支持范围和功能差异，请在最新官方页面确认。

Claude Cowork 能在手机上用吗？

官方表示，Cowork 正陆续在网页和移动端提供（移动端为测试版）。设想的用法是：在桌面上开始的工作，用手机查看或追加指令。

Claude Cowork 从什么时候开始可以用？

截至 2026 年 10 月 1 日，付费方案可在 Claude 桌面应用中使用。提供的方案和环境在分阶段扩大，你所用方案的开放时间请以官方公告为准。

Claude Cowork 能做什么？

读写你所选文件夹中的文件、制作表格和资料、用专用浏览器调研并填写表单，只在需要时操作屏幕。支持按每天、每周、每月定时执行，并能用技能、连接器、插件贴合业务。

Claude 的聊天和 Cowork 合并了吗？

官方以“Claude Cowork is now just Claude”为题，说明 Cowork 将作为 Claude 本体的功能，从 Pro、Max 开始陆续提供（截至 2026 年 10 月 1 日）。整合仍在进行中，菜单位置和名称请以最新官方信息为准。

Cowork 的定时执行和 SIMY 的 Autorun 有什么不同？

起点不同。Cowork 的定时是在设定时间重复你设计好的工作；SIMY 的 Autorun 是把从会议和聊天中接住的工作按你的格式推进，只把判断交给你。定时执行本身，两者都有。

和 Copilot Cowork 有什么不同？

Copilot Cowork 是 Microsoft 作为 Copilot 提供的业务智能体，适合 Microsoft 365 内的工作；Claude Cowork 是 Anthropic 的智能体，适合跨电脑文件夹和多个工具的工作。两者的起点都是你的指令。详情请以各公司的官方说明为准。

使用 SIMY 需要 Claude 的付费方案吗？

只用 SIMY 的话不需要。装上 SIMY 桌面应用后，可以把 Claude Code 的对话导入 SIMY，并从 SIMY 驱动 Claude Code。这时使用的是你自己的 Claude 登录和方案。Claude 的令牌不能接入 SIMY 的云端执行，云端执行使用你自己的 ChatGPT 账户（Codex）。Gemini 的令牌联动正在开发中。SIMY 的价格请见价格页面。

Claude Code 和 Cowork，该用哪个？

处理代码和仓库用 Claude Code，处理资料、表格、文件夹用 Cowork。SIMY 会从 Claude Code 的对话记录生成“来自 SIMY 的建议”，在本地也能让 Claude Code 当执行者。

让 Cowork 操作电脑里的文件夹安全吗？

Claude 能接触的只有你选的文件夹和已连接的工具，删除需要你的批准。启用权限设置后，重要操作前会展示计划并等待批准。一开始请从弄坏也无妨的文件夹开始。
