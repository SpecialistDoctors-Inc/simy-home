01 / REFERENCE

MiniMax 是什么：H3、M3、价格、API 与本地运行（想深入了解的人）

以下内容，想确认 MiniMax 本身的情况时再展开。模型名称和价格为截至 2026 年 10 月的信息。

MiniMax 是什么：哪个国家的 AI中国上海的 AI 公司。文本、视频、语音模型一应俱全

MiniMax 的开发方

MiniMax 是一家位于中国上海的 AI 公司。除了处理文字的大语言模型（LLM），还自主开发视频生成和语音合成的模型与应用。面向海外的应用由新加坡法人 Nanonoble Pte. Ltd. 提供。

3 种用法

  • 应用：在网页或手机上使用 MiniMax Code、MiniMax Audio、视频应用海螺（Hailuo）等。
  • API：通过 MiniMax 的开放平台（platform.minimax.io）接入自家系统或开发工具。有按量计费和包月的 Token Plan。
  • 开放权重：在自家服务器上运行 Hugging Face 公开的 MiniMax-M3 或 MiniMax H3 权重。有许可证条件。

“minimax”也是博弈论中一种搜索方法（极小化极大算法）的名称。本页讨论的是 AI 公司 MiniMax。

MiniMax H3 是什么

MiniMax H3 是 MiniMax 于 2026 年 7 月底发布的视频生成模型。以文字、图片、视频、声音为线索，生成带立体声的视频（4～15 秒，最高 2K）。官方模型卡写明，台词支持 11 种语言，具体语言请以模型卡为准。

  • 在哪里用：视频应用海螺（Hailuo）、MiniMax 的 API、Hugging Face 公开的权重。
  • 与 M3 的区别：H3 是生成视频的模型，M3 是处理文字的文本模型，两者不同。
  • 本地运行：对个人电脑来说是很重的模型。详见下方的本地运行的现实。

MiniMax-M3 是什么

MiniMax-M3 是 2026 年 6 月发布的 MiniMax 当前主力文本模型。总参数约 4,280 亿（单次推理激活约 230 亿），支持 100 万 token 上下文以及文本、图片、视频输入。API 单价低，还有可从编程工具包月使用的 Token Plan。

MiniMax Audio 的用法

贴入要朗读的文字，选择音色和语速，即可生成语音。可用于培训视频的旁白、产品介绍的朗读、面向内部的通知语音等。生成与真人声音相似的语音时，请确认本人同意以及发布平台的规定。

MiniMax 能做什么：工作中的用途文字、语音、视频，都能用同一家公司的工具备齐
  • 文字：用 MiniMax-M3 写脚本、文章、邮件、报告的初稿。也能总结长资料，或者给它看图片、视频后让它说明。
  • 语音：用 MiniMax Audio 根据脚本生成旁白或朗读音频。可用于培训、产品介绍、内部通知。
  • 视频：在海螺（Hailuo）或 API 中使用 MiniMax H3，从文字或图片生成带声音的短视频。适合用作分镜草稿，或试做社交媒体短视频。
  • 编程：通过 MiniMax Code，或经由兼容 Anthropic 的 API 接入的编程工具，把写代码的工作交出去。

用海螺（H3）制作视频的流程

  1. 用文字写出想要的场景。像“早晨的办公室里，员工一边看平板一边开会”这样，具体写出地点、人物和动作。
  2. 需要的话附上图片。可以让产品照片或示意图动起来。
  3. 多做几条再挑选。同样的指令每次结果都不同，把候选排在一起比较最快。

使用人物面孔、Logo，或与他人作品相似的表现时，请确认权利归属和发布平台的规定。对外发布的视频，最后请由人亲自检查后再发布。

无论哪种用途，MiniMax 给出的都只是“素材”或“草稿”。在此基础上于会议中定下的负责人、期限，以及给相关人员的联络，由 SIMY 从会议和聊天中接住并推进。

价格思路：按量计费与 Token Plan文本 API 属于便宜的一档。包月每月 22 美元起
  • 按量计费：截至 2026 年 10 月，MiniMax-M3 在输入不超过 512K token 时，每 100 万 token 输入 0.30 美元、输出 1.20 美元。超过 512K 的长输入为 2 倍，优先处理为 1.5 倍。在中国的 LLM 中也属于便宜的一档。
  • Token Plan：从编程工具等包月使用的方案，分为 Plus 每月 22 美元、Max 每月 55 美元、Ultra 每月 132 美元 3 档。每 5 小时和每周各有用量额度。
  • 税费：价格以美元标示。税费的处理和最新金额，请在按量计费价格页面和 Token Plan 页面确认。

怎么选

  • 每天在编程工具里用：如果用量难以预估，Token Plan 更容易把每月支出定下来。
  • 接入自家系统：适合与处理量成正比的按量计费。先小规模试用，看清每件的成本后再扩大。

视频和语音的价格与文本是不同的体系。会随制作的条数和时长变化，请在官方页面确认。

MiniMax 的 API：推荐兼容 Anthropic 的格式可接入 Claude Code 等使用 Anthropic 格式通信的工具
  • 入口：在 MiniMax 开放平台（platform.minimax.io）创建 API 密钥。
  • 兼容性：官方推荐使用与 Anthropic SDK 兼容的格式。也支持 OpenAI 的 Chat Completions 和 Responses API 格式。
  • 从编程工具使用：把 Claude Code 等使用 Anthropic 格式的工具的接入地址和 API 密钥换成 MiniMax 的，就能调用 MiniMax-M3。步骤在官方文档中有说明。

开始使用 API 的步骤

  1. 在 MiniMax 开放平台创建账户。选择按量计费或 Token Plan。
  2. 创建 API 密钥。把密钥放进环境变量，不要直接写在代码或共享文档里。
  3. 修改常用工具的接入地址。选择 Anthropic 格式或 OpenAI 格式，替换 URL 和模型名。
  4. 先小规模试用，观察用量。长输入单价更高。确认每天的用量后，再扩大到正式规模。

与 SIMY 的关系：SIMY 目前不接入 MiniMax 的 API 密钥。SIMY 的云端执行使用你自己的 ChatGPT（Codex）账户运行。

开放权重与许可证：商用有条件M3 和 H3 都是自有许可证，不要一概称为“开源”

MiniMax-M3 的模型权重在 Hugging Face 公开，但许可证是自有的“MiniMax Community License”。非商业用途可以自由使用，商业用途有条件。

  • 商业使用时：需要标示“Built with MiniMax M3”，并通知 MiniMax。
  • 年营收超过 2,000 万美元时：商业使用前需要获得 MiniMax 的书面许可。
  • 禁止的用途：禁止用于军事等用途。
  • M2.7：同样是自有许可证。

MiniMax H3 的许可证

  • 适用地区：MiniMax H3 Community License 将欧盟、英国、韩国、美国排除在适用地区之外。在海外据点或与海外合作方一起使用时，请确认所在地区是否适用。
  • 商业使用时：需要在产品界面上标示“MiniMax H3”。年营收超过 2,000 万美元时，需要事先获得书面许可。

即使只在公司内部试用，是否属于商业用途也会影响条件。在业务中使用前，请确认 M3 的许可证全文和 H3 的许可证全文。

MiniMax H3、M3 能否在本地运行对个人电脑都很重。官方步骤以多 GPU 配置为前提

“MiniMax H3 本地部署”的搜索很多，但截至 2026 年 10 月，请把在普通电脑上运行 H3 或 M3 视为很难的事。

  • Ollama：官方库中的 minimax-m3 和 minimax-m2.7 带有“cloud”标签。意思是在 Ollama 的云端运行，输入会发送到 Ollama 的服务器。也有社区制作的版本，但并非官方版本。
  • MiniMax H3：权重已公开，但官方步骤以 4 块 GPU 的配置为例。也公开了在 ComfyUI 中使用的步骤，所需显存请在自己的环境中确认。
  • M3、M2.7 的官方步骤：M3 以 8 块 B200 GPU 的配置为参考（实验性质），M2.7 以 4 块大显存 GPU 为参考。这是面向数据中心的配置。
  • 想在自己的电脑上运行：可以考虑Qwen 指南或 GLM 指南中介绍的小型文本模型。

如果目的是“不让数据流出”，带 cloud 标签的模型并不符合。请在自家 GPU 服务器上运行权重，或者选择本机能跑得动的模型。

MiniMax 的多语言：能用到什么程度可以用各种语言提需求，但官方未明确列出 M3 支持的语言

可以用多种语言向 MiniMax-M3 提需求，但截至 2026 年 10 月，官方没有明确列出 M3 支持的语言。另一方面，视频 H3 的模型卡写明，台词支持 11 种语言。无论哪个，都请用实际业务中的素材试一试再确认。

  • 文字：脚本和邮件草稿，请确认措辞和语气后再使用。
  • 语音：朗读时，请听一听专有名词和数字的读法是否正确。
  • 视频：请确认画面中的文字没有变形。字幕用剪辑软件后期加入更稳妥。

也可以组合这样的流程：用 M3 把其他语言的脚本翻译过来，再用 MiniMax Audio 生成朗读。会议中定下的修改负责人与期限、给制作公司或内部的联络，可以交给 SIMY。

02 / AFTER THE OUTPUT

用 MiniMax 做完之后，是不是这样？

脚本、配音、视频草稿，用 MiniMax 一口气就做好了。可在那之后，发生的却是这些。

1 素材做好的第二天 最后选的是哪个？

脚本和视频各有 3 个方案。会上选定的那个，被聊天记录冲走，找不到了。

2 定下修改的会议 谁来改？

旁白措辞和时长要改。负责人和期限，只是口头说了一句。

3 发布前一周 还没通知

忙着做素材，给制作公司和销售的联络一拖再拖。

做东西，MiniMax 一下就完成。工作能不能推进，取决于做完之后。

09 / FAQ

常见问题

MiniMax 是什么？

MiniMax 是一家位于中国上海的 AI 公司。开发视频生成的 MiniMax H3、文本模型 MiniMax-M3、语音合成的 MiniMax Audio 等模型和应用。

MiniMax 是哪个国家的 AI？

由中国上海的公司开发。面向海外的应用由新加坡法人 Nanonoble Pte. Ltd. 提供。

MiniMax H3 是什么？

MiniMax H3 是 MiniMax 于 2026 年 7 月底发布的、生成带声音视频的模型。以文字、图片、视频、声音为线索生成最长 15 秒的视频，可在海螺（Hailuo）和 API 中使用。它与文本模型 MiniMax-M3 是不同的模型。

MiniMax H3 能在本地运行吗？

请把在个人电脑上运行视为很难的事。权重已在 Hugging Face 公开，但官方步骤以 4 块 GPU 的配置为例。想轻松试用，海螺（Hailuo）或 API 更现实。

MiniMax 可以免费使用吗？

各应用情况不同，免费可用的范围请查看各应用的官方说明。API 是收费的，分为按用量付费的按量计费和包月的 Token Plan。

MiniMax 的 Token Plan 多少钱？

截至 2026 年 10 月，分为 Plus 每月 22 美元、Max 每月 55 美元、Ultra 每月 132 美元 3 档。每 5 小时和每周各有用量额度。

MiniMax Audio 是什么？

MiniMax 的语音合成应用和模型，可以把文字变成自然的语音。可用于培训视频的旁白、产品介绍的朗读等。

可以从 Claude Code 使用 MiniMax 的模型吗？

可以。MiniMax 的 API 推荐兼容 Anthropic 的格式，把 Claude Code 等工具的接入地址和 API 密钥替换后，就能调用 MiniMax-M3。

MiniMax 能在本地（自己的电脑）运行吗？

在个人电脑上运行当前的 MiniMax-M3 并不现实。Ollama 官方库中的 M3 带 cloud 标签（在 Ollama 云端运行的版本），官方的自托管步骤以多块高性能 GPU 为前提。

MiniMax 的模型可以商用吗？

有条件地可以。MiniMax-M3 商用时需要标示“Built with MiniMax M3”并通知 MiniMax，年营收超过 2,000 万美元时需要事先获得书面许可。MiniMax H3 的许可证将欧盟、英国、韩国、美国排除在适用地区之外，因此也请确认使用的国家或地区。

输入 MiniMax 的内容存储在哪里？

海外版应用的政策写明，原则上不转移到新加坡境外。API 另有政策，签约前请确认全文。

SIMY 是用 MiniMax 运行的吗？

不是。SIMY 目前不连接 MiniMax，而是使用你自己的 ChatGPT（Codex）账户和电脑上的 Claude Code 运行。用 MiniMax 做的脚本和素材，可以直接带进会议或聊天。

用 MiniMax 做完之后的工作，每次都要去请 SIMY 做吗？

不用。SIMY 会自己从会议记录和聊天中接住决定事项、负责人和期限。它从对话中学习你的做法，只把需要判断的部分交给你。
