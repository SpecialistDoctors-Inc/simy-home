01 / REFERENCE

PLAUD的用法、套餐价格与安全性（想深入了解的读者）

以下内容适合想确认PLAUD本身细节时展开阅读。这些都不影响与SIMY的连接。

PLAUD用法：到手后先做的5件事充电、配对、录音模式、摘要模板、说话人名称

到手后先做的5件事

  1. 充电，并将应用与设备配对。NotePin放到磁吸充电座上即可，约2小时充满。录音数据从设备传到应用后，开始转写。在设备存储空间用满之前勤传输，会更放心。
  2. 确认录音模式。PLAUD NOTE和PLAUD NOTE Pro可以在面对面和通话两种模式之间选择录音，NOTE Pro会自动切换。NotePin系列只能录制面对面对话。
  3. 选择摘要模板。可从商谈、1对1、讲座等1万多种模板中选择。把常开的会议类型添加为自定义模板，生成的摘要颗粒度会更统一。
  4. 登记说话人名称。把转写中的说话人改成姓名，纪要更易读，谁承担了什么也更好追踪。
  5. 把Plaud账号连接到SIMY。在连接页面点击“连接”即可。

在电脑上使用：Plaud Web与Plaud Desktop

  • Plaud Web：在浏览器里登录Plaud账号，即可查看录音、编辑转写。
  • Plaud Desktop：Windows和Mac桌面应用。无需让机器人入会，就能录制Zoom、Microsoft Teams、Google Meet等线上会议。PLAUD用户可免费使用。

无论在手机还是电脑上，Plaud账号中保存的录音都可以由SIMY参考。

PLAUD NOTE的主要功能：录音、转写、摘要、Ask Plaud作为AI录音笔，它擅长到这里

录音、转写、摘要

PLAUD NOTE是一款用AI自动完成对话录音、转写和摘要的录音设备。一键开始录音，关键时刻可以打上高亮标记。NOTE Pro支持最长50小时连续录音，另有可夹在胸前口袋的NotePin系列。转写支持112种语言，中文对话也能区分说话人。准确度受与麦克风的距离和环境噪音影响；在会议室里，用4个麦克风可收录最远5米声音的NOTE Pro更有优势。摘要所用的AI模型可在GPT、Gemini、Claude等之间选择。

思维导图、Ask Plaud、多模态输入

思维导图把对话结构画成图，帮助把握长会议的全貌。在Ask Plaud（测试版）中，可以就录音内容提问，比如“对方的预算大概多少？”。还可以给录音附上照片和文字，记成一条笔记。

导出与集成

可导出TXT、DOCX、PDF、SRT等27种以上格式。支持导出到Notion、AutoFlow功能、与Zapier的集成，以及让AI工具读取录音的PLAUD MCP。发给外部用PDF，内部编辑保存用DOCX，用轻量文件保留全文用TXT，需要带时间轴的记录或视频字幕用SRT。如果只是搭配SIMY使用，不需要导出。

安全、防泄露与录音同意不用于训练的设置、加密、同意的取得方式
  • 录音同意：开始录音前，请取得所有参与对话者的同意。SIMY的服务条款也规定，取得录音同意是用户的责任。
  • PLAUD的安全性：PLAUD公开表示符合SOC 2 Type II、HIPAA、GDPR和ISO/IEC 27001。数据在传输时以TLS 1.2及以上加密，存储时以AES-256加密。
  • AI训练：PLAUD表示，除非用户明确同意，否则不会将录音数据用于AI训练。不再需要的录音可以在PLAUD应用中删除。
  • 使用PLAUD MCP时：从网页版ChatGPT或Claude使用时，录音数据会经过PLAUD位于美国的服务器。PLAUD表示处理后不会保存数据。
  • 与SIMY的连接：在Plaud的授权页面登录你的Plaud账号并授权即可。SIMY的数据处理方式公开在安全和隐私政策中。
  • 转写准确度与验证：基本做法是缩短与麦克风的距离、减少噪音、登记说话人名称。线上会议时把设备放在扬声器附近，录音会更清晰。先用短会议验证，再用于正式场合会更放心。需要翻译或下载时，也可以在PLAUD应用中完成。

08 / START

  1. 配对PLAUD，开始录音充电，连接应用与设备。提前设置好摘要模板和说话人名称，摘要的颗粒度会更统一。

09 / FAQ

常见问题

刚买了PLAUD，应该从哪里开始？

先在PLAUD应用里配对设备，确认录音模式和摘要模板。然后在SIMY的连接页面连接Plaud账号，第一场会议就能用上。

我已经在用PLAUD了。以前的录音也能在SIMY里用吗？

可以。连接后，SIMY会检索并参考Plaud账号中保存的录音、转写和摘要。

PLAUD NOTE Pro、NotePin等型号都能用吗？

都能用。SIMY参考的是Plaud账号中保存的转写和摘要，与型号无关。如果还想录通话，请选择带通话模式的PLAUD NOTE或PLAUD NOTE Pro。

PLAUD的Starter（免费）、Unlimited等任何套餐都能连接吗？

都能。连接只需要一个已绑定设备的Plaud账号。套餐的区别在于转写时长：Starter每月300分钟，Pro每月1,200分钟，Unlimited不限。

需要导出到Notion或设置PLAUD MCP吗？

不需要。PLAUD MCP是PLAUD官方提供的、让ChatGPT或Claude读取录音的机制；SIMY直接参考Plaud账号，所以既不用导出，也不用设置MCP。

PLAUD是哪个国家的公司？

开发PLAUD的Plaud Inc.总部位于美国旧金山。各地区的客户支持与数据管理方式，请以PLAUD官方说明为准。

PLAUD的录音会被用于AI训练或泄露吗？

PLAUD表示，未经用户明确同意，不会将录音数据用于AI训练。它符合SOC 2 Type II、HIPAA、GDPR和ISO/IEC 27001，数据加密保存。SIMY的数据处理方式公开在安全页面和隐私政策中。

纪要格式（参会人、议题、决定事项、下一步）每次都要指定吗？

不用。按你的格式完成一次后，SIMY会学会这种做法，之后的会议都按同样的格式准备。不再需要粘贴转写、重复输入同样的指令。

“决定了什么”由AI判断，还是由我判断？

由你判断。SIMY从转写和摘要中整理出候补并推进到草稿，只把金额、能否发送等需要判断的部分交还给你。

用Notion AI、Notta、Teams等PLAUD以外的转写工具，也能用SIMY吗？

本页面向PLAUD用户，但SIMY的连接页面还有Notion、Google等其他连接项，可以从那里传入会议上下文。支持情况请在连接页面确认。

使用SIMY会额外产生AI使用费吗？

SIMY连接你自己的ChatGPT账号，通过Codex App Server推进工作。Codex的使用在你的ChatGPT套餐范围内进行。SIMY本身的费用请查看价格页面。

录音时需要对方同意吗？

需要。开始录音前，请取得所有参与对话者的同意。SIMY的服务条款也规定，取得录音同意是用户的责任。
