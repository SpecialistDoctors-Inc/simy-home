01 / REFERENCE

GPTs、设置、价格、Work 与 Codex、安全性（想深入了解的读者）

以下内容适合想确认 ChatGPT 本身细节时展开阅读。这些都不影响与 SIMY 的连接。

GPTs、项目、自定义指令：不必每次开口的技巧与局限在 ChatGPT 内部能做的和做不到的

在 ChatGPT 内部“不必每次都写”的3种技巧

  • 自定义指令：设置好职业、行业、常写的文档、想避免的说法，每次的提示词就会变短。写下“邮件用敬语，先说结论”“金额同时注明含税价”这类你在做好工作时遵守的标准。
  • 项目：按客户或项目建立项目，把资料和对话放在一起，Chat 和 Work 都能基于同样的前提工作。
  • GPTs（自定义 GPT）：像“把会议纪要改成我们格式的 GPT”这样，把一项任务的格式固定下来保存。GPT 商店公开的 GPTs 免费套餐也能用，但创建需要 Plus 及以上。只在工作区内共享的公司内部 GPTs，可以用 Team 或 Business 及以上创建（截至2026年10月）。

GPTs 的创建方法：4个步骤

  1. 打开“创建 GPT”。创建需要 Plus 及以上的付费套餐，免费套餐只能使用（截至2026年10月）。
  2. 设置指令、知识文件、对话开场白和功能。指令可以让 ChatGPT 先起草：“帮我写一个这样的 GPT 的指令”。
  3. 选择公开范围。仅自己、知道链接的人、公司内部（Team、Business 及以上的工作区）三选一。
  4. 开始使用。例如：读过公司资料的顾问，给个 URL 就能总结新闻的 GPT。

即便如此，打开 GPT、粘贴资料或 URL、提出请求的，每次都还是你。从会议和聊天中接手工作这一步起，由 SIMY 承担。

等待输入型提示词：免费套餐也能用的技巧

先定好规则：“接下来我发的要点，请按这个规则写成文章。明白了就回答‘好’”，之后只发数据。

对话变长后，它会逐渐忘记最初的指令；出现走样时，就在新对话里重新固定规则。

即便如此，打开聊天、重新粘贴规则、搬运数据的，每次都还是你。SIMY 从对话中学习你的做法，无需每次指令就能推进。

仍然剩下的事

GPTs 是“一项任务的格式”。决定从哪里开始的是你，粘贴转写、把写好的文字搬到该去的地方、下次会议再打开同一个 GPT 的，也是你。在长对话中，最初的指令会失效，有时还得在新对话里重来。

在工作中使用 ChatGPT 前要调整的5项设置不用于训练、自定义指令、项目、记忆、存放位置
  1. 确认“不用于训练”的设置 默认开启
    设置 → 数据控制 → 关闭“为所有人改进模型”。Free、Go、Plus、Pro 等个人套餐默认开启，输入客户名称或金额之前请先确认。Business 和 Enterprise 的业务数据默认不会用于训练。
  2. 在自定义指令中写下你的标准。职业、行业、常写的文档、想避免的说法。写下“邮件用敬语，先说结论”这类你在做好工作时遵守的标准。
  3. 用项目按案子分开。按客户或项目把资料和对话放在一起，Chat 和 Work 都能基于同样的前提工作。
  4. 决定记忆的范围。开启记忆后，它会参考过去的对话作答，但你可能不希望它记住客户名称或金额。先决定是限定在项目范围内，还是关闭。
  5. 决定回答的存放位置和下一项工作的起点。不要复制完回答就结束，而是决定放在 Notion、Google 云端硬盘还是 Slack。定好存放位置，就是把 SIMY 与工作连起来的入口。

提要求的格式：目的、对象、结构、限制

请它写邮件等内容时，先写清这4点再提要求，返工会更少。

例：“目的：重新约会议时间。对象：客户公司的部长。结构：致歉→3个候选时间→请求回复。限制：200字以内，用敬语”。

即便如此，写好格式再提要求的，每次都还是你。SIMY 从会议和聊天中找出“给谁、发什么”，按你的格式推进到草稿。

ChatGPT Work 的用法

ChatGPT Work 是2026年7月9日发布、面向耗时较长的复杂工作的智能体。它跨越已连接的应用和文件进行调研与分析，完成文档、电子表格、演示文稿、报告和 Sites。从以前的“智能体模式”开始的、由 ChatGPT 自己推进工作的做法，如今由 Work 承担。

  1. 把模式切换到 Work。桌面应用从左上角菜单选择，网页和手机从下拉菜单选择。桌面应用支持 macOS 和 Windows。
  2. 选择运行位置。想让它使用电脑里的文件和应用时，打开“Work locally”。想在合上电脑后继续运行，就在云端执行。
  3. 连接插件。Slack、Google Drive、邮件、日历等通过插件连接。以前的 App Directory 已被 Plugin Directory 取代。
  4. 在指令中写明“停下的条件”。像“填入报价金额之前停下，请我确认”这样，预先定好希望你批准的节点，返工会更少。
  5. 确认计划并批准。Work 会先给出工作计划再动手。回答中途的提问，并批准重要操作。

Scheduled Tasks 与用量额度

Work 可以预约一次性执行、每周一9点这样的重复执行，以及变更监控。2026年8月以后，还能通过所支持插件的 MCP 事件触发自动化。Work 和 Codex 使用同一份用量额度，每5小时有上限。Pro 是 Plus 的5倍，Business 的高级席位没有每5小时的上限。Work 本身不另收费。

与 SIMY 的关系：Work 和 Codex 是“把交代的那一件事做完的执行者”，SIMY 是“从会议和聊天中接手工作、驱动执行者、只交还判断的管理者”。SIMY 以 Codex 为执行者，所以两者不是替代关系，而是叠加使用。

安全、防泄露与公司内部指引训练设置、共享链接、插件权限、SIMY 的做法
  • 是否用于训练：Business 和 Enterprise 的业务数据默认不会用于模型训练。个人套餐默认开启，请在设置 → 数据控制中关闭“为所有人改进模型”。
  • 泄露的主要途径：对话的共享链接、放任不管的训练设置、授予插件的权限、本地执行时允许访问的文件范围。先把这4项定下来。
  • Work 的权限：Work Cloud、Work Local、Codex Local 可以分别设置。企业套餐请遵循工作区管理员的策略。
  • 指引中应包含的5项：可输入信息的分级、训练设置、共享链接的处理、插件与本地执行的许可范围、成果的确认负责人。
  • SIMY 的做法：Gmail 只保存到草稿。发布到 Slack 和写入 Notion 需要你的批准。根据电脑上的对话记录生成建议时，对话正文也不会保存到服务器。详情公开在安全和隐私政策中。
02 / AFTER THE ANSWER

用完 ChatGPT，是不是这样？

答案已经拿到了。可关掉 ChatGPT 标签页之后，发生的却是这些。

1 刚拿到答案 复制粘贴，再切回去

复制回答，贴到邮件、Notion、Slack。放哪儿，每次都得自己定。

2 下一个项目 每次同样的开场白

“按我们的格式”“用敬语，先说结论”。指令和数据，在新对话里再来一遍。

3 发送之前 最后还是自己改

把粗略的文字改成自己的说法。拍板、挑选、确认的，只有你自己。

问了就答，要了就做。可“开口去要”和“切回去”，仍然是你的工作。

  1. 调整好 ChatGPT 的设置确认不让数据用于训练的设置和自定义指令。Plus 及以上即可使用 Codex。5项设置见下文。
  2. 把 ChatGPT 账号连接到 SIMY在连接页面点击“连接”即可。连接方法见上文。
  3. 开完一场会议工作会从 Slack 或 Plaud 中被接手，草稿随后送到。审阅，发送，仅此而已。

注册流程：选择套餐 → 邮件验证身份 → 银行卡付款。没有免费套餐。查看价格。电脑端应用请从下载页面获取。

在电脑上使用 Codex 或 Claude Code 的人，SIMY 的桌面应用或 CLI 会根据电脑上的对话记录，生成 WorkFlow 候选“来自 SIMY 的建议”。对话正文不会保存到服务器。

09 / FAQ

常见问题

有没有办法不用每次都给ChatGPT写同样的指令？

在ChatGPT内部，自定义指令、项目和GPTs是三种“不必每次都写”的办法。不过，它们都要由你来启动，并在返回所请求的那一个回答时结束。从会议和聊天中接手工作、按你的做法推进、只交还判断的是SIMY；它不是替代ChatGPT的这些技巧，而是叠加使用。

如何设置让ChatGPT不把输入内容用于训练（关闭训练）？

打开设置，在“数据控制”中关闭“为所有人改进模型”。个人套餐（Free、Go、Plus、Pro）默认是开启的，输入客户名称或金额之前请先确认。Business和Enterprise的业务数据默认不会用于训练。

免费套餐能用GPTs吗？能创建吗？

免费套餐也可以使用GPT商店里的GPTs，但自己创建GPTs需要Plus及以上的付费套餐（截至2026年10月）。

创建仅限公司内部的GPTs，需要什么套餐？

只在工作区内共享的GPTs，可以用Team或Business及以上的企业套餐创建。用个人套餐创建的GPTs，只能分享给知道链接的人或公开给所有人。

ChatGPT的Go和Plus，该选哪个？

核对于2026年10月3日：Free和Go正在逐步提供桌面应用中的GPT-6 Luna，使用Standard速度。可用入口、模型和额度与Plus及更高方案不同。API密钥使用另行计费。SIMY云端连接的条件需要单独确认。

ChatGPT Work是什么？

这是OpenAI于2026年7月9日发布、面向耗时较长的复杂工作的智能体。它跨越已连接的应用和文件进行调研与分析，完成文档、电子表格、演示文稿、报告和Sites。还可以通过Scheduled Tasks执行一次性、重复和变更监控等任务。

ChatGPT Work和Codex有什么区别？

Work是完成调研、分析、文档和报告等各类工作成果的智能体，Codex是面向软件开发的智能体。两者共享同一套执行与权限机制和用量额度，GPT-6 Sol和Luna是Work和Codex专用的模型。

ChatGPT Work和SIMY有什么区别？

Work是把你交代的那一件事做到底的执行者。SIMY是从会议和Slack对话中接手工作、按你的做法推进、只交还判断的管理者。SIMY以你ChatGPT账号中的Codex作为执行者，所以两者不是替代关系，而是叠加使用。

ChatGPT Business一个人能用吗？

Business是面向2至200名员工团队的套餐，从一开始就包含管理控制台、SAML/SSO，以及业务数据默认不用于训练的设置。一个人使用时基本选Plus或Pro，个人套餐也可以设置不让数据用于训练。

使用SIMY会额外产生AI使用费吗？

SIMY连接你自己的ChatGPT账号，通过Codex App Server推进工作。Codex的使用在你的ChatGPT套餐范围内进行。SIMY本身的费用请查看价格页面。

ChatGPT以外的AI也能用SIMY吗？

云端执行使用你自己的ChatGPT账号（Codex）。在电脑上，SIMY的桌面应用或CLI除了Codex，还可以让Claude Code担任执行者。当其中一方状态不佳或达到用量上限时，可以作为后备。

能用ChatGPT写Excel公式或宏（VBA、GAS）吗？

能。用中文写出想做的事，它会返回公式或代码，贴到Excel或Apps Script里运行即可。不要粘贴机密数据，也请确认已设置不让数据用于训练。每次都要请ChatGPT做的固定工作，SIMY会从会议和聊天中接手推进。
