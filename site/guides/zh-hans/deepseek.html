01 / REFERENCE

DeepSeek 是什么：用法、模型、API、中文能力、安全性（想深入了解的人）

以下内容，想了解 DeepSeek 本身时再展开。模型名称和规格为 2026 年 10 月的信息。

DeepSeek 是什么：哪国的 AI，谁创立的深度求索。中国杭州公司开发的 LLM

DeepSeek（深度求索）是什么

DeepSeek 是总部位于中国杭州的 DeepSeek 公司（英文正式名称：Hangzhou DeepSeek Artificial Intelligence Co., Ltd.）开发的大语言模型（LLM）及其聊天服务的名称，中文名为“深度求索”。可以通过三种形式使用：免费的聊天（网页和手机应用）、低价的 API，以及公开权重的开放权重模型。

是哪国的 AI

是中国的 AI。隐私政策说明，运营公司是杭州的法人，从用户处收集的信息存储在中华人民共和国境内的服务器上。

由谁创立

DeepSeek 由梁文锋于 2023 年创立。据 Forbes 等媒体报道，他是中国投资公司幻方量化（High-Flyer）的联合创始人。从 R1 起持续公开模型权重，是 DeepSeek 的特点。

三种用法

  • 聊天（网页、应用）：在 chat.deepseek.com 或手机应用上免费对话使用。
  • API：把 DeepSeek 的 API 接入自家系统或开发工具，按用量付费。
  • 开放权重：把在 Hugging Face 上公开的模型部署在自有服务器或电脑上运行，数据不必外传。
DeepSeek 冲击是什么：发生了什么2025 年 1 月。低成本打造的高性能模型震惊世界

“DeepSeek 冲击”指 2025 年 1 月 DeepSeek 发布推理模型“DeepSeek-R1”之后引发的风波。性能接近美国顶级模型，又能在免费应用中使用，加上据报道以很少的费用和算力训练而成，它登上了日本和美国 App Store 的榜单前列。

  • 对市场的影响：“高性能 AI 需要巨额芯片投入”的前提受到动摇，NVIDIA 等半导体相关股价大幅下跌。
  • 对技术的影响：权重以 MIT 许可证公开，被各家服务和研究广泛采用，推理模型一下子变得触手可及。
  • 对监管的影响：与此同时，数据存储位置以及在政治话题上的回答倾向引发讨论，各国监管机构纷纷发出提醒或采取限制（见下文“安全性”）。

由于 API 便宜且权重开放，DeepSeek 也被嵌入其他公司的服务中，用户可能在不知不觉中间接使用它。工作中用到的工具采用了哪个模型、在哪里运行，事先确认会更安心。

DeepSeek 的用法：网页和手机应用免费。登录后直接对话
  1. 打开 chat.deepseek.com。浏览器即可使用。手机上有 iOS 和 Android 的“DeepSeek”应用。
  2. 登录。创建账户后，对话记录会被保留。
  3. 开始提问。可以用中文提问。还能附上文件或图片，请它“总结一下”“做成表格”。
  4. 选择模式。输入框附近可能会显示深度思考模式或联网搜索的开关（名称会随时间变化）。
  5. 检查训练设置。在设置中关闭“Improve the model for everyone”（撰写时的名称），即可要求不将输入内容用于模型训练。

截至 2026 年 10 月，未发现 DeepSeek 聊天有面向个人的付费方案。

工作中使用的诀窍

  • 先定好输入什么：先从公开信息和一般性问题入手，定下“不输入内部机密”再用，就不会犹豫（见下方判断表）。
  • 先说清角色和输出形式：像“面向管理层会议，三行，附依据”这样，一开始就写明给谁、要什么，返工会少很多。
  • 答案要核实：数字、专有名词、法规和规格的描述，请对照原始资料后再用。

把这样得到的答案变成“谁、在什么时候之前、做什么”并持续跟进，是 DeepSeek 之外的工作。如果这些每次都是你自己在做，请看看SIMY 的连接方法。

DeepSeek 的 API：兼容 OpenAI 与 Anthropic价格随时段变化。金额以官方页面为准
  • 兼容 OpenAI：把接入地址设为https://api.deepseek.com，就能从 OpenAI 的 SDK 或现有工具调用。官方更新日志中也记载了对 Responses API 和 Codex 的支持。
  • 兼容 Anthropic：使用https://api.deepseek.com/anthropic，可以把 Anthropic 格式工具（如 Claude Code）的接入地址换成 DeepSeek。
  • 计费方式：以每 100 万 token 的美元价格按用量计费。与上一次请求前缀相同、可复用的输入（缓存命中）非常便宜，输出则比输入贵。
  • 高峰时段翻倍：工作日高峰时段（UTC 1～4 点、6～10 点，即北京时间 9～12 点、14～18 点；中国法定节假日除外）的单价是非高峰时段的 2 倍。这与白天的工作时间重叠，大批量处理错开时段可以节省费用。

具体单价调整频繁，请以DeepSeek 官方价格页面为准。

开始使用 API 的步骤

  1. 在 DeepSeek 的 API 开放平台创建账户并充值。
  2. 创建 API 密钥。请把密钥放进环境变量，不要直接写在代码或共享文档里。
  3. 替换接入地址和模型名。使用 OpenAI 格式时，指定接入地址的 URL 和deepseek-flash等模型名。
  4. 先定好发送哪些数据，再扩大规模。发送到 API 的内容同样按隐私政策处理。请对照公司内部规定后，再扩大到正式的用量。

与 SIMY 的关系：目前，SIMY 不接入 DeepSeek 的 API 密钥。SIMY 的云端执行使用你的 ChatGPT（Codex）账户运行。

在本地运行 DeepSeek：Ollama、vLLMR1 小型版可在电脑上运行。V4.1-Flash 在 Ollama 上是 cloud
  • 能在电脑上运行的：Ollama 的deepseek-r1有 1.5B 到 671B 多种规模，7B 版约 4.7GB。用ollama run deepseek-r1:7b这样指定规模来运行。
  • 在 Ollama 上也是 cloud 的：deepseek-v4.1-flash和deepseek-v4-pro在 Ollama 官方库中只有 cloud 标签。它们在 Ollama 的云端运行，并不能在本机完成全部处理。
  • 想在公司内部运行最新版：V4.1-Flash 的权重已在 Hugging Face 公开，可以用 vLLM 或 SGLang 运行。但前提是有大规模 GPU 服务器。

如果目的是“数据不外传”，只有在本机或自有服务器上运行权重的方式才符合。cloud 标签的模型，即使名字出现在 Ollama 上，也不能用于这个目的。原理在中国 AI（LLM）对比的“在 Ollama 上，不代表能在本机运行”一节中有说明。

内存需求和量化方式的选择，也可以参考本地 LLM 运行方法（Qwen 篇）。

DeepSeek 的中文能力：能用到什么程度可以用中文提问、摘要、起草

DeepSeek 的模型卡没有列出支持的语言，但实际上可以用中文提问，并得到中文回答。

  • 擅长的：用中文回答问题、总结长篇资料、起草邮件和报告、解释代码。
  • 需要注意的：专有名词、细腻的措辞，以及法规和商业惯例的描述，请核实后再用。
  • 小模型的情况：在本地运行的 R1 小型版，有时行文不够自然，或思考过程以英文输出。

语言质量如何，用实际的业务文档小范围试一试最可靠。

DeepSeek 的安全性：日本及各国的提醒不是禁止，而是要求在了解风险的基础上判断

数据存储位置与训练

DeepSeek 的隐私政策（2026 年 2 月 10 日更新）说明，收集的信息存储在中华人民共和国境内的服务器上。政策也写明了拒绝将输入内容用于模型训练的权利，可以在应用设置中关闭。即使关闭，存储位置也不会改变。

日本监管机构的提醒

  • 日本个人信息保护委员会（2025 年 2 月 3 日，3 月 5 日更新）：发布了“关于 DeepSeek 的信息提示”。其中指出，DeepSeek 获取的包含个人信息的数据存储在中国的服务器上，并适用中国的法律（个人信息保护法、数据安全法、国家情报法等）。
  • 日本数字厅（2025 年 2 月 6 日）：数字社会推进会议干事会面向政府机关发出了“关于 DeepSeek 等生成式 AI 业务使用的提醒”。据报道，内容以 DeepSeek 为例指出同样的风险，要求原则上不处理机密信息，使用时须评估风险后再作判断。这并非一律禁止使用的措施。

截至 2026 年 10 月，日本没有禁止个人使用 DeepSeek 的法律或命令。如果所在公司或客户另有使用规则，请以其为准。

各国的应对（据报道）

  • 意大利：2025 年 1 月，个人数据保护机构采取措施，使应用无法使用。
  • 澳大利亚：2025 年 2 月，禁止在政府设备上使用。
  • 韩国：2025 年 2 月，根据个人信息保护委员会的措施，应用暂停新的下载。
  • 德国：2025 年 6 月，数据保护机构要求 Apple 和 Google 从应用商店下架该应用。

这些措施大多针对政府设备或个人数据的处理，各国的理由不尽相同。也有观点指出其在政治话题上的回答存在倾向，因此调研这类话题时，参考多个信息来源较为稳妥。

各国的应对为基于报道的摘要。最新情况请以各国监管机构的公告为准。SIMY 的数据处理方式，公开在安全和隐私政策中。

02 / AFTER THE ANSWER

DeepSeek 给出答案之后，是不是这样？

调研、草稿，DeepSeek 又便宜又快就给出来了。可之后发生的，是这些。

1 调研完的第二天 那么，谁来做？

对比表做得很漂亮。可会上定下的待办，谁的笔记里都没有。

2 跑了一周 API 结果四处散落

低价 API 产出了一大堆方案。选中的方案和下一步，埋在日志和聊天里。

3 想在公司推广的那个月 卡在等确认

本该找 IT 部门确认能用到什么程度，结果连问没问过都说不清了。

给出答案，DeepSeek 一瞬间就完成。工作能不能推进，取决于答案之后。

03 / WHAT YOU REALLY WANTED

其实，你想要的是这样：DeepSeek 给出答案之后

同一场会议，同一个 DeepSeek。答案出来的那一刻，本该是这样。

✓ 会议一结束 负责人和期限已成清单

调研和草稿照旧用 DeepSeek。决定事项、负责人、期限，已经排好了。

✓ 期限之前 卡住的工作自己找上门

等确认、快到期的工作，SIMY 会在下次会议前先提醒你。

✓ 不管用哪个 AI 结论集中在一处

选定的结论和下一步行动，跨模型、跨聊天，汇总成一份。

! 回到你手上的 只有判断

“按这个方案推进吗？”回来的只有这一个问题。

这些，从把会议和聊天接入 SIMY 后的下一场会议就会发生。DeepSeek 照旧用在它擅长的事上。

09 / FAQ

常见问题

DeepSeek 是什么？

DeepSeek（深度求索）是中国杭州的 DeepSeek 公司开发的大语言模型（LLM）及其聊天服务。可以通过三种形式使用：免费的聊天、低价的 API，以及公开权重的开放权重模型。

DeepSeek 是哪个国家的 AI？

是中国的 AI。运营公司是杭州的法人，隐私政策说明，收集的信息存储在中华人民共和国境内的服务器上。

DeepSeek 是谁创立的？

由梁文锋于 2023 年创立。据报道，他是中国投资公司幻方量化（High-Flyer）的联合创始人。

DeepSeek 冲击是什么？

指 2025 年 1 月推理模型 DeepSeek-R1 发布后，作为低成本打造的高性能模型在全球引发关注的事件。半导体相关股价大幅下跌，也促使各国监管机构就数据处理发出提醒。

DeepSeek 可以免费使用吗？

可以。网页版聊天和手机应用都免费。API 按用量付费。在自己的环境中运行开放权重模型时，不需要支付模型使用费（设备和电费另计）。

DeepSeek 支持中文吗？

支持。官方没有公布支持语言列表，但可以用中文提问并得到中文回答。重要的文稿，请先核对专有名词和措辞再使用。

DeepSeek 的 API 怎么收费？

按用量付费，以每 100 万 token 的美元价格计费。工作日高峰时段的单价是非高峰时段的 2 倍。单价调整频繁，请以 DeepSeek 官方价格页面为准。

DeepSeek 的 API 怎么用？

申请 API 密钥后，把常用工具的接入地址和模型名换成 DeepSeek 的即可。OpenAI 兼容的接入地址是 https://api.deepseek.com，Anthropic 兼容的是 https://api.deepseek.com/anthropic，模型名如 deepseek-flash（截至 2026 年 10 月）。

DeepSeek 能在本地（自己的电脑）运行吗？

R1 的小型版等可以用 Ollama 运行。最新的 V4.1-Flash 在 Ollama 上只有 cloud 标签，无法在本机运行；要在公司内部运行，需要大规模的 GPU 服务器。

DeepSeek 在日本被禁止了吗？

没有。截至 2026 年 10 月，日本没有禁止个人使用的法律或命令。2025 年 2 月，日本个人信息保护委员会发布了信息提示，日本数字厅（数字社会推进会议干事会）向政府机关发出了提醒，指出数据存储在中国的服务器上，并适用中国的法律。

输入 DeepSeek 的内容会被用于训练吗？

可能会。隐私政策写明了拒绝用于训练的权利，可以在应用设置中关闭（撰写时的名称为“Improve the model for everyone”）。即使关闭，数据仍存储在中国的服务器上，因此原则上不要输入机密信息。

SIMY 是用 DeepSeek 运行的吗？

不是。目前，SIMY 通过你的 ChatGPT（Codex）账户和电脑上的 Claude Code 运行。用 DeepSeek 做出的答案和草稿，可以直接带进会议和聊天。

DeepSeek 给出答案之后的工作，需要每次都交代给 SIMY 吗？

不需要。SIMY 会自己从会议记录和聊天中找出决定事项、负责人和期限。它从对话中学习你的做法，只把需要判断的部分交还给你。
