01 / EVERY TIME

用 Claude 时，是不是这样

回答质量没得挑。可关掉 Claude 之后，发生的是这些事。

1 会议结束后 明明存进了项目

纪要模板早已放进项目，粘贴转录稿的却每次都是自己。

2 读完回答后 明明接好了连接器

Gmail 和 Drive 都连上了，开口说“帮我写回复”的还是自己。

3 第二天 判断埋在聊天里

“这个金额行不行”藏在长回答中间，还得翻找是哪一段对话。

回答，Claude 一瞬间就给。开口、粘贴、分享、找出要判断的事，仍然留在你手上。

02 / WHAT YOU REALLY WANTED

其实你想要的是这样：Claude 回答之后

同样的 Claude，同样的会议。走出会议室时，你希望已经变成这样。

✓ 开口之前 没说就已经在动

会议一结束，回复草稿和客户备忘的更新方案已经送到。

✓ 不用下指令 每次都是你的格式

纪要的颗粒度、回复的语气、分享对象。不用调出保存的指令，也是熟悉的样子。

✓ 每周一次 收到建议

“这个流程你每周都在做。”重复的工作会作为 WorkFlow 候选送到你面前。

! 回到你手上的 只有判断

“按这个金额发出去可以吗？”只回来这一个问题，不用再翻聊天记录。

这些，从装上 SIMY 后的下一场会议就会发生。Claude 的用法，一点都不用改。

08 / REFERENCE

Claude 的用法、价格、模型、Cowork（想深入了解的人）

以下内容是想确认 Claude 本身时再展开看的。它们都不影响与 SIMY 的连接。

Claude 是什么：开发公司与能做的事写作、长文摘要、Excel、PDF、代码、调研

开发公司

Claude 由总部位于美国旧金山的 Anthropic 开发。Anthropic 是 2021 年由 OpenAI 前成员创立的 AI 公司。可以通过网页（claude.ai）、Mac／Windows 桌面应用、iOS／Android 应用和 Chrome 扩展使用，直接用中文对话即可。

服务所在地与中文表现

Anthropic 是美国公司，Claude 是运行在云端的服务，只在 Anthropic 支持的国家和地区提供，使用前请先确认你所在的地区。中文的输入和输出都很自然，在商务文书所需的措辞、语气统一等方面也常受好评。把中文转录稿交给它整理成纪要、把英文资料用中文摘要，这些用法免费版就能做到。以公司身份导入时，请通过 Team、Enterprise 的资料确认数据存放位置与合同条款。

工作中能做的事

  • 写作与润色：邮件、提案、报告的草稿。擅长写出礼貌易读的文字。
  • 长文摘要与阅读：一次交给它很长的合同或会议转录稿，就能提取要点和决定事项。
  • 上传文件：可以附上 PDF、Excel、Word、图片来提问。也能用来读表格、整理数字。
  • Artifacts：在界面右侧生成资料、图表或简单的应用，直接编辑后带走。
  • 项目与连接器：把指令和资料存进项目反复使用，并通过连接器接入 Google Drive、Slack 等外部工具来参考。
  • 代码与自动化：Claude Code 从终端操作文件、执行命令；Cowork 则是在桌面上把工作交给它的入口（下文对比）。

每项功能都是“开口就会做”。唯独“开口之前就开始”这一块，留在 Claude 之外。

Claude 的用法：工作中最先做的 5 件事应用、项目、连接器、模型、成果物放哪里
  1. 装好应用，直接用中文说话。网页版 claude.ai 就够用，但装上桌面应用可以用快捷键唤出，Cowork 也从这里使用。手机应用适合路上确认，Chrome 扩展适合让它直接读你打开的网页。
  2. 把指令和资料集中到项目里。把“纪要按这个格式”“回复用这个语气”这类每次都要交代的前提，和需要参考的资料放进项目，新开的对话也会从同样的前提开始。很多人会放入公司术语表或以往的提案。
  3. 用连接器接上要它看的地方。用连接器接入 Google Drive、Gmail、Slack、Notion 等，不用贴文件，就能说“读一下上周 B 公司的纪要”。连接请遵循公司管理员的规定。
  4. 模型先用默认，不够再升级。日常工作默认模型就够了。只有对比长合同、重要提案时，才切换到 Opus。
  5. 定好成果物放在哪里。Claude 的回答留在对话里。事先定好邮件进 Gmail 草稿、纪要进 Notion、分享发 Slack，之后就不用再找。SIMY 接手的，正是这个“搬到该放的地方”的部分。

提示词技巧

先写清角色、目的、读者、格式这四点，回答就更稳定。像“以销售的身份，给 B 公司的部长写一封感谢并约下次时间的邮件，300 字以内”这样，一句话交给它就足够。把原始资料一起给它，能减少编造（幻觉）。

连接器的接入步骤

在左侧“自定义”→“连接器”→“＋”→ 选择 Google 日历等并授权（界面名称可能会变）。

就算连上了，请它去读的还是每次的你。SIMY 从会议和聊天中接活，不需要你先开口。

怎么请它做幻灯片

在横向比较中，Claude 做出的资料往往设计更沉稳。用一句话交代目的、对象、页数和风格。

例：“下周和 B 公司例会，向对方部长汇报本月进展，做 5 页。风格沉稳，数字用表格呈现。”

即便如此，请它做资料的仍是每次的你。SIMY 会接住会议上定下的“做资料”，按你的格式起草，只把确认交给你。

Claude Code、Cowork 与 API 的费用

Claude Code 和 Cowork 包含在 Pro 或 Max 中，不另收月费。不过额度由方案共享，长时间运行 Claude Code 会更快触顶。Max 就是把这一额度扩大到 Pro 数倍到数十倍的方案。开发者通过程序调用的 API 与方案分开，按用量计费，不同模型单价不同。公司要用 API，请先估算每月用量再选择。

免费版的限制

免费版在一定时间内的使用次数有上限，高峰时段会更早触顶。如果反复让它读长文件，上午就可能用完。工作中天天用的话，Pro 是现实的起点。

SIMY 的费用与 Claude 的方案分开计算。SIMY 本身的价格请见价格页面。SIMY 云端执行所用的 Codex，在你自己的 ChatGPT 方案范围内计用量。换句话说，这笔支出不是“升级 Claude 方案”，而是“减少回答之后的工作”，单独考虑会更清楚。

Cowork 的用法（写给非工程师）

Cowork 是 Anthropic 在 2026 年推出的桌面端功能，作为“把工作交给 AI”的入口，在非工程师中迅速普及。聊天是“问了才答”的对象，Cowork 则是“交代了就动手”的对象。它常被拿来和 Copilot 的同类功能比较，两者都以电脑内的文件和定时任务为主。

在桌面应用中打开 Cowork，选择允许它操作的文件夹，然后像“用这个发票文件夹做一张清单”这样用中文交代。Cowork 会读取文件，必要时操作浏览器，再把结果存进文件夹。每周相同的作业可以登记为定时任务，到点就执行同样的指令。需要付费方案和桌面应用，截至 2026 年 10 月支持 Mac 和 Windows。

Claude Code 的用法（第一步）

在终端启动 Claude Code，指定工作文件夹，然后说“把这个 CSV 按月汇总”。改写文件或执行命令前会请求确认，请读过内容再允许。用它把会计软件的报销录入、日报自动化的非工程师案例也越来越多，但扩大权限的设置（跳过确认）一开始最好不要用。

Cowork 和 SIMY 并不冲突。用 Cowork 清空桌面上的工作，会议和聊天中产生的“之后的工作”交给 SIMY。SIMY 从 Claude Code 的对话中学习重复的步骤，用 Codex（ChatGPT）或 Claude Code 都能执行同一个 WorkFlow。Cowork 的详细用法整理在Claude Cowork 使用指南里。

例：把报销录入会计软件的工作自动化

  1. 把信用卡账单导出到电子表格。
  2. Claude Code 分成“报销／排除／无法判断”三类。
  3. 只有“无法判断”的由本人确认。
  4. 把确定的部分录入会计软件。

在介绍的案例中，每月 2 小时缩短到了约 10 分钟（仅为一例）。“只把无法判断的交还给人”，和 SIMY 的“只把判断交给你”是同一个形状。SIMY 把起点扩展到了会议和聊天。

做技能：省去每次说明的操作手册

最先做起来最方便的，是把语音输入整理成通顺文字的“写作技能”、记录反馈的“备忘技能”，以及资料的“设计技能”。

  1. 先当着 Claude 的面把做法演示一遍。
  2. 让它把这个流程存成操作手册（技能）。
  3. 之后用名字调用即可。

说明可以省掉，但每次调用的仍是你。SIMY 会在你调用之前，从会议和聊天中接住工作。

用 CLAUDE.md 留下做法

  • CLAUDE.md：每次都要遵守的规则。
  • progress.md：工作进度。
  • 其他文件：其余知识和资料。

写下来、存起来的工夫，留在你身上。SIMY 不用你写，也会从对话中学习做法（SIMY 桌面应用会导入 Claude Code 的对话）。

不用于训练的设置与安全Claude 侧的设置，以及 SIMY 侧的承诺

Claude 侧

  • 不用于训练的设置：个人方案（Free、Pro、Max）可以在设置的隐私项中，自己选择对话是否用于改进模型。用于工作前请先确认一次。
  • Team、Enterprise、API：合同约定输入数据默认不用于模型训练。处理机密信息或合同，原则上选这类方案。
  • Claude Code 的权限：它能读写文件、执行命令，请把工作文件夹分开，并保持“需要确认”的设置。
  • 机密信息与合同：放入含客户名称或金额的资料前，请确认公司的信息管理规定和所用方案的合同条款。原则是不要用个人账户处理公司机密。
  • 防范编造（幻觉）：把原始资料一起交给它，数字和专有名词请与原资料核对后再用。发送前的确认，无论哪个方案都是人的工作。

SIMY 侧

  • 不保存对话正文：Claude Code 和 Codex 的对话记录只在分析期间使用，SIMY 保留的只有抽象化的步骤、确认事项和完成条件。
  • 期限与停止：默认读取 90 天的记录，可在设置中停止。停止后，派生数据也会删除。
  • 对外写入需要批准：Gmail 只到保存草稿为止。发布到 Slack、写入 Notion，都会等你批准。
  • Delivery Loop 的钩子：Claude Code 侧的插件不会上传对话、令牌或提示词。
  • CLI 会话：SIMY 桌面应用的登录 48 小时后失效，需要重新登录。删除账户时，个人工作区也会一并删除。

详情请见安全、隐私政策和使用条款。

09 / FAQ

常见问题

Claude 是哪家公司开发的？能在哪里使用？

开发公司是总部位于美国旧金山的 Anthropic。在 Anthropic 支持的国家和地区，可以通过网页、桌面应用、手机应用和浏览器扩展用中文使用。

Claude 免费版能在工作中用到什么程度？

写作和摘要、附文件提问、用 Artifacts 做资料，免费版都能用。使用次数有上限，高峰时段更早受限。Claude Code 和 Cowork 需要付费方案。

Opus、Sonnet、Haiku、Fable 该怎么选？

日常工作用 Sonnet，复杂判断和读长资料用 Opus，想快速跑短小的固定处理用 Haiku，需要最新综合能力用 Fable。拿不准就先用默认模型，只在回答不满意时切换到更高的模型。

Claude Cowork 是什么？和 Claude Code 有什么不同？

Cowork 是在桌面应用中，借助电脑内的文件和浏览器把工作交给 Claude 的功能，擅长桌面上的指令和定时任务。Claude Code 是从终端在电脑上执行命令和文件操作的执行者。两者都需要付费方案。

非工程师也能安全地使用 Claude Code 吗？

可以，但它拥有改写和删除文件的权限，一开始请在专用文件夹中、保持“需要确认”的设置使用。作为 SIMY 的执行者时，对外发送或发布也需要你的批准。

ChatGPT 和 Claude，工作中用哪个好？

以阅读和撰写长文档为主选 Claude，想把图像生成和广泛连接都放在一个工具里选 ChatGPT，这是常见的选法。无论用哪个，SIMY 都用同样的方式推进回答之后剩下的工作。

有没有让 Claude 不用我的输入来训练的设置？

有。个人方案可以在设置的隐私项中自己选择是否用于改进模型；公司使用请考虑 Team 或 Enterprise。SIMY 只在分析期间使用 Claude Code 的对话正文，不保存在服务器上。

使用 SIMY 需要 Claude 的付费方案吗？

只用 SIMY 的话不需要。装上 SIMY 桌面应用后，可以把 Claude Code 的对话导入 SIMY，并从 SIMY 驱动 Claude Code。这时使用的是你自己的 Claude Code 登录和方案。唯一做不到的，是把 Claude 的令牌（方案的用量额度）接入 SIMY 的云端执行。云端执行使用你自己的 ChatGPT 账户（Codex），Gemini 的令牌联动正在开发中。

Claude 出故障或达到用量上限时，工作会停吗？

不会停。SIMY 可以让 Codex（ChatGPT）和电脑上的 Claude Code 都作为执行者，一方不能用时由另一方继续。两边的用量都在各自方案的范围内计算。

Claude Cowork 和 SIMY 有什么不同？能一起用吗？

Cowork 在 Claude 中推进你在桌面上交代的工作和定时任务。SIMY 在你开口之前，就接住会议和聊天中产生的工作，按你的做法推进，只把判断交给你。两者可以一起用，Cowork 完成的成果之后的部分由 SIMY 接手。

Claude Code 的对话变成“来自 SIMY 的建议”之前，会发送什么？

SIMY 桌面应用默认读取电脑内 90 天的 Claude Code 和 Codex 对话记录，把重复的步骤和确认事项抽象化，生成 WorkFlow 候选。对话正文只在分析期间使用，不会留在服务器上。这项导入随时可以在设置中停止。

我每周都用同样的步骤分享和记录 Claude 写的草稿，能自动化吗？

可以。SIMY 会从对话中学会这个步骤，并作为 WorkFlow 提出建议。批准后，下次起就以会议或聊天为起点自动推进：Gmail 只到保存草稿为止，写入 Slack 或 Notion 会等你批准。
