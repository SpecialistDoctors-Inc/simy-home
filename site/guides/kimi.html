01 / REFERENCE

Kimiとは・Kimi K3とは：使い方・API・Kimi Code・データの扱い（詳しく知りたい人向け）

ここから下は、Kimi本体のことを確かめたいときに開いてください。モデル名と仕様は2026年10月時点の情報です。

Kimiとは：どこの国のAIか（Moonshot AI）中国・北京のMoonshot AI（月之暗面）が開発するAI

Kimiの開発元

Kimi（キミ）は、中国・北京のAI企業Moonshot AI（月之暗面）が開発するチャットAIと、大規模言語モデル（LLM）のシリーズです。中国向けのKimiは北京の法人が運営し、海外向けのAPI（Kimi Open Platform）はシンガポールの法人MOONSHOT AI PTE. LTD.が提供しています。

3つの使い方

  • Kimiのチャット：kimi.comとスマホアプリで話しかけて使う。無料で始められ、有料の会員プランもあります。
  • API：Kimi Open Platformで自社のシステムや開発ツールに組み込む。使った分だけ支払います。
  • オープンウェイト：Hugging Faceで公開されたモデルの重みを、自社のサーバーで動かす。ライセンスの条件があります。

Kimiの特徴

長い文脈をまとめて扱えることと、コーディング向けの道具がそろっていることが特徴です。最新のKimi K3は100万トークンの文脈を扱い、文章だけでなく画像や動画も入力できます。ターミナルで動くKimi Code CLIも公開されています。

「Kimi」で検索すると、F1ドライバーのアンドレア・キミ・アントネッリなど同じ名前の話題も出てきます。このページで扱うのは、Moonshot AIのKimiです。

Kimiのチャットの使い方：Webとアプリ無料で始められる。会員になると利用枠が増える
  1. kimi.comを開く。ブラウザから使えます。スマホ用のアプリもあります。
  2. ログインする。アカウントを作ると、会話の履歴が残ります。
  3. 話しかける。日本語で質問できます。PDFや画像を添えて「要点を表にして」「この図を説明して」と頼めます。
  4. 長い資料をまとめて渡す。複数のファイルを一度に読ませて、比べたり要約したりする使い方がKimiの得意分野です。

有料の会員プラン

Kimiの有料会員はクレジット制で、公式ヘルプでは月額4段階のプランが案内されています（2026年10月時点）。どのプランでもKimi K3を使え、Kimi Codeの利用枠もついてきます。価格は地域と通貨で表示が違うため、公式の会員プランのページで確認してください。

仕事で使うときのコツ

  • 読ませる前に、聞きたいことを書く：「この契約書で、解約条件と違約金だけを抜き出して」のように目的を先に伝えると、長い資料でも答えがぶれにくくなります。
  • 出典の箇所を聞き返す：要約の数字や条件は「何ページのどこに書いてある？」と確かめてから使ってください。
  • 案件ごとに会話を分ける：前の資料に引きずられた答えを避けられます。

こうして出した要点を「誰が・いつまでに・何をするか」に変えて追いかけるのは、Kimiの外の仕事です。そこを毎回自分でやっているなら、SIMYのつなぎ方を見てください。

Kimiでできること：仕事での使い道長い資料、複数のファイル、コード。得意な場面から試す
  • 長い資料の読解：契約書、仕様書、調査報告書など、長い資料をまとめて読ませ、条件や論点を抜き出す。
  • 複数の資料の比較：見積書や提案書を何通も渡し、違いを表にまとめる。
  • 画像・動画の理解：画面のスクリーンショットや図、短い動画を見せて、内容を説明させる。
  • コーディング：Kimi Codeやエディタから、コードの読解、修正、テストの追加を任せる。
  • 下書き：報告書、メール、議事メモのたたき台を作る。

試す順番

最初は、手元にある長い資料を1つ選び、「この資料で決めなければいけないことを3つ挙げて」と頼むと、Kimiの得意な場面がつかみやすくなります。慣れてきたら、複数の資料の比較や、コードの作業に広げてください。

どの使い道でも、Kimiが出すのは「答え」や「下書き」までです。それをもとに会議で決めた担当や期限、関係者への連絡は、SIMYが会議とチャットから拾って進めます。

Kimi K3とは：K2との違いと主なモデル2026年10月時点。名前と世代は頻繁に変わる

Kimi K3は、2026年7月に公開されたKimiの最新世代のモデルです（2026年10月時点）。総パラメータは2.8兆で、1回の処理ではそのうち1,040億だけを使うMoE（得意分野の違う小さなモデルを切り替えて使う構成）です。100万トークン（トークンは文字数の目安になる単位）の文脈と、テキスト・画像・動画の入力に対応します。

K3とK2、どちらを使うか

  • K3：長い資料を読ませたい、画像や動画も一緒に扱いたい、難しい作業を任せたいとき。
  • K2系：コードの生成を安く大量に回したいとき。K2.6以前の公開モデルは、ライセンスの条件もK3より緩やかです。

名前の覚え方：Kimiのモデル名は数か月ごとに変わります。「最新の主力（K3）」「コーディング向けで安い（k2.7-code）」の役割で覚えておけば足ります。

Kimi Code CLI：ターミナルで動くコーディングエージェントオープンソース（MIT）。会員プランの利用枠でも使える

Kimi Code CLIは、Moonshot AIがMITライセンスで公開しているコーディングエージェントです。ターミナルで動き、コードを読んで修正し、コマンドを実行します。MCP（外部のツールやデータとつなぐ共通の仕組み）に対応し、ACP（エディタからエージェントを呼び出す仕組み）でZedやJetBrainsなどのエディタからも使えます。以前のPython版のkimi-cliはアーカイブされ、こちらに置き換わりました。

  • インストール：公式のインストールスクリプトのほか、npmでも入れられます。手順はGitHubのページにあります。
  • ログイン：起動して/loginを実行し、Kimi CodeのアカウントかKimi Open PlatformのAPIキーを選びます。会員プランの人は、プランの利用枠で使えます。
  • 向いている人：Claude CodeやCodexと同じ使い方を、Kimiのモデルで試したい開発者。

使い始めの流れ

  1. 作業したいフォルダでKimi Codeを起動する。最初にログインの方法を選びます。
  2. やりたいことを日本語で伝える。「このリポジトリの構成を説明して」「落ちているテストを直して」のように、目的から頼みます。
  3. 変更は確認してから受け入れる。ファイルの書き換えやコマンドの実行は、内容を見て許可します。

Kimi Codeで書いたコードのあと、レビューの会議で決まった修正や担当の割り振りは、SIMYが会議から拾って一覧にします。

KimiのAPI：Anthropic互換でClaude Codeからも使えるOpenAI互換とAnthropic互換。料金は100万トークンあたりの米ドル
  • 入口：Kimi Open Platform（platform.kimi.ai）でAPIキーを発行します。提供元はシンガポールの法人です。
  • 互換性：OpenAI互換とAnthropic互換のエンドポイントがあります。OpenAIのSDKや、Anthropic形式で話すツールの接続先を差し替えて使えます。
  • Claude Codeから使う：Claude Codeの接続先（ANTHROPIC_BASE_URL）とAPIキーをKimiのものに変えると、Claude Codeの画面のままKimiのモデルを呼べます。手順は公式ドキュメントで案内されています。
  • 料金：2026年10月時点で、Kimi K3は100万トークンあたり入力3.00ドル・出力15.00ドル（税別）。同じ前置きを再利用するキャッシュは、読み出しが0.30ドルと安く、書き込みは保持時間に応じて別料金です。最新の単価は公式の料金ページで確認してください。

APIを使い始める手順

  1. Kimi Open Platformのアカウントを作る。コンソールでチャージや支払い方法を設定します。
  2. APIキーを発行する。キーは環境変数に入れ、コードや共有ドキュメントに直接書かないでください。
  3. 使い慣れたツールの接続先を変える。OpenAI形式かAnthropic形式かを選び、URLとモデル名を差し替えます。
  4. 小さく試して、使用量を見る。長い文脈はトークンを多く使います。日々の使用量を確認してから本番の量に広げてください。

SIMYとの関係：SIMYは現時点ではKimiのAPIキーを接続しません。SIMYのクラウド実行は、お使いのChatGPT（Codex）アカウントで動きます。

オープンウェイトとライセンス：K3は条件つき「オープンソース」と一括りにしない

Kimi K3のモデルの重みはHugging Faceで公開されていますが、ライセンスは独自の「Kimi K3 License」です。利用・改変・再配布はできますが、事業の規模に応じた条件がついています。

  • モデルを提供する事業：K3をサービスとして提供し、直近12か月の売上が2,000万ドルを超える場合は、Moonshot AIとの別途の商用契約が必要です。
  • 大きな製品：月間利用者が1億人を超えるか、月間売上が2,000万ドルを超える製品では、画面に「Kimi K3」と表示する必要があります。
  • K2.6以前：Modified MITライセンスで、K3より条件が緩やかです。

多くの会社にとって、社内で使う範囲では大きな制約になりにくい条件です。ただし製品に組み込む場合は、ライセンスの本文を確認してください。

Kimiをローカルで動かせるか：Ollamaはcloudタグ「Ollamaで使える」は「手元のPCで動く」とは限らない

Ollamaの公式ライブラリにあるkimi-k3、kimi-k2.7-code、kimi-k2.6は、2026年10月時点ですべて「cloud」タグです。これはOllamaのクラウドで動くという意味で、手元のPCでモデルが動くわけではありません。入力はOllamaのサーバーに送られます。

  • 自社サーバーで動かす：公開された重みをvLLMやSGLangで動かせます。K3は2.8兆パラメータの大規模構成で、複数の高性能GPUを前提にしたサーバー向けです。
  • 個人のPCで動かしたい：Kimiの最新モデルは現実的ではありません。手元で動く中国系のモデルなら、Qwenの中小規模のモデルなどが選択肢になります。

「データを外に出したくない」が目的なら、cloudタグのモデルは当てはまりません。自社のサーバーで重みを動かすか、手元で動く大きさのモデルを選んでください。

Kimiの日本語：どこまで使えるか日本語で頼めるが、公式の対応言語の明記はない

Kimiのチャットには日本語で話しかけられ、日本語で答えが返ってきます。ただし2026年10月時点で、K3のモデルカードには対応言語の明記がありません。日本語の品質は公式に保証されたものではないので、実際の業務の文書で試して確かめてください。

  • 試しやすいこと：日本語の資料の要約、英語や中国語の資料を日本語でまとめる、コードの説明を日本語で聞く。
  • 気をつけたいこと：敬語の細かい使い分け、日本の固有名詞、法令や商習慣の記述は、確かめてから使ってください。

小さく試すなら、過去に自分で書いた日本語の報告書を1つ渡し、要約と言い回しの直しを頼んでみてください。元の文章を知っているので、品質の良し悪しを判断しやすくなります。

英語の長い資料をKimiで読み、会議で決めたことの担当と期限、日本語の共有文はSIMYに任せる、という分け方ができます。

02 / AFTER THE ANSWER

Kimiが書き終えたあと、こうなっていませんか

長い資料の読み込みも、コードの修正も、Kimiで一気に終わった。それでも、そのあとに起きていること。

1 長文を読ませた翌日 結論はどこ？

長い資料の要点は出た。でも会議で決めたことは、別のメモに埋もれたまま。

2 Kimi Codeで直した夜 誰がレビューする？

修正はコミットした。レビューの依頼と顧客への連絡は、まだ誰も書いていない。

3 会議で決めた翌週 あれ、どうなった

担当も期限も口頭で決めた。確認するのは、結局いつも自分。

読むのも書くのも、Kimiで一気に終わる。仕事が進むかどうかは、書き終えたあとで決まっています。

03 / WHAT YOU REALLY WANTED

本当は、こうしたかった：Kimiが書き終えたあと

同じ会議。同じKimi。書き終えた瞬間に、こうなっていてほしかった。

✓ 会議が終わったら 修正と担当が一覧に

読解とコードはKimiのまま。決まった修正と担当・期限は、もう並んでいる。

✓ コードを書いたら 依頼文ができている

レビュー依頼と顧客への進捗共有が、あなたの文面で用意されている。

✓ 期限の前に 止まった仕事が届く

返事待ち・レビュー待ちの仕事を、次の会議の前にSIMYが先に知らせる。

! あなたに戻るのは 判断だけ

「リリースを今週にするか」。戻ってくるのはその一問だけ。

これは、SIMYに会議とチャットをつないだ次の会議から起きることです。Kimiは、得意な仕事にそのまま使えます。

09 / FAQ

よくある質問

Kimiとは何ですか？

Kimiは、中国のMoonshot AI（月之暗面）が開発するチャットAIと大規模言語モデル（LLM）のシリーズです。kimi.comやアプリのチャット、API、公開されたモデルの重みの3つの使い方があります。

Kimiはどこの国のAIですか？

中国のAIです。北京のMoonshot AI（月之暗面）が開発し、中国向けのKimiは北京の法人が運営し、海外向けのAPIはシンガポールの法人MOONSHOT AI PTE. LTD.が提供しています。

Kimi K3とは何ですか？

Kimi K3は、2026年7月に公開されたMoonshot AIの最新世代のモデルです（2026年10月時点）。100万トークンの文脈を扱え、テキストに加えて画像と動画も入力でき、重みは独自のKimi K3 Licenseで公開されています。

Kimi K3とKimi K2の違いは？

K3は長い文脈と画像・動画の入力に対応した最新の主力で、独自のKimi K3 Licenseで公開されています。K2系はひとつ前の世代で、コーディング向けのk2.7-codeはAPIの単価がK3より低く設定されています。

Kimiは無料で使えますか？

kimi.comとアプリのチャットは無料で始められます。利用枠を増やす有料の会員プランがあり、APIは使った分だけの従量課金です。

Kimi Codeとは何ですか？

Moonshot AIがMITライセンスで公開している、ターミナルで動くコーディングエージェントです。Kimi CodeのアカウントかAPIキーでログインして使い、会員プランの利用枠でも使えます。

KimiのモデルをClaude Codeから使えますか？

使えます。KimiのAPIにはAnthropic互換のエンドポイントがあり、Claude Codeの接続先とAPIキーを差し替える手順が公式に案内されています。

Kimiはローカル（自分のPC）で動かせますか？

最新のKimi K3を個人のPCで動かすのは現実的ではありません。Ollamaの公式ライブラリのKimiはcloudタグで、Ollamaのクラウドで動きます。自社で動かすなら、公開された重みを高性能なGPUサーバーで運用します。

Kimiに入力した内容はどこに保存されますか？

公式の説明では、Kimiのチャット（中国語のヘルプ）は中国国内のサーバー、海外向けのAPIはシンガポールのサーバーに保存するとされています。機密を扱う場合は、社内ルールと各ポリシーの本文を確認してください。

Kimiは日本語に対応していますか？

日本語で質問し、日本語で答えを受け取れます。ただし公式のモデルカードに対応言語の明記はないため、業務の文書で品質を確かめてから使ってください。

SIMYはKimiで動きますか？

いいえ。SIMYは現時点ではKimiに接続せず、お使いのChatGPT（Codex）アカウントと、PC上のClaude Codeで動きます。Kimiで作った要点やコードは、そのまま会議やチャットに持ち込めます。

Kimiで書いたあとの仕事は、毎回SIMYに頼む必要がありますか？

いいえ。SIMYは会議の記録やチャットから、決まったことと担当・期限を自分で拾います。あなたのやり方を会話から学び、判断が必要なところだけをあなたに返します。
