01 / REFERENCE

Qwen, c'est quoi : utilisation, modèles, API, exécution locale, sécurité (pour aller plus loin)

Ouvrez les sections ci-dessous pour vérifier un point sur Qwen lui-même. Noms de modèles et caractéristiques : informations d'octobre 2026.

Qwen, c'est quoi : nom et origineUne IA chinoise, développée par le groupe Alibaba

Prononciation et nom complet

Qwen se prononce généralement « kouène ». Son nom chinois complet est Tongyi Qianwen (通义千问), dont Qwen est l'abréviation. Le nom désigne à la fois l'IA conversationnelle et toute une famille de grands modèles de langage (LLM) qui traitent texte, image, audio et code.

Une IA de quel pays ?

Qwen est une IA chinoise, développée par l'équipe Qwen du groupe Alibaba. La version internationale de Qwen Chat (chat.qwen.ai) est fournie par Alibaba Cloud (Singapore), une société de Singapour, et sa politique de confidentialité indique que les saisies sont traitées à Singapour. L'API est proposée via Model Studio d'Alibaba Cloud, avec plusieurs régions au choix, dont Tokyo.

Trois façons de l'utiliser

  • Qwen Chat : gratuit, dans le navigateur ou l'application mobile. Idéal pour les recherches personnelles et la traduction.
  • API : via Model Studio d'Alibaba Cloud, à intégrer dans vos systèmes et outils. Vous payez ce que vous consommez.
  • Poids ouverts : les modèles (fichiers de poids) publiés sur Hugging Face ou ModelScope tournent sur votre ordinateur ou votre serveur. Vos données ne sortent pas.

Ce que Qwen sait faire

  • Chat : réponses aux questions, rédaction, traduction, résumé. Avec recherche web et Deep Research.
  • Image et vidéo : compréhension d'images et de vidéos, génération et retouche d'images.
  • Audio : modèles de synthèse vocale et de traduction en temps réel.
  • Code : modèles dédiés au code et Qwen Code, qui tourne dans le terminal.

Grande différence avec ChatGPT ou Claude : beaucoup de modèles de petite et moyenne taille sont publiés en poids ouverts et tournent sur votre propre ordinateur ou serveur.

Utiliser Qwen Chat : web et application mobileGratuit. On se connecte et on écrit
  1. Ouvrez chat.qwen.ai. Tout se fait dans le navigateur. Sur mobile, l'application « Qwen » existe pour iOS et Android.
  2. Connectez-vous. Créez un compte, puis connectez-vous.
  3. Choisissez un modèle. Le sélecteur de modèle permet de changer. Dans le doute, gardez celui par défaut.
  4. Posez votre question. En français, sans souci. Joignez un fichier ou une image et demandez « résume » ou « mets en tableau ».
  5. Activez les fonctions. Recherche web, Deep Research, génération d'images, Web Dev (maquette de page web), etc.

Qwen Chat est gratuit. En octobre 2026, nous n'avons pas trouvé d'offre payante individuelle pour Qwen Chat, à la manière de ChatGPT Plus.

Conseils pour un usage professionnel

  • Indiquez d'abord le rôle et le format : « Réponse à un fournisseur, ton courtois, en 3 paragraphes ». Dire d'emblée à qui s'adresse le texte réduit les retouches.
  • Vérifiez la traduction face à l'original : montants, dates, références et noms propres se contrôlent sur le texte source, pas sur la traduction seule.
  • Transmettez les longs documents en fichier : un PDF ou un document joint préserve mieux tableaux et titres qu'un copier-coller.
  • Séparez les conversations : une nouvelle conversation par dossier évite les réponses influencées par le sujet précédent.

Transformer ces réponses en « qui fait quoi, et pour quand », puis en assurer le suivi, se passe hors de Qwen Chat. Si vous le faites encore à la main à chaque fois, voyez comment connecter SIMY.

Utiliser Qwen Image Edit

Dans Qwen Chat, joignez une image et décrivez la retouche : « mets le fond en blanc », « traduis le texte du panneau en français ». La version à poids ouverts est souvent intégrée à des outils de génération d'images comme ComfyUI.

API et tarifs de Qwen : Alibaba Cloud Model StudioCompatible OpenAI. Le prix dépend du modèle et de la région
  • Point d'entrée : créez une clé API dans Model Studio (DashScope) d'Alibaba Cloud. L'API est compatible OpenAI : il suffit de changer la destination dans vos outils existants.
  • Régions : pour Qwen3.8-Max, au choix Pékin, Singapour, Francfort, Virginie, Tokyo ou Hong Kong. Les régions disponibles varient selon le modèle, et c'est ce choix qui fixe où vos données sont traitées.
  • Tarifs : facturation à l'usage, selon les jetons en entrée et en sortie. En octobre 2026, qwen3.8-max est affiché à 1,65 $ en entrée et 4,951 $ en sortie par million de jetons (Tokyo notamment ; 2,00 $ et 6,00 $ à Singapour). Le prix unitaire varie aussi avec le modèle, le mode réflexion et le cache : vérifiez les montants à jour sur la page tarifaire officielle (taxes comprises ou non, voir la même page).
  • Coding Plan : un forfait pour utiliser Qwen et d'autres modèles depuis des outils de code comme Claude Code ou Qwen Code. En octobre 2026, seule l'offre Pro existe (50 $ par mois), avec des plafonds de requêtes par tranche de 5 heures, par semaine et par mois. Détails dans la documentation officielle.

Premiers pas avec l'API

  1. Créez un compte Alibaba Cloud. Ouvrez la console Model Studio et choisissez votre région.
  2. Générez une clé API. Placez-la dans une variable d'environnement, jamais en clair dans le code ou un document partagé.
  3. Pointez vers l'endpoint compatible OpenAI. Avec le SDK OpenAI ou vos outils existants, il suffit de changer l'URL et le nom du modèle.
  4. Testez petit et surveillez la consommation. Le mode réflexion et les longs contextes consomment beaucoup de jetons. Suivez l'usage quotidien dans la console avant de passer aux volumes réels.

SIMY et Qwen : pour l'instant, on ne peut pas connecter une clé API Qwen à SIMY. L'exécution cloud de SIMY tourne sur votre compte ChatGPT (Codex).

Faire tourner Qwen en local : Ollama, LM StudioVos données restent chez vous. La licence varie selon le modèle
  • Ollama : après installation, tapez ollama run qwen3.8 dans le terminal pour lancer le modèle 27B (téléchargement d'environ 18 Go, entrée texte et image). Prévoyez un ordinateur avec une bonne marge de mémoire.
  • LM Studio : recherchez et téléchargez les modèles depuis l'interface. Pour celles et ceux qui préfèrent éviter la ligne de commande.
  • Autres : llama.cpp, Jan, vLLM, SGLang, etc. Avec vLLM ou SGLang, vous pouvez monter un serveur interne compatible OpenAI (une API qui s'appelle comme celle d'OpenAI).

Des licences différentes

On ne peut pas dire simplement « Qwen est open source ». La plupart des modèles de petite et moyenne taille, comme Qwen3.8-27B, sont sous Apache 2.0, une licence qui facilite l'usage commercial. Le plus grand, Qwen3.8-2.4T-A95B, a sa propre licence, et les poids des modèles réservés à l'API, comme Max, ne sont pas publiés.

Les tâches qui se prêtent au local

Résumer des documents internes qui ne doivent pas sortir, travailler hors ligne, produire chaque jour beaucoup de brouillons répétitifs : c'est là que l'exécution locale brille. En revanche, un petit modèle est moins capable qu'un grand ; utilisé pour produire une première ébauche plutôt qu'une version finale, il déçoit moins. Fixez d'abord un usage précis, puis testez : vous saurez plus facilement quelle taille de modèle suffit.

Mémoire nécessaire, choix de la quantification et tailles de modèles : tout est dans Faire tourner Qwen en local.

Qwen Code : un agent de code dans le terminalOpen source. Se connecte aussi à d'autres modèles que Qwen

Qwen Code est un agent de code publié en open source (Apache 2.0) par l'équipe Qwen. Il tourne dans le terminal, lit et corrige le code, et exécute des commandes.

  • Installation : avec Node.js 22 ou plus, npm i -g @qwen-code/qwen-code@latest. Sur Mac, Homebrew fonctionne aussi.
  • Modèles compatibles : Qwen, mais aussi les API d'OpenAI, d'Anthropic et de Gemini, et les modèles locaux servis par Ollama ou vLLM.
  • Pour qui : les développeurs qui veulent travailler comme avec Claude Code ou Codex, mais avec les modèles Qwen ou leur propre serveur.

Prise en main

  1. Lancez qwen dans le dossier de travail. Choisissez d'abord le modèle et la méthode d'authentification.
  2. Décrivez ce que vous voulez, en français. Partez de l'objectif : « explique la structure de ce dossier », « trouve pourquoi ce test échoue ».
  3. Validez les changements après lecture. Modifications de fichiers et commandes s'autorisent après vérification. Commencez par de petites corrections.

Après le code écrit avec Qwen Code, SIMY capte en réunion les corrections décidées en revue et la répartition des tâches, et les met en liste.

Qwen en français : jusqu'où ?Traduction, résumé et brouillons se demandent en français

À l'annonce de la génération Qwen3, l'éditeur revendiquait la prise en charge de 119 langues et dialectes, dont le français (les fiches de la génération 3.8 n'indiquent pas de nombre de langues).

  • Points forts : traduction entre chinois, anglais et français, résumé de longs documents, brouillons d'e-mails et de rapports, mise en tableau.
  • Points de vigilance : noms propres locaux, nuances de registre (tutoiement, vouvoiement, formules de politesse), références juridiques et usages commerciaux : vérifiez avant d'utiliser.
  • Avec un petit modèle : un petit modèle local peut produire des tournures peu naturelles sur de longs textes. Finalisez les textes importants avec un grand modèle.

Avec un fournisseur chinois, on peut répartir ainsi : Qwen met le résumé de réunion en français, SIMY prend en charge responsables, échéances et brouillon de réponse. La comparaison sur une réunion plus haut en est l'exemple.

02 / AFTER THE ANSWER

Après la réponse de Qwen, ça se passe comme ça ?

Traduction, résumé, brouillon : Qwen a tout sorti en un instant. Et pourtant, voici ce qui arrive ensuite.

1 Le lendemain de la traduction Qui doit répondre ?

Les notes en chinois sont traduites. Mais tâches et délais s'y perdent, et la réponse tarde.

2 La semaine des brouillons Lequel a été retenu ?

L'API a produit des dizaines de versions. Les décisions restent éparpillées entre chats et fichiers.

3 Le mois du modèle local Rapide, mais seul

Qwen sous Ollama vous a fait gagner du temps. Les demandes nées en réunion restent dans vos notes.

Obtenir la réponse, Qwen le fait en un instant. Que le travail avance ou non se joue après la réponse.

09 / FAQ

Questions fréquentes

Qu'est-ce que Qwen ?

Qwen est une famille de grands modèles de langage (LLM) développée par le groupe chinois Alibaba. On peut l'utiliser de trois façons : le chat gratuit « Qwen Chat », l'API dans le cloud, et des modèles à poids ouverts qui tournent sur votre propre ordinateur.

Comment se prononce Qwen ?

On dit généralement « kouène ». Son nom chinois complet est Tongyi Qianwen (通义千问), dont Qwen est l'abréviation.

Qwen est une IA de quel pays ?

C'est une IA chinoise. Elle est développée par le groupe Alibaba ; la version internationale de Qwen Chat est fournie par Alibaba Cloud (Singapore), et sa politique de confidentialité indique que les saisies sont traitées à Singapour.

Qwen est-il gratuit ?

Oui. Qwen Chat sur le web et l'application mobile sont gratuits. L'API est facturée à l'usage, et les modèles à poids ouverts ne coûtent rien si vous les faites tourner sur votre ordinateur (hors matériel et électricité).

Qwen parle-t-il français ?

Oui. À l'annonce de la génération Qwen3, l'éditeur revendiquait 119 langues et dialectes, dont le français. Traductions, résumés et brouillons d'e-mails se demandent en français.

Peut-on faire tourner Qwen en local, sur son ordinateur ?

Oui. Avec Ollama, ollama run qwen3.8 lance le modèle 27B (environ 18 Go), et LM Studio permet aussi d'utiliser les modèles publiés. Licence et mémoire nécessaire varient selon le modèle : voir Faire tourner Qwen en local.

Ce que je saisis dans Qwen Chat sert-il à entraîner l'IA ?

C'est possible. La politique de confidentialité indique que le contenu anonymisé peut servir à améliorer les modèles, et qu'on peut s'y opposer par e-mail (octobre 2026). Pour des données confidentielles, envisagez l'API avec choix de la région, ou l'exécution locale, où rien ne sort.

Combien coûte l'API de Qwen ?

Cela dépend du modèle et de la région. En octobre 2026, le haut de gamme qwen3.8-max coûte 1,65 $ en entrée et 4,951 $ en sortie par million de jetons (Tokyo notamment). C'est une facturation à l'usage via Alibaba Cloud Model Studio, qui varie aussi avec le mode réflexion et le cache : vérifiez sur la page tarifaire officielle.

Qu'est-ce que Qwen Code ?

Un agent de code open source publié par l'équipe Qwen. Il lit et écrit du code depuis le terminal, et se connecte à Qwen comme aux modèles d'autres éditeurs ou à des modèles locaux.

Quelle différence entre Qwen, ChatGPT, Claude et DeepSeek ?

Les grandes différences : peut-on faire tourner le modèle sur son ordinateur, et où vont les données. Qwen publie ses modèles petits et moyens en poids ouverts, utilisables en local. La différence avec DeepSeek est détaillée dans le comparatif des IA chinoises (LLM).

SIMY fonctionne-t-il avec Qwen ?

Non. Pour l'instant, SIMY ne se connecte pas à Qwen : il tourne sur votre compte ChatGPT (Codex) et, via l'application de bureau SIMY, sur Claude Code installé sur votre ordinateur. Vous pouvez garder Qwen pour la traduction et les brouillons, et confier à SIMY l'organisation de ce qui a été décidé.

Faut-il demander à SIMY, à chaque fois, de prendre la suite d'une réponse de Qwen ?

Non. SIMY capte lui-même, dans vos comptes rendus et vos chats, ce qui a été décidé, avec responsables et échéances. Il apprend votre façon de faire dans vos conversations et ne vous renvoie que ce qui demande une décision.
