GLM, c'est quoi : modèles, GLM Coding Plan, Claude Code, API et sécurité (pour aller plus loin)

GLM, c'est quoi : d'où vient cette IA, et les autres « GLM »Les LLM de Zhipu AI, proposés à l'international sous le nom Z.ai

GLM, Z.ai et Zhipu

GLM est une famille de grands modèles de langage (LLM) développée par Zhipu AI, une entreprise de Pékin, en Chine. Les services pour la Chine sont gérés par Zhipu ; à l'international, la marque « Z.ai » propose un chat (chat.z.ai), une API et un forfait pour le code. Z.ai à l'international est exploité par une société de Singapour (JINGSHENG HENGXING TECHNOLOGY PTE. LTD.).

Sur Hugging Face, les modèles sont publiés sous le nom d'organisation « zai-org ». Dans la presse, « Zhipu », « Z.ai » et « GLM » se mélangent, mais il s'agit des modèles et services de la même entreprise.

Les autres « GLM »

Le sigle « GLM » sert aussi hors de l'IA. Pour vos recherches, ajoutez un mot selon ce que vous cherchez.

  • Modèle linéaire généralisé (Generalized Linear Model) : une méthode statistique, qui regroupe la régression logistique et la régression de Poisson, fréquente dans les tutoriels de statistiques en R ou Python. Sans rapport avec le GLM de ce guide.
  • GLM dans l'automobile : le sigle sert parfois de nom de société ou de code de modèle. Là encore, rien à voir avec ce guide.
  • GLM, l'IA : le nom des modèles de Zhipu AI, avec un numéro de génération et une variante, comme « GLM-5.3 » ou « GLM-4.7-Flash ».

Ce que GLM sait faire

  • Chat : réponses aux questions, rédaction, traduction, résumés.
  • Code : appelé depuis Claude Code, Cline, OpenCode ou d'autres outils, il écrit, corrige et explique du code.
  • Images et lecture de texte : GLM-5.3-Flash est multimodal et accepte aussi des images. GLM-OCR lit le texte des documents.

Ce qui le distingue des modèles phares de ChatGPT ou de Claude : des poids proches du modèle phare sont publiés, et on peut, sous conditions, les faire tourner sur ses propres serveurs ou son ordinateur.

GLM Coding Plan : un forfait pour les outils de codeLite à 18 $ US par mois (octobre 2026, tarif officiel)

Le GLM Coding Plan permet d'utiliser GLM au forfait depuis des outils de code comme Claude Code, Cline ou OpenCode. Contrairement à l'API payée au token, on l'utilise dans la limite d'un montant mensuel : quand on code tous les jours, le budget devient prévisible.

  • Lite : 18 $ US par mois (octobre 2026, affiché sur la page officielle ; vérifiez le traitement des taxes à l'achat).
  • Offres supérieures : il existe des offres avec plus de volume. Contenu et prix sur la présentation officielle et la page d'achat.
  • Volume : des quotas (crédits) par tranche de 5 heures et par semaine, selon l'offre.
  • Modèles disponibles : GLM-5.3 et GLM-5.3-Flash. GLM-5.2 est redirigé vers GLM-5.3, GLM-4.7 vers GLM-5.3-Flash.
  • Outils compatibles : Claude Code, Cline, OpenCode et les autres outils de code dont on peut changer la connexion.

Coding Plan ou API à l'usage ?

  • Le Coding Plan convient : aux développeurs qui utilisent un outil de code tous les jours et veulent une dépense mensuelle fixe.
  • L'API convient : pour l'intégrer à vos systèmes, faire des traitements groupés la nuit, ou si le volume varie beaucoup d'un mois à l'autre.

Dans les deux cas, ce qui suit le code, « qui relit » et « quand on livre », n'est pas pris en charge. Si vous le suivez vous-même à chaque fois, voyez comment connecter SIMY.

Utiliser GLM dans Claude Code : l'API compatible AnthropicChanger la connexion et la clé API par variables d'environnement

Z.ai fournit une API compatible Anthropic (https://api.z.ai/api/anthropic). Comme Claude Code permet de changer sa connexion par variables d'environnement, vous gardez la même façon de travailler dans Claude Code, avec GLM comme modèle en coulisses.

  1. Générez une clé API sur Z.ai. Si vous utilisez le Coding Plan, souscrivez d'abord, puis créez la clé.
  2. Définissez les variables d'environnement. Mettez l'URL ci-dessus dans ANTHROPIC_BASE_URL et la clé API dans ANTHROPIC_AUTH_TOKEN. N'écrivez jamais la clé en clair dans le code ou un document partagé.
  3. Lancez Claude Code. Selon la documentation officielle, les appels de niveau Opus ou Sonnet passent à GLM-5.3, ceux de niveau Haiku à GLM-5.3-Flash. La correspondance se règle par variables d'environnement.
  4. Commencez par une petite tâche. Changer de modèle change aussi la façon d'écrire et de suivre les consignes. Démarrer par une correction de tests, par exemple, est plus rassurant.

Les réglages précis peuvent évoluer : suivez la procédure officielle de Z.ai. Cline et OpenCode s'utilisent de la même façon, en réglant connexion et clé.

Et SIMY : à ce jour, SIMY ne se connecte pas avec une clé API GLM (Z.ai). L'exécution cloud de SIMY passe par votre compte ChatGPT (Codex).

Licences et usage en local : GLM-4.7-Flash avec OllamaFlash sous MIT, GLM-5.3 sous licence propre

Des licences différentes

On ne peut pas résumer en « GLM est open source ». GLM-5.3-Flash est sous licence MIT, facile à utiliser commercialement. GLM-5.3 relève d'une licence propre, la « GLM-5.3 License », proche de la MIT dans sa souplesse ; mais les entreprises dont l'activité consiste à fournir le modèle en API avec un très gros chiffre d'affaires doivent passer un examen de sécurité de Z.AI avant tout usage commercial. Pour une entreprise ordinaire qui l'utilise en interne, c'est souvent sans effet, mais lisez le texte de la licence avant un usage professionnel.

Le faire tourner sur votre ordinateur

  • GLM-4.7-Flash : avec Ollama, ollama run glm-4.7-flash. Environ 19 Go en version quantifiée (q4_K_M) : il faut un ordinateur avec de la mémoire en réserve.
  • GLM-5.3 et GLM-5.3-Flash : dans la bibliothèque officielle d'Ollama, seule la balise « cloud » existe. Cette version tourne dans le cloud d'Ollama, pas sur votre ordinateur.
  • Sur vos propres serveurs : les poids de GLM-5.3 sont publiés sur Hugging Face, mais avec plusieurs centaines de milliards de paramètres, il faut prévoir plusieurs GPU de grande taille.

« En local » ne veut pas toujours dire « rien ne sort » : si l'objectif est de ne pas faire sortir les données de l'entreprise, les modèles à balise cloud ne conviennent pas. Ce qui tourne vraiment en local, ce sont les petits modèles comme GLM-4.7-Flash.

Les tâches qui conviennent au local

Résumer des documents qui ne doivent pas sortir, travailler hors ligne, produire chaque jour en volume des brouillons standardisés : c'est le terrain du local. Les petits modèles sont moins capables que les grands ; utilisez-les pour un « premier jet » plutôt qu'une version finale, et vous serez moins déçu.

GLM et les langues : jusqu'où ?On peut lui écrire dans sa langue, mais seuls l'anglais et le chinois sont officiellement indiqués

Posez une question à GLM dans votre langue, il répond dans cette langue. Mais la fiche officielle du modèle sur Hugging Face ne cite que l'anglais et le chinois : la qualité dans les autres langues n'est pas garantie officiellement.

  • Points forts : générer et corriger du code, résumer des documents en anglais ou en chinois, rédiger des explications techniques.
  • À vérifier : le registre, les noms propres locaux, ce qu'il écrit sur les lois et usages commerciaux de votre pays. Relisez toujours un texte destiné à l'extérieur.
  • Avec un petit modèle : les petits modèles en local peuvent produire des tournures peu naturelles sur de longs textes.

Le plus sûr pour juger la qualité : quelques essais sur vos vrais documents de travail.

09 / FAQ

Questions fréquentes

GLM, c'est quoi ?

GLM est une famille de grands modèles de langage (LLM) développée par Zhipu AI, une entreprise chinoise. À l'international, la marque Z.ai propose un chat, une API et un forfait pour le code. Le « modèle linéaire généralisé » des statistiques s'abrège aussi en GLM, mais c'est autre chose.

GLM (Z.ai) est une IA de quel pays ?

L'éditeur, Zhipu AI, est une entreprise de Pékin, en Chine. Z.ai à l'international est exploité par une société de Singapour, et la politique de confidentialité indique que les données personnelles sont en principe traitées à Singapour.

Quel est le dernier modèle GLM ?

En octobre 2026, les modèles phares sont GLM-5.3 et GLM-5.3-Flash, plus léger et plus rapide. Les noms changent tous les quelques mois : vérifiez la liste officielle.

GLM-5.2 est-il encore disponible ?

Oui. En octobre 2026, GLM-5.2 figure dans la grille tarifaire de l'API Z.ai, au même prix que GLM-5.3. Dans le GLM Coding Plan, une requête vers GLM-5.2 est redirigée vers GLM-5.3.

Le GLM Coding Plan, c'est quoi ?

Un forfait mensuel pour utiliser GLM depuis des outils de code comme Claude Code, Cline ou OpenCode. En octobre 2026, la page officielle affiche l'offre la plus petite, Lite, à 18 $ US par mois. Pour les prix des offres Pro et Max, consultez la page officielle.

Peut-on utiliser GLM dans Claude Code ?

Oui. Z.ai fournit une API compatible Anthropic : en remplaçant la connexion et la clé API de Claude Code par variables d'environnement, on appelle GLM depuis Claude Code. La procédure figure dans la documentation officielle de Z.ai.

GLM est-il gratuit ?

On peut l'essayer sur le chat web chat.z.ai. Côté API, en octobre 2026, la page officielle des tarifs indique GLM-4.7-Flash et GLM-4.5-Flash comme gratuits. Les modèles phares comme GLM-5.3 sont payants à l'usage.

Peut-on faire tourner GLM en local, sur son propre ordinateur ?

Certains modèles, oui. GLM-4.7-Flash sur Ollama pèse environ 19 Go en version quantifiée et tourne sur un ordinateur avec de la mémoire en réserve. GLM-5.3 et GLM-5.3-Flash n'existent sur Ollama qu'avec la balise d'exécution cloud : ils ne tournent pas sur votre machine.

La licence de GLM permet-elle un usage commercial ?

GLM-5.3-Flash est sous licence MIT. GLM-5.3 relève d'une licence propre, globalement libre, mais les fournisseurs d'API à très gros chiffre d'affaires doivent passer un examen avant tout usage commercial. Avant un usage professionnel, lisez le texte de la licence de chaque modèle.

GLM fonctionne-t-il dans d'autres langues que l'anglais et le chinois ?

Posez une question dans votre langue, il répond dans cette langue, mais la fiche officielle du modèle ne cite que l'anglais et le chinois. Pour les textes importants, vérifiez la qualité sur vos vrais documents de travail avant de vous en servir.

SIMY fonctionne-t-il avec GLM ?

Non, à ce jour SIMY ne se connecte pas à GLM (Z.ai). SIMY fonctionne avec votre compte ChatGPT (Codex) et avec Claude Code sur votre ordinateur. Le code et les brouillons écrits avec GLM peuvent être apportés tels quels en réunion ou dans un chat.

Faut-il demander à SIMY, à chaque fois, le travail qui suit GLM ?

Non. SIMY capte de lui-même, dans vos comptes rendus et vos chats, ce qui a été décidé, avec responsables et échéances. Il apprend votre façon de faire dans vos conversations et ne vous renvoie que ce qui demande une décision.
