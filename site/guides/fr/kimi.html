Kimi et Kimi K3, c'est quoi : utilisation, API, Kimi Code, données (pour aller plus loin)

Ouvrez les sections ci-dessous pour vérifier un point sur Kimi lui-même. Noms de modèles et caractéristiques : informations d'octobre 2026.

Kimi, c'est quoi : une IA de quel pays (Moonshot AI) ?Une IA développée par Moonshot AI, à Pékin

L'éditeur de Kimi

Kimi désigne l'IA conversationnelle et la famille de grands modèles de langage (LLM) développées par Moonshot AI (Yuezhi Anmian), une entreprise d'IA basée à Pékin. La version chinoise de Kimi est exploitée par une société pékinoise ; l'API internationale (Kimi Open Platform) est fournie par MOONSHOT AI PTE. LTD., une société de Singapour.

Trois façons de l'utiliser

  • Le chat Kimi : sur kimi.com et l'application mobile. On démarre gratuitement, avec des abonnements payants en option.
  • API : via Kimi Open Platform, à intégrer dans vos systèmes et outils de développement. Vous payez ce que vous consommez.
  • Poids ouverts : les poids publiés sur Hugging Face tournent sur vos serveurs. Sous conditions de licence.

Ce qui distingue Kimi

Il gère de très longs contextes d'un seul tenant et dispose d'outils pensés pour le code. Le dernier modèle, Kimi K3, traite un contexte d'un million de jetons et accepte texte, images et vidéos. Kimi Code CLI, qui tourne dans le terminal, est aussi publié.

En cherchant « Kimi », on tombe aussi sur des homonymes, comme le pilote de F1 Andrea Kimi Antonelli. Cette page parle du Kimi de Moonshot AI.

Utiliser le chat Kimi : web et applicationGratuit pour commencer. L'abonnement augmente les quotas
  1. Ouvrez kimi.com. Tout se fait dans le navigateur. Une application mobile existe aussi.
  2. Connectez-vous. Avec un compte, l'historique des conversations est conservé.
  3. Posez votre question. En français, sans souci. Joignez un PDF ou une image et demandez « mets les points clés en tableau » ou « explique ce schéma ».
  4. Donnez les longs documents d'un coup. Lire plusieurs fichiers à la fois pour les comparer ou les résumer, c'est le point fort de Kimi.

Les abonnements payants

L'abonnement Kimi fonctionne avec des crédits ; l'aide officielle présente quatre niveaux d'abonnement mensuel (octobre 2026). Tous donnent accès à Kimi K3 et incluent un quota pour Kimi Code. Les prix s'affichent selon la région et la devise : vérifiez-les sur la page officielle des abonnements.

Conseils pour un usage professionnel

  • Posez la question avant de donner le document : « Dans ce contrat, extrais seulement les conditions de résiliation et les pénalités ». Annoncer l'objectif d'abord stabilise les réponses, même sur un long document.
  • Demandez où c'est écrit : avant d'utiliser un chiffre ou une condition du résumé, demandez « à quelle page, à quel endroit ? ».
  • Une conversation par dossier : cela évite les réponses influencées par le document précédent.

Transformer ces points clés en « qui fait quoi, et pour quand », puis en assurer le suivi, se passe hors de Kimi. Si vous le faites encore à la main à chaque fois, voyez comment connecter SIMY.

Ce que Kimi sait faire au travailLongs documents, fichiers multiples, code. Commencez par ses points forts
  • Lecture de longs documents : contrats, cahiers des charges, rapports d'étude, lus d'un coup pour en extraire conditions et enjeux.
  • Comparaison de documents : plusieurs devis ou propositions, avec les différences mises en tableau.
  • Compréhension d'images et de vidéos : captures d'écran, schémas ou courtes vidéos, expliqués.
  • Code : depuis Kimi Code ou l'éditeur, lecture, correction et ajout de tests.
  • Brouillons : premières versions de rapports, d'e-mails, de notes de réunion.

Par quoi commencer

Prenez d'abord un long document que vous avez sous la main et demandez « cite les trois décisions à prendre dans ce document » : vous verrez vite où Kimi excelle. Ensuite, passez à la comparaison de documents ou au code.

Quel que soit l'usage, Kimi s'arrête à la « réponse » ou au « brouillon ». Les responsables et délais fixés ensuite en réunion, et les messages aux personnes concernées, SIMY les capte dans vos réunions et vos chats et les fait avancer.

Kimi K3, c'est quoi : différences avec K2 et principaux modèlesOctobre 2026. Noms et générations changent souvent

Kimi K3 est la dernière génération de modèles Kimi, publiée en juillet 2026 (octobre 2026). Il compte 2 800 milliards de paramètres au total, dont seulement 104 milliards sont utilisés à chaque traitement : c'est un MoE (une architecture qui alterne entre de petits modèles spécialisés). Il gère un contexte d'un million de jetons (le jeton est une unité proche du nombre de caractères) et accepte texte, images et vidéos.

K3 ou K2 ?

  • K3 : pour lire de longs documents, traiter aussi images et vidéos, ou confier des tâches difficiles.
  • Famille K2 : pour générer du code en masse à moindre coût. Les modèles publiés jusqu'à K2.6 ont aussi une licence plus souple que K3.

Pour s'y retrouver : les noms des modèles Kimi changent tous les quelques mois. Retenez les rôles : « le modèle phare (K3) » et « le modèle code bon marché (k2.7-code) ».

Kimi Code CLI : un agent de code dans le terminalOpen source (MIT). Utilisable aussi avec le quota de l'abonnement

Kimi Code CLI est un agent de code publié par Moonshot AI sous licence MIT. Il tourne dans le terminal, lit et corrige le code, et exécute des commandes. Il prend en charge MCP (le standard commun pour se connecter à des outils et données externes) et, via ACP (le protocole qui permet d'appeler un agent depuis l'éditeur), s'utilise aussi depuis des éditeurs comme Zed ou JetBrains. L'ancien kimi-cli en Python a été archivé et remplacé par celui-ci.

  • Installation : par le script d'installation officiel, ou via npm. Les étapes sont sur la page GitHub.
  • Connexion : lancez-le, exécutez /login, puis choisissez un compte Kimi Code ou une clé API Kimi Open Platform. Les abonnés l'utilisent avec le quota de leur offre.
  • Pour qui : les développeurs qui veulent travailler comme avec Claude Code ou Codex, mais avec les modèles Kimi.

Prise en main

  1. Lancez Kimi Code dans le dossier de travail. Choisissez d'abord le mode de connexion.
  2. Décrivez ce que vous voulez, en français. Partez de l'objectif : « explique la structure de ce dépôt », « corrige les tests qui échouent ».
  3. Validez les changements après lecture. Modifications de fichiers et commandes s'autorisent après vérification.

Après le code écrit avec Kimi Code, SIMY capte en réunion les corrections décidées en revue et la répartition des tâches, et les met en liste.

L'API Kimi : compatible Anthropic, utilisable depuis Claude CodeCompatible OpenAI et Anthropic. Prix en dollars par million de jetons
  • Point d'entrée : créez une clé API sur Kimi Open Platform (platform.kimi.ai). Le fournisseur est une société de Singapour.
  • Compatibilité : des endpoints compatibles OpenAI et Anthropic. Il suffit de changer la destination dans le SDK OpenAI ou dans les outils qui parlent le format Anthropic.
  • Depuis Claude Code : en remplaçant la destination de Claude Code (ANTHROPIC_BASE_URL) et la clé API par celles de Kimi, vous appelez les modèles Kimi depuis l'interface de Claude Code. La procédure est décrite dans la documentation officielle.
  • Tarifs : en octobre 2026, Kimi K3 coûte 3,00 $ en entrée et 15,00 $ en sortie par million de jetons (hors taxes). Le cache, qui réutilise un même préfixe, ne coûte que 0,30 $ en lecture ; l'écriture est facturée à part selon la durée de conservation. Prix à jour sur la page tarifaire officielle.

Premiers pas avec l'API

  1. Créez un compte Kimi Open Platform. Dans la console, approvisionnez votre solde ou réglez le moyen de paiement.
  2. Générez une clé API. Placez-la dans une variable d'environnement, jamais en clair dans le code ou un document partagé.
  3. Changez la destination de vos outils habituels. Choisissez le format OpenAI ou Anthropic, puis remplacez l'URL et le nom du modèle.
  4. Testez petit et surveillez la consommation. Les longs contextes consomment beaucoup de jetons. Suivez l'usage quotidien avant de passer aux volumes réels.

SIMY et Kimi : pour l'instant, SIMY ne se connecte pas à une clé API Kimi. L'exécution cloud de SIMY tourne sur votre compte ChatGPT (Codex).

Poids ouverts et licence : K3 sous conditionsNe pas tout ranger sous « open source »

Les poids de Kimi K3 sont publiés sur Hugging Face, mais sous une licence propre, la « Kimi K3 License ». Utilisation, modification et redistribution sont permises, avec des conditions liées à la taille de l'activité.

  • Activités qui fournissent le modèle : si vous proposez K3 comme service et que votre chiffre d'affaires des 12 derniers mois dépasse 20 millions de dollars, un contrat commercial séparé avec Moonshot AI est nécessaire.
  • Gros produits : au-delà de 100 millions d'utilisateurs mensuels ou de 20 millions de dollars de chiffre d'affaires mensuel, le produit doit afficher « Kimi K3 » à l'écran.
  • K2.6 et antérieurs : sous licence Modified MIT, plus souple que celle de K3.

Pour la plupart des entreprises, ces conditions pèsent peu tant que l'usage reste interne. Mais pour l'intégrer à un produit, lisez le texte de la licence.

Faire tourner Kimi en local ? Sur Ollama, c'est le tag cloud« Disponible sur Ollama » ne veut pas forcément dire « tourne sur votre ordinateur »

Dans la bibliothèque officielle d'Ollama, kimi-k3, kimi-k2.7-code et kimi-k2.6 portent tous le tag « cloud » en octobre 2026. Ils tournent donc sur le cloud d'Ollama, pas sur votre ordinateur, et vos saisies sont envoyées aux serveurs d'Ollama.

  • Sur vos propres serveurs : les poids publiés tournent avec vLLM ou SGLang. K3 est une configuration géante de 2 800 milliards de paramètres, pensée pour des serveurs dotés de plusieurs GPU haut de gamme.
  • Sur un ordinateur personnel : les derniers modèles Kimi ne sont pas réalistes. Parmi les modèles chinois qui tournent en local, les modèles petits et moyens de Qwen sont une option.

Si le but est que les données ne sortent pas, les modèles au tag cloud ne conviennent pas. Exécutez les poids sur vos propres serveurs, ou choisissez un modèle assez petit pour tourner chez vous.

Kimi en français : jusqu'où ?On peut lui écrire en français, mais aucune langue n'est officiellement listée

On peut écrire au chat Kimi en français et recevoir des réponses en français. Mais en octobre 2026, la fiche du modèle K3 ne précise pas les langues prises en charge. La qualité en français n'est pas garantie officiellement : testez-la sur vos vrais documents de travail.

  • Faciles à tester : résumer un document en français, synthétiser en français un document anglais ou chinois, se faire expliquer du code en français.
  • Points de vigilance : nuances de registre (tutoiement, vouvoiement, formules de politesse), noms propres locaux, références juridiques et usages commerciaux : vérifiez avant d'utiliser.

Pour un petit test, donnez-lui un rapport que vous avez vous-même écrit en français et demandez un résumé et une reformulation. Comme vous connaissez le texte d'origine, vous jugerez plus facilement la qualité.

On peut répartir ainsi : Kimi lit les longs documents en anglais, SIMY prend en charge responsables, échéances et message de partage en français pour ce qui a été décidé en réunion.

Quand Kimi a fini d'écrire, ça se passe comme ça ?

Lire de longs documents, corriger du code : Kimi a tout bouclé d'un trait. Et pourtant, voici ce qui arrive ensuite.

1 Le lendemain de la lecture On a conclu quoi ?

Les points clés du long document sont sortis. Mais ce qui a été décidé en réunion dort dans une autre note.

2 Le soir du correctif Qui relit ?

Le correctif est commité. La demande de relecture et le message au client, personne ne les a écrits.

3 La semaine d'après Où en est-on ?

Responsables et délais ont été fixés à l'oral. Au final, c'est toujours vous qui vérifiez.

09 / FAQ

Questions fréquentes

Qu'est-ce que Kimi ?

Kimi est l'IA conversationnelle et la famille de grands modèles de langage (LLM) développées par l'entreprise chinoise Moonshot AI (Yuezhi Anmian). On l'utilise de trois façons : le chat sur kimi.com ou l'appli, l'API, et les poids publiés des modèles.

Kimi est une IA de quel pays ?

C'est une IA chinoise. Elle est développée par Moonshot AI (Yuezhi Anmian), à Pékin ; la version chinoise de Kimi est exploitée par une société pékinoise, et l'API internationale est fournie par MOONSHOT AI PTE. LTD., une société de Singapour.

Qu'est-ce que Kimi K3 ?

Kimi K3 est la dernière génération de modèles de Moonshot AI, publiée en juillet 2026 (octobre 2026). Il gère un contexte d'un million de jetons, accepte images et vidéos en plus du texte, et ses poids sont publiés sous sa propre licence, la Kimi K3 License.

Quelle différence entre Kimi K3 et Kimi K2 ?

K3 est le modèle phare actuel, avec longs contextes et entrée image et vidéo, publié sous la Kimi K3 License. La famille K2 est la génération précédente ; son modèle dédié au code, k2.7-code, a un prix d'API inférieur à celui de K3.

Kimi est-il gratuit ?

Le chat sur kimi.com et l'appli se commencent gratuitement. Des abonnements payants augmentent les quotas, et l'API est facturée à l'usage.

Qu'est-ce que Kimi Code ?

Un agent de code qui tourne dans le terminal, publié par Moonshot AI sous licence MIT. On s'y connecte avec un compte Kimi Code ou une clé API, et il s'utilise aussi avec le quota de l'abonnement.

Peut-on utiliser les modèles Kimi depuis Claude Code ?

Oui. L'API Kimi a un endpoint compatible Anthropic, et la procédure pour remplacer la destination et la clé API de Claude Code est décrite officiellement.

Peut-on faire tourner Kimi en local, sur son ordinateur ?

Faire tourner le dernier Kimi K3 sur un ordinateur personnel n'est pas réaliste. Dans la bibliothèque officielle d'Ollama, Kimi porte le tag cloud et tourne sur le cloud d'Ollama. Pour l'héberger soi-même, il faut exploiter les poids publiés sur des serveurs GPU haut de gamme.

Où sont stockées les données saisies dans Kimi ?

Selon les explications officielles, le chat Kimi (aide en chinois) stocke les données sur des serveurs en Chine, et l'API internationale sur des serveurs à Singapour. Pour des données confidentielles, vérifiez vos règles internes et le texte de chaque politique.

Kimi fonctionne-t-il en français ?

On peut l'interroger en français et recevoir ses réponses en français. Mais la fiche officielle du modèle ne précise pas les langues prises en charge : vérifiez la qualité sur vos documents de travail avant usage.

SIMY fonctionne-t-il avec Kimi ?

Non. Pour l'instant, SIMY ne se connecte pas à Kimi : il tourne sur votre compte ChatGPT (Codex) et sur Claude Code installé sur votre ordinateur. Les points clés et le code produits avec Kimi peuvent être apportés tels quels en réunion ou dans un chat.

Faut-il demander à SIMY, à chaque fois, de prendre la suite de ce que Kimi a écrit ?

Non. SIMY capte lui-même, dans vos comptes rendus et vos chats, ce qui a été décidé, avec responsables et échéances. Il apprend votre façon de faire dans vos conversations et ne vous renvoie que ce qui demande une décision.
