01 / REFERENCE

OpenAI Codex en détail : installation, tarifs, limites, comparatifs, sécurité

Ouvrez cette partie pour en savoir plus sur Codex lui-même. Rien ici ne change la connexion avec SIMY.

OpenAI Codex, c'est quoi : différences avec ChatGPT et avec l'ancien Codexun agent inclus dans les offres ChatGPT

Ce qu'est Codex

OpenAI Codex est un agent IA proposé par OpenAI. ChatGPT « répond quand on demande » ; Codex « travaille quand on demande ». Il lit des fichiers, exécute des commandes, utilise le navigateur et produit des livrables, sur votre ordinateur ou dans un environnement cloud. Né pour le développement logiciel, il s'est étendu en 2026, avec l'application de bureau et les plugins, à des tâches sans code comme les présentations ou les brouillons d'e-mails.

La différence avec ChatGPT

ChatGPT répond dans la conversation ; Codex rend un « résultat fini ». Demandez « recherche le client A et fais une proposition » : ChatGPT renvoie un plan rédigé, Codex crée le fichier Slides. Les deux s'utilisent avec le même compte ChatGPT et partagent le quota.

Attention aux confusions de noms

  • L'ancien Codex (2021) : un modèle de complétion de code, utilisé au départ par GitHub Copilot. Arrêté en 2023, c'est un produit distinct de l'actuel OpenAI Codex.
  • Les noms de modèles comme GPT-5-Codex : ce sont des modèles sélectionnables dans Codex. Le produit Codex et le modèle GPT-5-Codex sont deux niveaux différents.

La différence avec ChatGPT Work

L'application de bureau ChatGPT propose trois modes : Chat, Work et Codex. Work est un agent qui finalise des livrables de travail en général (recherches, documents) ; Codex est un agent fort sur les fichiers et les commandes. Ils partagent le même quota. Sans écrire de code : si vous avez besoin de lire et écrire des fichiers ou de piloter Chrome, Codex ; si vous voulez un livrable dans le prolongement d'une conversation, Work.

Codex en français

Oui. L'interface est surtout en anglais, mais consignes et livrables peuvent être en français. AGENTS.md et les skills aussi.

Installation : connexion, AGENTS.md, modes d'approbationavec l'application de bureau : télécharger, se connecter, c'est parti

Démarrer avec l'application de bureau (sans code)

  1. Télécharger et installer. Depuis la page Codex d'OpenAI, version Windows ou Mac.
  2. Se connecter avec son compte ChatGPT. Avec Plus ou plus, pas besoin de clé API. Le navigateur s'ouvre : autorisez, c'est fait.
  3. Choisir le dossier de travail. Le dossier où Codex peut lire et écrire. Un dossier Drive ou un dossier de documents suffit.
  4. Choisir le mode d'approbation. Au début, « confirmer avant chaque modification », puis « auto » une fois à l'aise.
  5. Confier une première tâche. « Avec les références de ce dossier, fais une proposition pour le client A » : demandez comme à un collègue.

Démarrer avec la CLI (développeurs)

Avec Node.js installé, lancez npm install -g @openai/codex dans le terminal, puis tapez codex pour vous connecter. Le support natif de Windows progresse, mais WSL reste plus stable.

AGENTS.md : le fichier où l'on écrit sa méthode

Placez un fichier texte AGENTS.md dans le dossier de travail : Codex lit à chaque fois les règles qui s'y trouvent (nommage, structure, interdits). On peut y décrire un modèle métier, par exemple « une proposition fait 12 slides et se termine par les prochaines étapes ». Avec SIMY, ce modèle est appris des conversations : inutile de l'écrire pour commencer.

Réussir sa première demande

  • Indiquer où sont les matériaux. « Utilise le dossier Drive “Références” » : en précisant d'emblée où lire, vous réduisez temps de recherche et consommation.
  • Montrer un exemple du résultat. Un ancien support ou un e-mail type harmonise la structure et le ton.
  • Dire où s'arrêter. « Ne rien envoyer », « jusqu'au brouillon » : moins d'approbations, plus de sérénité.
  • Recevoir un fichier. Plutôt qu'un long texte dans le chat, un fichier Slides ou Docs se partage tel quel.

Modes d'approbation et bac à sable

Codex propose un mode « confirmation » qui demande l'accord avant toute modification ou action externe, un mode « auto » libre à l'intérieur du dossier de travail, et un « accès complet ». Dans tous les cas, le travail se fait dans un bac à sable qui limite l'accès hors du dossier et au réseau.

Possibilités : skills, MCP, Chrome, plugins, planificationbrouillons Gmail, Drive, Sheets, Slides, Notion, Agenda, Slack

Applications métier reliées par plugin (octobre 2026)

  • Gmail : lit les e-mails et enregistre réponses et nouveaux messages en brouillon. C'est vous qui cliquez sur Envoyer.
  • Google Drive, Sheets, Slides : lit les fichiers d'un dossier, met à jour des tableaux, crée des présentations.
  • Notion : lit et écrit pages et bases. Idéal pour ranger CR et fiches clients.
  • Google Agenda : lit l'agenda, propose des créneaux, prépare l'invitation.
  • Slack : lit les canaux et rédige des brouillons de messages.
  • Chrome : ouvre Chrome pour chercher, remplir des formulaires, lire des écrans. Utile aussi pour vérifier un outil métier avec connexion.

Skills, MCP, sous-agents

Une skill est un jeu d'instructions réutilisable qui regroupe étapes et critères. Avec « comment faire le rapport hebdo » ou « modèle de CR » en skill, vous n'expliquez plus. MCP (Model Context Protocol) est le standard qui relie outils et données externes à Codex : c'est par là qu'on ajoute ce qui n'a pas de plugin (Figma, base interne…). Les longues tâches peuvent être découpées en sous-agents menés en parallèle.

Planification, mode plan, revue

La planification répète une tâche à heure fixe, par exemple « chaque vendredi, croiser les e-mails, Slack et le suivi commercial de la semaine et rédiger l'hebdo du manager en brouillon Slack ». Le mode plan fait d'abord présenter les étapes et l'impact, pour validation. La revue de code fait vérifier les PR GitHub par Codex ; elle s'adresse aux équipes de développement.

Usages sans code (exemples)

  • Recherche client : lire le site et l'actualité de l'entreprise dans Chrome, résumer points clés et enjeux dans Docs.
  • Proposition : 12 slides à partir des références et de la grille tarifaire du Drive, sur la structure du support précédent.
  • CR et rapport : à partir d'une transcription, un CR décisions / responsable / échéance et un résumé pour le manager en brouillon Slack.
  • Agenda : trois créneaux libres et l'invitation en brouillon Gmail.
  • Tableaux : lire le suivi dans Sheets, appliquer les changements décidés en réunion, lister les écarts.

Et SIMY : la planification part d'une heure, et la première consigne reste à écrire. SIMY part des réunions et des chats. Comme les plugins Codex savent produire brouillons Gmail et Slides, SIMY peut se concentrer sur « quand, quoi, jusqu'où ».

  • Plus et Business standard ont des quotas sur cinq heures ; des limites hebdomadaires peuvent aussi s’appliquer. Pro n’a actuellement pas de limite sur cinq heures. Faire durer son quota

Indiquer en une consigne où sont les matériaux et la forme attendue, découper les longues conversations en nouveaux fils, séparer recherche et production. Ces trois gestes réduisent nettement la consommation. Le modèle, c'est le talent du peintre ; le niveau de raisonnement, le temps passé sur la toile. Si le quota vous inquiète, baissez le niveau de raisonnement. Quand SIMY sollicite Codex, il transmet le modèle appris tel quel : moins de reprises, moins de consommation.

Pourquoi combiner

Codex et Claude Code dépendent d'offres différentes. Pour ne pas être bloqué quand un modèle flanche ou que le quota est épuisé, de plus en plus de gens maîtrisent les deux. En CLI, on peut les alterner dans le même dossier.

La place de SIMY : SIMY peut faire exécuter par Codex comme par Claude Code. Dans le cloud, il pilote Codex sur votre compte ChatGPT ; sur votre ordinateur, l'application de bureau SIMY peut aussi utiliser Claude Code. Dans les deux cas, seule la décision vous revient. L'usage de ChatGPT lui-même est détaillé dans le guide ChatGPT.

Sécurité et précautions : entraînement, bac à sable, approbationtrois points à vérifier avant un usage professionnel
  • Refuser l'entraînement : dans les paramètres ChatGPT → « Gestion des données » → désactivez « Améliorer le modèle pour tous » ; vos conversations Codex ne servent alors plus à l'entraînement. L'option est activée par défaut. Avec Business et Enterprise, les données professionnelles ne servent pas à l'entraînement par défaut, par contrat.
  • Bac à sable : Codex travaille dans un environnement limité au dossier choisi et au réseau autorisé. Il ne touche ni aux fichiers hors du dossier ni aux sites non autorisés.
  • Approbation : avant toute action irréversible (suppression, envoi, publication), Codex demande votre accord. Évitez l'approbation automatique (le fameux « YOLO ») hors des environnements jetables.
  • Pilotage de Chrome : pour un outil métier avec connexion, créez un profil Chrome dédié et utilisez un compte aux droits limités.
  • Fuite d'informations : ne choisissez pas comme dossier de travail un dossier contenant des données personnelles ou confidentielles. Si votre entreprise encadre l'usage de ChatGPT, envisagez Business ou plus.
  • Connexion à SIMY : vous vous connectez à votre compte via l'écran d'authentification ChatGPT et autorisez l'accès. Pour créer des suggestions à partir de l'historique, le contenu n'est pas stocké sur nos serveurs. Détails sur les pages Sécurité et Politique de confidentialité.

09 / FAQ

Questions fréquentes

OpenAI Codex est-il gratuit ?

Vérifié le 3 octobre 2026 : Free et Go donnent accès à GPT-6 Luna à vitesse Standard dans l’application de bureau, selon le déploiement. Les interfaces, modèles et limites diffèrent de Plus et des offres supérieures. L’usage par clé API est facturé séparément. Vérifiez séparément les conditions de connexion cloud de SIMY.

Combien peut-on utiliser Codex avec ChatGPT Plus ?

Plus et Business standard ont des quotas sur cinq heures ; des limites hebdomadaires peuvent aussi s’appliquer. Pro n’a actuellement pas de limite sur cinq heures. La consommation dépend du modèle et de la tâche : consultez le quota restant et les réinitialisations dans le tableau de bord d’utilisation.

Quand l'utilisation de Codex est-elle réinitialisée ?

Les réinitialisations dépendent de l’offre et du quota. Consultez le solde et les horaires dans le tableau de bord d’utilisation de Codex ou avec /status dans la CLI. Ne supposez pas que chaque quota repart à un délai fixe après la première utilisation.

Claude Code ou Codex : lequel choisir ?

Inutile de choisir. Codex dépend de l'offre ChatGPT et Claude Code de l'offre Claude : de plus en plus de gens maîtrisent les deux, au cas où l'un flanche ou que le quota soit épuisé. SIMY peut faire exécuter par Codex comme par Claude Code.

Qu'est-ce que le mode plan de Codex ?

Un mode qui fait d'abord présenter les étapes et l'impact, sans modifier de fichier. Avant un gros travail, vous validez le plan, puis vous passez à l'exécution. Combiné aux modes d'approbation, il permet de régler finement ce que vous déléguez.

Peut-on utiliser Codex sans être développeur ?

Oui. OpenAI indique que plus de 20 % des utilisateurs de Codex ne sont pas développeurs (2026). Dans l'application de bureau, une demande en langage courant mène jusqu'à la recherche client, la proposition, le compte rendu ou le brouillon Gmail, presque sans voir de code.

Quelle différence entre la planification de Codex et SIMY ?

La planification de Codex répète une tâche définie à partir d'une heure. SIMY part des réunions et des chats, y repère le travail qui en naît et le fait avancer par Codex. Le rituel de 9 h chaque matin va à la planification Codex ; le travail qui change à chaque réunion, à SIMY.

Est-il sûr de laisser Codex piloter Chrome ?

Codex tourne dans un bac à sable et demande votre accord avant toute action ayant un effet externe, comme une connexion ou l'envoi d'un formulaire. En usage professionnel, retenez trois points : ne pas passer l'approbation en automatique, utiliser un profil Chrome dédié, vérifier le réglage d'entraînement.

Ce que je saisis dans Codex sert-il à entraîner l'IA ?

Si vous désactivez « Améliorer le modèle pour tous » dans « Gestion des données » des paramètres ChatGPT, vos conversations Codex ne servent plus à l'entraînement. Avec Business et Enterprise, les données professionnelles ne servent pas à l'entraînement par défaut, par contrat.

Avec SIMY, l'usage de Codex est-il facturé en plus ?

SIMY se connecte à votre compte ChatGPT et fait avancer le travail via Codex App Server. L'usage de Codex reste dans les limites de votre offre ChatGPT. Les tarifs de SIMY sont sur la page des tarifs.

Peut-on utiliser Codex depuis un smartphone ?

Les applications ChatGPT iOS et Android permettent de suivre les tâches Codex Cloud et d'en lancer de nouvelles. Avec l'app iOS de SIMY, seules les décisions en attente sur le travail mené par Codex arrivent sur votre téléphone, et vous les validez de là.
