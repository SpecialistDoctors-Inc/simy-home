MiniMax, c'est quoi : H3, M3, tarifs, API et usage en local (pour aller plus loin)

Dépliez ces sections pour en savoir plus sur MiniMax lui-même. Noms de modèles et tarifs à jour d'octobre 2026.

MiniMax, c'est quoi : d'où vient cette IAUne entreprise d'IA de Shanghai, avec des modèles texte, vidéo et voix

Qui développe MiniMax

MiniMax est une entreprise d'IA basée à Shanghai, en Chine. Elle développe en interne des grands modèles de langage (LLM) pour le texte, mais aussi des modèles et applications de génération vidéo et de synthèse vocale. Les applications destinées à l'international sont fournies par Nanonoble Pte. Ltd., une société de Singapour.

Trois façons de l'utiliser

  • Applications : MiniMax Code, MiniMax Audio, Hailuo pour la vidéo, etc., sur le web ou le mobile.
  • API : via la plateforme MiniMax (platform.minimax.io), pour intégrer les modèles à vos systèmes ou outils de développement. Au choix : paiement à l'usage ou Token Plan forfaitaire.
  • Poids ouverts : faire tourner sur vos propres serveurs les poids de MiniMax-M3 ou MiniMax H3 publiés sur Hugging Face, sous conditions de licence.

« Minimax » désigne aussi un algorithme de recherche issu de la théorie des jeux. Ce guide parle de l'entreprise d'IA MiniMax.

MiniMax H3, c'est quoi

MiniMax H3 est le modèle de génération vidéo annoncé par MiniMax fin juillet 2026. À partir de texte, d'images, de vidéos ou de sons, il crée des vidéos avec son stéréo (4 à 15 s, jusqu'en 2K). Selon la fiche officielle du modèle, il gère 11 langues pour les dialogues ; vérifiez que la vôtre en fait partie.

  • Où l'utiliser : l'application vidéo Hailuo, l'API MiniMax, les poids publiés sur Hugging Face.
  • Différence avec M3 : H3 crée des vidéos, M3 est un modèle de texte. Ce sont deux modèles distincts.
  • En local : le modèle est lourd pour un ordinateur personnel. Voir Ce qu'implique l'usage en local plus bas.

MiniMax-M3, c'est quoi

MiniMax-M3 est le modèle de texte phare actuel de MiniMax, publié en juin 2026. Il compte environ 428 milliards de paramètres au total (environ 23 milliards actifs par inférence), avec un contexte d'un million de tokens et des entrées texte, image et vidéo. Son API est peu chère, et un Token Plan forfaitaire permet de l'utiliser depuis les outils de code.

Utiliser MiniMax Audio

Collez le texte à lire, choisissez le type de voix et le débit, puis générez l'audio. Utile pour la voix off d'une vidéo de formation, la lecture d'une présentation produit ou une annonce interne. Pour une voix proche de celle d'une personne réelle, obtenez son accord et vérifiez les règles de la plateforme de diffusion.

Ce que MiniMax sait faire : usages au travailTexte, voix et vidéo, avec les outils d'un seul éditeur
  • Texte : avec MiniMax-M3, premiers jets de scripts, articles, e-mails et rapports. Il résume aussi de longs documents et commente images et vidéos.
  • Voix : avec MiniMax Audio, voix off et lectures à partir d'un script. Pour la formation, les présentations produit ou les annonces internes.
  • Vidéo : MiniMax H3, via Hailuo ou l'API, crée de courtes vidéos avec son à partir de texte ou d'images. Idéal pour une ébauche façon storyboard ou un prototype de vidéo courte pour les réseaux sociaux.
  • Code : déléguer du code avec MiniMax Code, ou avec un outil de code branché sur l'API compatible Anthropic.

Créer une vidéo avec Hailuo (H3)

  1. Décrivez la scène par écrit. Lieu, personnes, mouvement, de façon concrète : « dans un bureau le matin, des collègues font le point autour d'une tablette ».
  2. Ajoutez une image si besoin. Une photo produit ou une image d'ambiance peut être animée.
  3. Générez plusieurs versions et choisissez. Le résultat change à chaque fois, même avec la même consigne : comparer les candidats est le plus rapide.

Si vous utilisez des visages, des logos ou un style proche d'une œuvre existante, vérifiez les droits et les règles de la plateforme de diffusion. Une vidéo destinée à l'extérieur doit être vérifiée par un humain avant publication.

Quel que soit l'usage, MiniMax s'arrête au « contenu » ou au « brouillon ». Les responsables, échéances et messages aux intéressés décidés ensuite en réunion, SIMY les capte dans vos réunions et vos chats et les fait avancer.

Comprendre les tarifs : paiement à l'usage et Token PlanAPI texte parmi les moins chères. Forfait dès 22 $ par mois
  • Paiement à l'usage : en octobre 2026, MiniMax-M3 coûte 0,30 $ en entrée et 1,20 $ en sortie par million de tokens, pour une entrée jusqu'à 512K tokens. Au-delà de 512K, c'est le double ; le traitement prioritaire coûte 1,5 fois plus. C'est l'un des moins chers parmi les LLM chinois.
  • Token Plan : forfait pour l'utiliser depuis les outils de code, en trois niveaux : Plus à 22 $/mois, Max à 55 $/mois, Ultra à 132 $/mois. Avec des quotas par tranche de 5 heures et par semaine.
  • Taxes : les prix sont en dollars US. Pour les taxes et les montants à jour, consultez la page des tarifs à l'usage et la page du Token Plan.

Lequel choisir

  • Usage quotidien dans un outil de code : si votre consommation est difficile à prévoir, le Token Plan rend la dépense mensuelle plus lisible.
  • Intégration à vos systèmes : le paiement à l'usage, proportionnel au volume, convient mieux. Commencez petit, regardez le coût par traitement, puis élargissez.

La vidéo et la voix ont une grille tarifaire distincte du texte. Le prix dépend du nombre et de la durée des contenus : vérifiez sur les pages officielles.

L'API MiniMax : format compatible Anthropic recommandéÀ brancher sur Claude Code et les outils qui parlent le format Anthropic
  • Point d'entrée : créez une clé API sur la plateforme MiniMax (platform.minimax.io).
  • Compatibilité : MiniMax recommande le format compatible avec le SDK d'Anthropic. Les formats Chat Completions et Responses API d'OpenAI sont aussi pris en charge.
  • Depuis un outil de code : dans Claude Code ou un autre outil au format Anthropic, remplacez l'adresse de connexion et la clé API par celles de MiniMax pour appeler MiniMax-M3. La documentation officielle décrit la marche à suivre.

Premiers pas avec l'API

  1. Créez un compte sur la plateforme MiniMax. Choisissez le paiement à l'usage ou le Token Plan.
  2. Générez une clé API. Placez-la dans une variable d'environnement, jamais en clair dans le code ou un document partagé.
  3. Changez la connexion de votre outil habituel. Choisissez le format Anthropic ou OpenAI, puis remplacez l'URL et le nom du modèle.
  4. Testez à petite échelle et surveillez la consommation. Les entrées longues coûtent plus cher. Regardez l'usage quotidien avant de passer au volume réel.

Et SIMY : à ce jour, SIMY ne se connecte pas avec une clé API MiniMax. L'exécution cloud de SIMY passe par votre compte ChatGPT (Codex).

Poids ouverts et licence : usage commercial sous conditionsM3 comme H3 ont leur propre licence. Ne pas tout ranger sous « open source »

Les poids de MiniMax-M3 sont publiés sur Hugging Face, mais sous une licence propre, la « MiniMax Community License ». L'usage non commercial est libre ; l'usage commercial est soumis à conditions.

  • Usage commercial : mention « Built with MiniMax M3 » et notification à MiniMax obligatoires.
  • Au-delà de 20 millions de dollars de chiffre d'affaires annuel : autorisation écrite de MiniMax requise avant tout usage commercial.
  • Usages interdits : notamment l'usage militaire.
  • M2.7 : également sous licence propre.

La licence de MiniMax H3

  • Territoire : la MiniMax H3 Community License exclut de son territoire l'UE, le Royaume-Uni, la Corée du Sud et les États-Unis. Vérifiez si le pays où vous l'utilisez est couvert, y compris pour vos implantations et partenaires à l'étranger.
  • Usage commercial : la mention « MiniMax H3 » doit figurer dans l'interface du produit. Au-delà de 20 millions de dollars de chiffre d'affaires annuel, une autorisation écrite préalable est requise.

Même pour un test interne, les conditions changent selon que l'usage est commercial ou non. Avant un usage professionnel, lisez le texte de la licence M3 et le texte de la licence H3.

Faire tourner MiniMax H3 ou M3 en local ?Trop lourds pour un PC personnel. Les guides officiels visent plusieurs GPU

« MiniMax H3 en local » est une recherche fréquente. Mais en octobre 2026, faire tourner H3 ou M3 sur un ordinateur ordinaire reste difficile.

  • Ollama : dans la bibliothèque officielle, minimax-m3 et minimax-m2.7 portent la balise « cloud ». Ils tournent dans le cloud d'Ollama : vos entrées partent sur les serveurs d'Ollama. Il existe des versions communautaires, mais elles ne sont pas officielles.
  • MiniMax H3 : les poids sont publiés, mais la procédure officielle prend l'exemple d'une configuration à 4 GPU. Une procédure pour ComfyUI existe aussi ; vérifiez la mémoire GPU nécessaire sur votre propre machine.
  • Procédures officielles pour M3 et M2.7 : M3 sur 8 GPU B200 (à titre expérimental), M2.7 sur 4 GPU à grande mémoire. Ce sont des configurations de centre de données.
  • Pour tourner sur votre ordinateur : les petits modèles de texte présentés dans le guide Qwen ou le guide GLM sont une option.

Si votre objectif est de « ne pas faire sortir les données », les modèles à balise cloud ne conviennent pas. Faites tourner les poids sur vos propres serveurs GPU, ou choisissez un modèle à la taille de votre machine.

MiniMax et les langues : jusqu'où ?On peut lui écrire dans sa langue, mais la liste officielle des langues n'est pas publiée

On peut s'adresser à MiniMax-M3 dans sa propre langue, mais en octobre 2026, la liste des langues prises en charge par M3 n'est pas publiée officiellement. Pour H3, la fiche du modèle indique 11 langues pour les dialogues. Dans les deux cas, testez avec vos vrais contenus de travail.

  • Texte : pour un script ou un brouillon d'e-mail, vérifiez le registre et les tournures avant de l'utiliser.
  • Voix : écoutez la lecture et vérifiez la prononciation des noms propres et des chiffres.
  • Vidéo : vérifiez que le texte affiché à l'image n'est pas déformé. Ajouter les sous-titres ensuite dans un logiciel de montage reste le plus sûr.

Vous pouvez aussi traduire un script anglais ou chinois avec M3, puis le faire lire par MiniMax Audio. Responsables et échéances des corrections décidées en réunion, messages au studio et à l'équipe : confiez-les à SIMY.

Elle est développée par une entreprise de Shanghai, en Chine. Les applications destinées à l'international sont fournies par Nanonoble Pte. Ltd., une société de Singapour.

MiniMax H3, c'est quoi ?

MiniMax H3 est un modèle génératif de vidéo avec son, annoncé par MiniMax fin juillet 2026. À partir de texte, d'images, de vidéos ou de sons, il crée des vidéos de 15 secondes maximum, utilisables via Hailuo ou l'API. C'est un modèle distinct de MiniMax-M3, le modèle de texte.

Peut-on faire tourner MiniMax H3 en local ?

Sur un ordinateur personnel, c'est difficile. Les poids sont publiés sur Hugging Face, mais la procédure officielle prend l'exemple d'une configuration à 4 GPU. Pour l'essayer simplement, Hailuo ou l'API sont plus réalistes.

MiniMax est-il gratuit ?

Cela dépend de l'application : vérifiez ce qui est gratuit dans les informations officielles de chacune. L'API est payante, soit à l'usage, soit avec le Token Plan mensuel.

Combien coûte le Token Plan de MiniMax ?

En octobre 2026, il existe trois niveaux : Plus à 22 $/mois, Max à 55 $/mois et Ultra à 132 $/mois. Des quotas s'appliquent par tranche de 5 heures et par semaine.

MiniMax Audio, c'est quoi ?

C'est l'application et le modèle de synthèse vocale de MiniMax, qui transforment un texte en voix naturelle. Utile pour la voix off d'une vidéo de formation ou la lecture d'une présentation produit.

Peut-on utiliser les modèles MiniMax depuis Claude Code ?

Oui. MiniMax recommande pour son API un format compatible Anthropic : en remplaçant l'adresse de connexion et la clé API dans Claude Code ou un outil similaire, on peut appeler MiniMax-M3.

Peut-on faire tourner MiniMax en local, sur son propre ordinateur ?

Faire tourner l'actuel MiniMax-M3 sur un ordinateur personnel n'est pas réaliste. Dans la bibliothèque officielle d'Ollama, M3 porte la balise cloud (version qui tourne dans le cloud d'Ollama), et la procédure officielle d'auto-hébergement suppose plusieurs GPU haut de gamme.

Peut-on utiliser les modèles MiniMax à des fins commerciales ?

Oui, sous conditions. Pour un usage commercial, MiniMax-M3 exige la mention « Built with MiniMax M3 » et une notification à MiniMax ; au-delà de 20 millions de dollars de chiffre d'affaires annuel, une autorisation écrite préalable est nécessaire. La licence de MiniMax H3 exclut de son territoire l'UE, le Royaume-Uni, la Corée du Sud et les États-Unis : vérifiez aussi le pays d'utilisation.

Où sont stockées les données saisies dans MiniMax ?

La politique des applications internationales indique qu'en principe, les données ne sont pas transférées hors de Singapour. L'API relève d'une politique distincte : lisez-en le texte avant de vous engager.

SIMY fonctionne-t-il avec MiniMax ?

Non. À ce jour, SIMY ne se connecte pas à MiniMax : il fonctionne avec votre compte ChatGPT (Codex) et avec Claude Code sur votre ordinateur. Les scripts et contenus créés avec MiniMax peuvent être apportés tels quels en réunion ou dans un chat.

Non. SIMY capte de lui-même, dans vos comptes rendus et vos chats, ce qui a été décidé, avec responsables et échéances. Il apprend votre façon de faire dans vos conversations et ne vous renvoie que ce qui demande une décision.
