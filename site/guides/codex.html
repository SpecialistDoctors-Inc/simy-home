01 / AFTER THE TASK

Codex で1日が終わったあと、こうなっていませんか

会社調査、提案資料、議事録、上司への報告。OpenAI Codex に頼めば、全部できた。それでも、夕方に起きていること。

1 翌朝 翌日も、同じ指示

会社調査→資料→議事録→報告、できた。でも明日も、同じ指示を自分が打つ。

2 頼むたび 使用量を気にしながら

残り84%。賢いモデルほど早く減るから、頼む前に一度ためらう。

3 会議の合間 終わったか、見に行く

タスクの一覧を開いて確かめる。判断待ちは、チャットの下に埋もれている。

Codex は1件を仕上げる。「次に何を頼むか」と「終わったかの確認」は、まだあなたの手元に残っています。

08 / REFERENCE

OpenAI Codex の使い方・料金と利用制限・比較・安全性（詳しく知りたい人向け）

ここから下は、Codex 本体のことを確かめたいときに開いてください。SIMY との接続には、どれも影響しません。

OpenAI Codex とは：ChatGPT との違い、旧 Codex・塊根植物との区別読み方は「コーデックス」。ChatGPT のプランに含まれるエージェント

Codex とは何か

OpenAI Codex は、OpenAI が提供する AI エージェントです。ChatGPT が「聞けば答える」のに対し、Codex は「頼めば作業する」。あなたの PC やクラウド上の作業環境でファイルを読み、コマンドを実行し、ブラウザを操作し、成果物を作ります。もとはソフトウェア開発のために生まれましたが、2026年にはデスクトップアプリとプラグインの追加で、資料作成やメールの下書きなど、コードを書かない仕事にも広がりました。

ChatGPT との違い

ChatGPT は会話の中で答えを返します。Codex は、答えではなく「できたもの」を返します。たとえば「A社を調べて提案資料を作って」と頼むと、ChatGPT は文章で構成案を返し、Codex は Slides のファイルを作って終わります。どちらも同じ ChatGPT アカウントで使え、利用枠は共有です。

名前の混同に注意

  • 旧 Codex（2021年）：GitHub Copilot の初期モデルとして使われた、コード補完のための言語モデルです。2023年に提供を終え、現在の OpenAI Codex とは別の製品です。
  • 塊根植物の「コーデックス」：パキポディウムなど、根や幹が太る多肉植物の総称（caudex）です。「コーデックス 初心者」で検索すると園芸情報が混ざるので、AI の方は「OpenAI Codex」「ChatGPT の Codex」と探すと確実です。
  • GPT-5-Codex などのモデル名：Codex の中で選べるモデルの名前です。製品としての Codex と、モデルとしての GPT-5-Codex は別の階層です。

ChatGPT Work との違い

ChatGPT のデスクトップアプリには、Chat・Work・Codex の3つのモードがあります。Work は調査や資料など仕事全般の成果物を仕上げるエージェント、Codex はファイルやコマンドを扱う作業に強いエージェントで、同じ利用枠を共有します。コードを書かない人がどちらを使うか迷ったら、ファイルの読み書きや Chrome 操作が要るなら Codex、会話の延長で成果物がほしいなら Work が目安です。

日本語で使えるか

使えます。アプリの表示は英語が中心ですが、指示も成果物も日本語で問題ありません。AGENTS.md や skills も日本語で書けます。

導入手順：ログイン・AGENTS.md・承認モードデスクトップアプリなら、ダウンロードとログインの2手で始まる

デスクトップアプリで始める（コードを書かない人向け）

  1. ダウンロードしてインストールする。OpenAI の Codex ページから Windows 版または Mac 版を入れます。
  2. ChatGPT アカウントでログインする。Plus 以上のプランなら、API キーは不要です。ブラウザが開き、許可すれば完了です。
  3. 作業フォルダを選ぶ。Codex が読み書きしてよいフォルダを指定します。Drive のフォルダや、資料をまとめたフォルダで十分です。
  4. 承認モードを決める。最初は「変更の前に確認する」設定で、慣れたら「自動」に広げます。
  5. 日本語で1件頼む。「このフォルダの事例を使って、A社向けの提案資料を作って」のように、人に頼む言い方で構いません。

CLI で始める（エンジニア向け）

Node.js を入れたうえで、ターミナルから npm install -g @openai/codex を実行し、codex と打ってログインします。Windows はネイティブ対応が進んでいますが、WSL 上で動かす方が安定します。

AGENTS.md：やり方を書いておくファイル

作業フォルダに AGENTS.md というテキストファイルを置くと、Codex はそこに書かれた決まり（命名、構成、禁止事項）を毎回読んで作業します。「提案資料は12枚、最後は次のステップで締める」のような業務の型も書けます。SIMY を使う場合は、この型を会話から学ぶため、書かなくても始められます。

最初の1件で、うまくいく頼み方

  • 材料の場所を伝える。「Drive の『事例』フォルダを使って」のように、読んでよい場所を最初に書くと、探し回る時間と使用量が減ります。
  • できあがりの形を1つ示す。前回の資料や、見本のメールを1つ添えると、構成と言葉遣いがそろいます。
  • 途中で止めてよい場所を決める。「送信はしない」「下書きまで」と書いておけば、承認の回数が減り、安心して任せられます。
  • 結果はファイルで受け取る。チャットの長文ではなく、Slides や Docs のファイルにしてもらうと、そのまま共有できます。

承認モードとサンドボックス

Codex は、ファイルの変更や外部への操作の前に承認を求める「確認モード」、作業フォルダ内なら進めてよい「自動モード」、すべて任せる「フルアクセス」を切り替えられます。どのモードでも、作業はサンドボックスの中で行われ、指定したフォルダの外やネットワークへの操作は制限されます。

できること：skills・MCP・Chrome 操作・プラグイン・スケジュールGmail 下書き、Drive、Sheets、Slides、Notion、Calendar、Slack

プラグインでつながる業務アプリ（2026年10月時点）

  • Gmail：メールを読み、返信や新規メールを下書きに保存します。送信はあなたが押します。
  • Google Drive・Sheets・Slides：フォルダ内のファイルを読み、表を更新し、スライドを作ります。
  • Notion：ページやデータベースを読み書きします。議事録の保存先や顧客メモに向いています。
  • Google Calendar：予定を読み、候補日を出し、招待を用意します。
  • Slack：チャンネルを読み、投稿の下書きを作ります。
  • Chrome 操作：Chrome を開いてサイトを調べ、フォームに入力し、画面を読みます。ログインが必要な業務システムの確認にも使えます。

skills・MCP・サブエージェント

skills は、手順と判断基準をまとめた再利用できる指示のセットです。「週報の作り方」「議事録の型」を skill にしておくと、毎回の説明を省けます。MCP（Model Context Protocol）は、外部のツールやデータを Codex につなぐ共通の規格で、プラグインにないサービス（Figma、社内 DB など）はここから足します。長いタスクはサブエージェントに分けて並行して進められます。

スケジュール・プランモード・レビュー

スケジュールは「毎週金曜に、その週のメール・Slack・営業記録を突き合わせて、上司への週報を Slack 用に下書きする」のように、時刻を起点にタスクを繰り返す機能です。プランモードは、実行の前に手順と影響範囲だけを出させて確認するモードです。コードレビューは GitHub の PR を Codex に点検させる機能で、開発チーム向けです。

コードを書かない仕事での使い方（例）

  • 会社調査：Chrome で相手企業のサイトとニュースを読み、要点と論点を Docs にまとめる。
  • 提案資料：Drive の事例と価格表を使い、Slides に12枚。前回の資料を見本に構成をそろえる。
  • 議事録と報告：文字起こしを渡し、決定事項・担当・期限の型で議事録を作り、上司向けの要約を Slack の下書きに。
  • 日程調整：Calendar の空きから候補を3つ出し、招待メールを Gmail の下書きに保存する。
  • 表の更新：Sheets の進捗表を読み、会議で決まった変更を反映し、差分を一覧にする。

併用のすすめ

Codex と Claude Code は、動くプランが違います。片方のモデルが不調なとき、枠を使い切ったときに仕事が止まらないよう、両方に慣れておく人が増えています。CLI 同士なら、同じフォルダで交互に使えます。

SIMY の立ち位置：SIMY は Codex と Claude Code の両方を実行役にできます。クラウドではお使いの ChatGPT アカウントで Codex を動かし、PC 上では SIMY デスクトップアプリが Claude Code も使えます。どちらで動いても、あなたに戻るのは判断だけです。ChatGPT 本体の使い分けはChatGPT 活用ガイドにまとめています。

セキュリティと注意点：学習させない設定、サンドボックス、承認業務で使う前に押さえる3点
  • 学習させない設定：ChatGPT の設定 →「データコントロール」→「すべての人のためにモデルを改善する」をオフにすると、Codex の会話も学習に使われません。既定はオンです。Business と Enterprise は、契約上、業務データが既定で学習に使われません。
  • サンドボックス：Codex の作業は、指定したフォルダとネットワークの範囲を制限した環境で行われます。フォルダの外のファイルや、許可していないサイトには触れません。
  • 承認：削除、送信、投稿など元に戻せない操作の前に、Codex は承認を求めます。自動承認（いわゆる YOLO）は、使い捨ての環境以外では避けてください。
  • Chrome 操作：業務システムにログインした状態で使うなら、専用の Chrome プロファイルを作り、権限の少ないアカウントで操作させると安全です。
  • 情報の持ち出し：個人情報や機密を含むフォルダは、作業フォルダに指定しないのが基本です。社内ルールで ChatGPT の利用範囲が決まっている場合は、Business 以上での利用を検討してください。
  • SIMY との接続：SIMY は ChatGPT の認証画面であなたのアカウントにログインし、許可して接続します。会話履歴から提案を作るとき、本文はサーバーに保存しません。詳しくはセキュリティとプライバシーポリシーで公開しています。
09 / FAQ

よくある質問

OpenAI Codex は無料で使えますか？

ChatGPT の無料プランでは Codex は使えません。Plus、Pro、Business、Enterprise、Edu の各プランに含まれていて、追加の申し込みは不要です。API キーを使って従量課金で動かす方法もあります（2026年10月時点）。

ChatGPT Plus で、Codex はどれくらい使えますか？

5時間ごとの枠と週ごとの枠があり、残量はアプリの使用量メーターで確認できます。賢いモデルや長いタスクほど消費が早く、Pro は Plus より枠が大きくなります。具体的な上限は変わるため、公式の料金ページで確認してください。

Codex の使用量はいつリセットされますか？

5時間ごとの枠は最初の利用から5時間で、週ごとの枠は最初の利用から7日で回復します。アプリの使用量メーターに次のリセット時刻が表示されます。

Claude Code と Codex は、どちらを選べばいいですか？

どちらか一方に決める必要はありません。Codex は ChatGPT のプラン、Claude Code は Claude のプランで動くので、片方が不調なときや枠を使い切ったときの備えとして、両方に慣れておく人が増えています。SIMY は Codex と Claude Code の両方を実行役にできます。

Codex のプランモードとは何ですか？

ファイルを変えずに、手順と影響範囲だけを先に出させるモードです。大きな作業の前に計画を確認し、合意してから実行に移せます。承認モードと組み合わせると、何をどこまで任せるかを細かく決められます。

エンジニアでなくても Codex は使えますか？

使えます。OpenAI は、Codex ユーザーの2割超がエンジニア以外だと説明しています（2026年時点）。デスクトップアプリに日本語で頼めば、会社調査、提案資料、議事録、Gmail の下書きまで進み、コードを見る場面はほぼありません。

Codex のスケジュール機能と SIMY は何が違いますか？

Codex のスケジュールは時刻を起点に、決めたタスクを繰り返します。SIMY は会議やチャットを起点に、そこで生まれた仕事を見つけて Codex に進めさせます。毎朝9時の定型は Codex のスケジュールで、会議のたびに変わる仕事は SIMY で、と使い分けられます。

Codex に Chrome を操作させるのは安全ですか？

Codex はサンドボックスの中で動き、ログインやフォーム送信など外に影響する操作の前に承認を求めます。業務で使うなら、承認モードを自動にしない、専用の Chrome プロファイルを使う、学習させない設定を確認する、の3点を押さえてください。

Codex に入力した内容は AI の学習に使われますか？

ChatGPT の設定の「データコントロール」で「すべての人のためにモデルを改善する」をオフにすると、Codex の会話も学習に使われません。Business と Enterprise は、既定で業務データが学習に使われない契約です。

SIMY を使うと、Codex の利用料は別にかかりますか？

SIMYはお使いのChatGPTアカウントをつなぎ、Codex App Server経由で仕事を進めます。Codexの利用は、お使いのChatGPTプランの範囲で行われます。SIMY自体の料金は料金ページをご覧ください。

スマホから Codex を使えますか？

ChatGPT の iOS・Android アプリから Codex Cloud のタスクを確認し、新しいタスクを頼めます。SIMY の iOS アプリを使うと、Codex が進めた仕事の判断待ちだけがスマホに届き、承認して返せます。
