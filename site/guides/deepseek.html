DeepSeekとは：使い方・モデル・API・日本語・安全性（詳しく知りたい人向け）

ここから下は、DeepSeek本体のことを確かめたいときに開いてください。モデル名と仕様は2026年10月時点の情報です。

DeepSeekとは：どこの国のAIか、誰が作ったかディープシーク。中国・杭州の会社が開発するLLM

DeepSeek（ディープシーク）とは

DeepSeekは、中国の杭州に本社を置くDeepSeek（正式名：Hangzhou DeepSeek Artificial Intelligence Co., Ltd.）が開発する大規模言語モデル（LLM）と、そのチャットサービスの名前です。読み方は「ディープシーク」。無料のチャット（Webとスマホアプリ）、安いAPI、重みが公開されたオープンウェイトの3つの形で使えます。

どこの国のAIか

中国のAIです。プライバシーポリシーでは、運営会社は杭州の法人で、利用者から集めた情報は中華人民共和国内のサーバーに保存すると案内されています。日本のApp Storeでもアプリが配信されています。

設立したのは誰か

DeepSeekは2023年、梁文鋒（リャン・ウェンフォン）氏が設立しました。Forbesなどの報道によると、同氏は中国の投資会社High-Flyer（幻方）の共同創業者です。R1以降、モデルの重みを公開してきたことが特徴です。

3つの使い方

  • チャット（Web・アプリ）：chat.deepseek.comやスマホアプリで、無料で話しかけて使う。
  • API：DeepSeekのAPIを、自社のシステムや開発ツールに組み込む。使った分だけ支払います。
  • オープンウェイト：Hugging Faceで公開されたモデルを、自社のサーバーやPCで動かす。データを外に出さずに使えます。
DeepSeekショックとは：何が起きたのか2025年1月。安く作られた高性能モデルが世界を驚かせた

「DeepSeekショック」は、2025年1月にDeepSeekが推論モデル「DeepSeek-R1」を公開したあとの騒ぎを指す言葉です。米国の最上位モデルに近い性能が無料のアプリで使え、しかも少ない費用と計算資源で作られたと伝えられたことで、日米のApp Storeで上位に入りました。

  • 市場への影響：「高性能なAIには巨額の半導体投資が必要」という前提が揺らぎ、NVIDIAなど半導体関連の株価が大きく下落しました。
  • 技術への影響：重みがMITライセンスで公開されたため、各社のサービスや研究に取り込まれ、推論モデルが一気に身近になりました。
  • 規制への影響：同時に、データの保存先や政治的な話題への回答の傾向が議論になり、各国の当局が注意喚起や制限に動きました（下の「安全性」を参照）。

APIが安くオープンウェイトでもあるため、他社のサービスに組み込まれ、利用者が意識しないまま間接的に使っている場合もあります。業務で使うツールが、どのモデルをどこで動かしているかを確かめておくと安心です。

DeepSeekの使い方：Webとスマホアプリ無料。ログインして、話しかけるだけ
  1. chat.deepseek.comを開く。ブラウザから使えます。スマホならiOSとAndroidの「DeepSeek」アプリがあります。
  2. ログインする。アカウントを作ると、会話の履歴が残ります。
  3. 話しかける。日本語で質問できます。ファイルや画像を添えて「要約して」「表にして」と頼めます。
  4. モードを選ぶ。入力欄の近くに、深く考えるモードやWeb検索の切り替えが表示される場合があります（表記は時期によって変わります）。
  5. 学習の設定を確認する。設定の「Improve the model for everyone」（執筆時点の表記）をオフにすると、入力内容をモデルの訓練に使わないよう求められます。

2026年10月時点で、DeepSeekのチャットに個人向けの有料プランは確認できませんでした。

仕事で使うときのコツ

  • 入れる情報を先に決める：公開情報や一般的な質問から始め、社外秘は入れない、と決めてから使うと迷いません（下の判断表を参照）。
  • 役割と出力の形を先に伝える：「経営会議向けに、3行で、根拠つきで」のように、誰に向けた何かを最初に書くと手直しが減ります。
  • 答えは確かめる：数字、固有名詞、法令や仕様の記述は、元の資料と照らし合わせてから使ってください。

こうして出した答えを「誰が・いつまでに・何をするか」に変えて追いかけるのは、DeepSeekの外の仕事です。そこを毎回自分でやっているなら、SIMYのつなぎ方を見てください。

APIのモデル名：以前のdeepseek-chatとdeepseek-reasonerは廃止が告知され、新しいモデル名への切り替えが案内されています。既存のコードを使っている場合は、公式の更新履歴を確認してください。

DeepSeekのAPI：OpenAI互換・Anthropic互換料金は時間帯で変わる。金額は公式ページで
  • OpenAI互換：接続先をhttps://api.deepseek.comにすると、OpenAIのSDKや既存のツールから呼び出せます。Responses APIやCodexへの対応も公式の更新履歴に記載があります。
  • Anthropic互換：https://api.deepseek.com/anthropicを使うと、Anthropic形式のツール（Claude Codeなど）の接続先をDeepSeekに差し替えられます。
  • 料金の形：100万トークンあたりの米ドル建て従量課金です。直前と同じ前置きを再利用できた入力（キャッシュヒット）はとても安く、出力は入力より高くなります。
  • 時間帯で倍になる：平日のピーク時間帯（UTC 1〜4時・6〜10時、日本時間では10〜13時・15〜19時。中国の祝日を除く）は、オフピークの2倍の単価です。日本の業務時間と重なるので、大量処理は時間をずらすと費用を抑えられます。

具体的な単価は改定が多いため、DeepSeek公式の料金ページで確認してください。

APIを使い始める手順

  1. DeepSeekのAPIプラットフォームでアカウントを作り、残高をチャージする。
  2. APIキーを発行する。キーは環境変数に入れ、コードや共有ドキュメントに直接書かないでください。
  3. 接続先とモデル名を差し替える。OpenAI形式なら接続先のURLとdeepseek-flashなどのモデル名を指定します。
  4. 送るデータを決めてから広げる。APIに送った内容も、プライバシーポリシーの範囲で扱われます。社内規程と照らしてから本番の量に広げてください。

SIMYとの関係：現時点では、SIMYはDeepSeekのAPIキーを接続しません。SIMYのクラウド実行は、お使いのChatGPT（Codex）アカウントで動きます。

DeepSeekをローカルで動かす：Ollama・vLLMR1の小型版はPCで動く。V4.1-FlashはOllamaではcloud
  • PCで動くもの：Ollamaのdeepseek-r1は1.5Bから671Bまでの大きさがあり、7B版は約4.7GBです。ollama run deepseek-r1:7bのように大きさを指定して動かします。
  • Ollamaでもcloudのもの：deepseek-v4.1-flashとdeepseek-v4-proは、Ollamaの公式ライブラリではcloudタグのみです。Ollamaのクラウドで動くため、手元のPCで完結するわけではありません。
  • 最新版を自社で動かすなら：V4.1-Flashの重みはHugging Faceで公開されており、vLLMやSGLangで動かせます。ただし大規模なGPUサーバーが前提です。

「データを外に出さない」ことが目的なら、手元のPCや自社のサーバーで重みを動かす方式だけが当てはまります。cloudタグのモデルは、名前がOllamaにあってもこの目的には使えません。仕組みは中国のAI（LLM）比較の「Ollamaにあっても手元で動くとは限らない」で説明しています。

メモリの目安や量子化の選び方は、ローカルLLMの動かし方（Qwen編）も参考になります。

DeepSeekの日本語：どこまで使えるか日本語で質問・要約・下書きができる

DeepSeekのモデルカードには対応言語の一覧がありませんが、実際には日本語で質問し、日本語で答えを受け取れます。アプリは日本のApp Storeでも配信されています。

  • 得意なこと：日本語での質問への回答、長い資料の要約、メールや報告の下書き、コードの説明。
  • 気をつけたいこと：日本の固有名詞、敬語の細かい使い分け、日本の法令や商習慣の記述は、確かめてから使ってください。
  • 小さなモデルの場合：ローカルで動かすR1の小型版は、日本語の文章が不自然になったり、考える過程が英語や中国語で出たりすることがあります。

日本語の品質は、実際の業務文書で小さく試して確かめるのが確実です。

DeepSeekの安全性：日本と各国の注意喚起禁止ではなく、リスクを踏まえた判断が求められている

データの保存先と学習

DeepSeekのプライバシーポリシー（2026年2月10日更新）では、集めた情報は中華人民共和国内のサーバーに保存されると案内されています。入力をモデルの訓練に使うことを拒否する権利も明記されており、アプリの設定でオフにできます。オフにしても、保存先は変わりません。

日本の当局の注意喚起

  • 個人情報保護委員会（2025年2月3日、3月5日更新）：「DeepSeekに関する情報提供」を公表しました。DeepSeekが取得した個人情報を含むデータは中国のサーバーに保存され、中国の法令（個人情報保護法、データセキュリティ法、国家情報法など）が適用される、という留意点を示しています。
  • デジタル庁（2025年2月6日）：デジタル社会推進会議幹事会が、政府機関向けに「DeepSeek等の生成AIの業務利用に関する注意喚起」を出しました。報道によると、DeepSeekを例に同じリスクを示し、機密情報は扱わないことを原則に、利用する場合はリスクを評価して判断するよう求める内容です。利用を一律に禁止する措置ではありません。

2026年10月時点で、日本の個人がDeepSeekを使うことを禁じる法律や命令はありません。勤務先や取引先が独自の利用ルールを定めている場合は、そちらに従います。

各国の対応（報道）

  • イタリア：2025年1月、個人データ保護当局がアプリを利用できなくする措置をとりました。
  • オーストラリア：2025年2月、政府の端末での利用を禁止しました。
  • 韓国：2025年2月、個人情報保護委員会の措置で、アプリの新規ダウンロードが停止されました。
  • ドイツ：2025年6月、データ保護当局がAppleとGoogleに、ストアからアプリを削除するよう求めました。

多くは政府の端末や個人データの扱いに関する措置で、理由は国ごとに違います。政治的な話題で回答の傾向が偏るという指摘もあるため、そうした話題の調べものには複数の情報源を使うのが無難です。

各国の対応は報道に基づく要約です。最新の状況は各国当局の発表を確認してください。SIMYでのデータの取り扱いは、セキュリティとプライバシーポリシーで公開しています。

02 / AFTER THE ANSWER

DeepSeekの答えのあと、こうなっていませんか

調べものも下書きも、DeepSeekで安く一瞬で出た。それでも、そのあとに起きていること。

1 調べ終えた翌日 で、誰がやる？

比較表はきれいにできた。でも会議で決まった宿題は、誰のメモにも残っていない。

2 APIで回した週 結果が散らばる

安いAPIで案は大量に出た。採用した案と次の作業は、ログとチャットに埋もれた。

3 社内に広げたい月 確認待ちで止まる

使ってよい範囲を情報システム部門に確かめるはずが、依頼したかどうかも曖昧に。

答えを出すのは、DeepSeekで一瞬で終わる。仕事が進むかどうかは、答えのあとで決まっています。

03 / WHAT YOU REALLY WANTED

本当は、こうしたかった：DeepSeekの答えのあと

同じ会議。同じDeepSeek。答えが出た瞬間に、こうなっていてほしかった。

✓ 会議が終わったら 担当と期限が一覧に

調査と下書きはDeepSeekのまま。決まったことと担当・期限は、もう並んでいる。

✓ 期限の前に 止まった仕事が届く

確認待ち・期限間近の仕事を、次の会議の前にSIMYが先に知らせてくれる。

✓ どのAIで出しても 結論は一か所に

採用した結論と次の行動が、モデルやチャットをまたいで1つに残っている。

! あなたに戻るのは 判断だけ

「この案で進めるか」。戻ってくるのはその一問だけ。

これは、SIMYに会議とチャットをつないだ次の会議から起きることです。DeepSeekは、得意な仕事にそのまま使えます。

09 / FAQ

よくある質問

DeepSeekとは何ですか？

DeepSeek（ディープシーク）は、中国・杭州のDeepSeekが開発する大規模言語モデル（LLM）と、そのチャットサービスです。無料のチャット、安いAPI、重みが公開されたオープンウェイトの3つの形で使えます。

DeepSeekはどこの国のAIですか？

中国のAIです。運営会社は杭州の法人で、プライバシーポリシーでは集めた情報を中華人民共和国内のサーバーに保存すると案内されています。

DeepSeekを設立したのは誰ですか？

梁文鋒（リャン・ウェンフォン）氏が2023年に設立しました。報道によると、同氏は中国の投資会社High-Flyer（幻方）の共同創業者です。

DeepSeekショックとは何ですか？

2025年1月に推論モデルDeepSeek-R1が公開され、安く作られた高性能モデルとして世界で話題になった出来事です。半導体関連の株価が大きく下落し、各国の当局がデータの扱いに注意喚起する動きにもつながりました。

DeepSeekは無料で使えますか？

はい。Webのチャットとスマホアプリは無料で使えます。APIは使った分だけの従量課金です。オープンウェイトのモデルを自分の環境で動かす場合、モデルの利用料はかかりません（機材や電気代は別）。

DeepSeekは日本語で使えますか？

使えます。公式に対応言語の一覧はありませんが、日本語で質問し、日本語で答えを受け取れます。大事な文面は、固有名詞や敬語を確かめてから使ってください。

DeepSeekのAPIの料金はいくらですか？

使った分だけ払う従量課金で、100万トークンあたりの米ドル建てです。平日のピーク時間帯はオフピークの2倍の単価になります。単価は改定が多いため、DeepSeek公式の料金ページで確認してください。

DeepSeekのAPIはどう使いますか？

DeepSeekのAPIは、APIキーを発行し、使い慣れたツールの接続先とモデル名を差し替えて使います。OpenAI互換の接続先はhttps://api.deepseek.com、Anthropic互換はhttps://api.deepseek.com/anthropicで、モデル名はdeepseek-flashなどです（2026年10月時点）。

DeepSeekはローカル（自分のPC）で動かせますか？

R1の小型版などはOllamaで動かせます。最新のV4.1-FlashはOllamaではcloudタグのみで手元では動かず、自社で動かすには大規模なGPUサーバーが必要です。

DeepSeekは日本で禁止されていますか？

いいえ。2026年10月時点で、個人の利用を禁じる法律や命令はありません。2025年2月に個人情報保護委員会が情報提供を、デジタル庁（デジタル社会推進会議幹事会）が政府機関向けの注意喚起を出し、データが中国のサーバーに保存され中国の法令が適用されることを示しています。

DeepSeekに入力した内容は学習に使われますか？

使われる場合があります。プライバシーポリシーには訓練への利用を拒否する権利が明記されており、アプリの設定（執筆時点の表記は「Improve the model for everyone」）でオフにできます。オフにしてもデータは中国のサーバーに保存されるため、機密情報は入れないのが基本です。

SIMYはDeepSeekで動きますか？

いいえ。現時点では、SIMYはお使いのChatGPT（Codex）アカウントと、PC上のClaude Codeで動きます。DeepSeekで作った答えや下書きは、そのまま会議やチャットに持ち込めます。

DeepSeekで出した答えのあとの仕事は、毎回SIMYに頼む必要がありますか？

いいえ。SIMYは会議の記録やチャットから、決まったことと担当・期限を自分で拾います。あなたのやり方を会話から学び、判断が必要なところだけをあなたに返します。
