01 / SETUP

ChatGPT を仕事で使う前に整える5つの設定

無料版でも Plus でも、最初に5つだけ整えておくと、回答の質と、そのあとの仕事の進み方が変わります。社内の情報を扱うなら、1と2は最初の日に済ませておきましょう。

  1. 1

    「学習させない」設定を確認する

    Free、Go、Plus、Pro の個人プランでは、設定のデータコントロールから、会話をモデルの改善に使わせない設定にできます。Business と Enterprise の業務データは、既定では学習に使われません。顧客名や金額を入力する前に、ここを確認します。

  2. 2

    カスタム指示に、あなたの基準を書く

    職種、業界、よく作る文書、避けたい言い回しを設定しておくと、毎回のプロンプトが短くなります。「メールは敬体で、結論から」「金額は税込で併記」のような、あなたが良い仕事で守っている基準を書きます。

  3. 3

    プロジェクトで、案件ごとに分ける

    顧客や案件ごとにプロジェクトを作り、資料と会話をまとめておくと、Chat も Work も同じ前提で動けます。Plus 以上では、より大きなプロジェクトで作業を整理できます。

  4. 4

    メモリの範囲を決める

    メモリを有効にすると、過去の会話を踏まえて答えてくれます。便利な反面、顧客名や金額まで覚えさせたくない場合もあります。プロジェクト単位のメモリに絞るか、オフにするかを最初に決めておきます。

  5. 5

    回答の置き場所と、次の仕事の起点を決める

    回答をコピーして終わりにせず、Notion、Google ドライブ、Slack のどこに置くかを決めます。会話と記録の置き場所が決まっていることが、SIMY と仕事をつなぐ入口になります。連携方法を見る

03 / HOW TO USE WORK

ChatGPT Work の使い方：指示の書き方と Scheduled Tasks

ChatGPT Work は、2026年7月9日に公開された、長く込み入った作業のためのエージェントです。連携したアプリとファイルを横断して調査・分析し、資料、スプレッドシート、プレゼン、レポート、Sites を仕上げます。進捗を見ながら質問に答え、方向を変え、重要な操作を承認できます。

  1. 1

    モードを Work に切り替える

    デスクトップアプリでは左上のメニューから、Web とモバイルではドロップダウンから Work を選びます。デスクトップアプリは macOS と Windows で使えます。

  2. 2

    実行場所を選ぶ

    PC の中のファイルやアプリを使わせたいときは、デスクトップの「Work locally」をオンにします。PC を閉じても続けたい、Web やモバイルで続きを見たいときは、クラウドで実行します。

  3. 3

    プラグインをつなぐ

    Slack、Google Drive、メール、カレンダーなどはプラグインで接続します。以前の App Directory は Plugin Directory に置き換わり、スキル、アプリ、テンプレートをまとめて入れられます。

  4. 4

    指示に「止める条件」まで書く

    「何を」「どの情報源で」「誰向けに」「どこで止めるか」の4つを書きます。「見積もりの金額を入れる前に止めて、確認を求める」のように、承認してほしい地点を先に決めておくと、やり直しが減ります。

  5. 5

    計画を確認して、承認する

    Work は作業計画を示してから動きます。途中で質問が来たら答え、重要な操作は承認します。成果物は Work のタスク一覧から開けます。

Scheduled Tasks と、アプリのイベントで起動する自動化

Work は、1回限りの実行、毎週月曜9時のような繰り返し、変更の監視を予約できます。2026年8月以降は、対応するプラグインの MCP イベントで自動化を始められるようになりました。たとえば、監視を頼んだ Slack チャンネルに新しい情報が来たら要約を用意する、といった使い方です。接続したアカウントが、そのイベントと情報にアクセスできることが条件です。

利用枠：Work と Codex は同じ利用枠を使います。5時間ごとの上限があり、モデルとタスクの規模で変わります。Pro は Plus の5倍、Business のプレミアムシートには5時間ごとの上限がありません。Work 自体に追加料金はありません。

04 / AFTER WORK

Work が仕上げたあとに、まだ残っている仕事

Work は、頼んだ1件を最後まで仕上げてくれます。けれど仕事は1件では終わりません。会議のたびに、Slack のスレッドのたびに、「今回は何を頼むか」を決め、前提を集め、仕上がりを自分の基準で直し、次の人に渡す作業が発生します。

ChatGPT終わらせてくれること

  • 質問への回答と説明
  • 頼んだ資料・レポート・スプレッドシートの作成
  • 予約したスケジュールや、アプリのイベントでの実行
  • コードの作成と修正

あなたまだ手元に残ること

  • 今回は何を、どの情報で頼むかを決める
  • 会議や Slack の文脈を集めて、渡す
  • 仕上がりを自分の基準で確認し、直す
  • メール、メモ、共有、次回準備の順番をつなぐ
  • どこまで自動で進めてよいかを、毎回判断する
  • 「終わった」と言われた仕事が、本当に終わったかを確かめる

問題は、AI が働かないことではない。仕事を前に進める役が、まだあなたのままなことだ。

SIMY は、この部分のために作られています。会話から仕事を拾い、あなたの仕事の基準を学んで合うワークフローを選び、進み具合を確かめながら、判断が要るところだけをあなたに戻します。

05 / CONNECT

ChatGPT アカウントと SIMY の連携方法

SIMY は ChatGPT の代わりではありません。お使いの ChatGPT アカウントをつなぎ、Codex App Server 経由で Codex を実行役として動かす、仕事の管理層です。利用は、お使いの ChatGPT プランの枠の中で行われます。

A

ChatGPT アカウントをつなぐ

最初にやること

すでに使っている ChatGPT アカウントを、そのまま SIMY のエンジンにします。新しい API キーも、別のサブスクリプションも要りません。

  1. SIMY にサインアップし、ChatGPT アカウントを接続します。Codex が使える Plus 以上のプランが対象です。
  2. SIMY が Codex App Server を通じて、あなたの代わりに Codex のセッションを開始し、続けます。
  3. 使用量は、お使いの ChatGPT プランの範囲で数えられます。

向いている人：ChatGPT Plus、Pro、Business をすでに仕事で使っている人

B

会話と記録の置き場所をつなぐ

Slack、Teams、Notion、Google ドライブ、カレンダーなど、会話と記録がある場所をつなぎます。SIMY はそこから仕事を拾い、成果を元の場所に返します。

  1. SIMY で連携するアプリを選びます。
  2. 見てほしいチャンネル、ページ、フォルダを指定します。
  3. 会議1件から試します。SIMY が仕事を認識し、合うワークフローを選び、Autorun が進めます。

向いている人：会議や商談が多い人、チームで記録を共有している人

C

Codex や Claude Code の会話を、SIMY に監督させる

エンジニア向け

SIMY CLI を入れると、進行中の Codex や Claude Code の会話を、元の目的に向けて上限つきで続けさせられます（Delivery Loop）。毎ターンのチェックポイント、承認待ち、完了の検証までを SIMY が受け持ちます。

  1. npm install -g @awak-app/simy-cli でインストールし、simy --daemon でバックグラウンドの agent を起動します。
  2. Codex の Plugins で SIMY を有効にし、/hooks でフックを確認して有効にします。SIMY がフックを勝手に有効にすることはありません。
  3. 会話の中で、目的と次の一手を決めて Delivery Loop を始めます。進み方は simy delivery status で確認できます。

向いている人：Codex や Claude Code をふだんから使っているエンジニア、PR の品質検査（SQM）まで任せたいチーム

07 / COMPARE

どれが上という話ではなく、役割が違います。Work と Codex は「頼まれた1件を仕上げる実行役」、SIMY は「仕事を拾い、実行役を動かし、終わったかを確かめる管理役」です。SIMY は Codex を実行役として使うので、置き換えではなく、重ねて使うものです。

選び方：1件を今すぐ仕上げたいなら Work で十分です。同じ種類の会議や依頼が毎週あり、そのあとの仕事が毎回同じで、「本当に終わったか」の確認まで任せたいなら、SIMY の出番です。

SIMY の「進め方の管理」が実際にやっていること

SIMY の中核は、AI に賢く答えさせることではなく、仕事の工程を管理することです。SIMY CLI の Delivery Loop を例にすると、次のように動きます。

  • 目的を固定する：始めるときに「目的」と「次の一手」を決め、途中で勝手に目的が変わったら止まります。
  • 毎ターン、チェックポイントを取る：実行役は毎ターンの終わりに、進行中・完了・ブロック・エラーのどれかと、根拠を報告します。報告がなければ失敗として数えます。
  • ブロックを型で分ける：「承認が要る」「情報が足りない（具体的な質問つき）」「外部の返事待ち（条件と担当と次の確認時刻つき）」のどれかに分けて、人に戻します。
  • 外に出る操作は必ず承認：外部への送信、破壊的な変更、範囲の変更は、自動化の設定にかかわらず承認を待ちます。却下された操作は、自動では再実行しません。
  • 「終わった」を鵜呑みにしない：独立した確認がない完了は「報告ベース」として表示し、検証済みの完了と区別します。進んでいない状態が続けば自動で止まります。
  • 上限を守る：継続回数、連続失敗、時間の上限つきで動き、再開しても上限はリセットされません。
  • チャットが終わっても見ている：PR の準備が整った仕事は、チャットを閉じたあとも5分ごとに再確認し、確認できなくなった完了は取り消します。

09 / SECURITY

社内で ChatGPT を使うときのデータの扱いとガイドライン

情報漏洩の心配は、ChatGPT を使うかどうかより、どの設定で、どこまで任せるかで決まります。社内ガイドラインに入れておきたい項目を整理します。

  • 学習に使われるか：Business と Enterprise の業務データは、既定ではモデルの学習に使われません。個人プランは、設定で学習に使わせないようにできます。削除した会話は30日以内に完全に削除される予定と案内されています。
  • 情報漏洩の主な経路：会話の共有リンク、学習設定の放置、プラグインに与えた権限、ローカル実行で許可したファイルの範囲。この4つを最初に決めておきます。
  • Work の権限：Work Cloud、Work Local、Codex Local は個別に設定できます。Enterprise と Edu はプラグインが既定でオフ、Business は既定でオンです。
  • ガイドラインに入れる5項目：入力してよい情報の区分、学習設定、共有リンクの扱い、プラグインとローカル実行の許可範囲、成果物を確認する責任者。
  • SIMY 側の考え方：SIMY は、外部への送信、破壊的な変更、範囲の変更を常に人の承認待ちにします。ただし承認は「進め方の判断」であって、セキュリティの境界ではないと明記しています。SIMY のフックは、会話の記録やアカウントのトークンをアップロードしません。詳細はセキュリティとプライバシーポリシーで公開しています。
10 / FAQ

よくある質問

ChatGPT Work とは何ですか？

2026年7月9日に OpenAI が公開した、長く込み入った作業のためのエージェントです。連携したアプリとファイルを横断して調査・分析し、資料、スプレッドシート、プレゼン、レポート、Sites を仕上げます。Scheduled Tasks で1回限り・繰り返し・変更の監視といった実行もできます。

ChatGPT Work は無料で使えますか？

Web とモバイルでは Plus 以上の有料プランで使えます。Free と Go はデスクトップアプリで制限つきです。Work 自体に追加料金はなく、お使いのプランの利用枠の中で動きます。

ChatGPT Work と Codex の違いは何ですか？

Work は調査、分析、資料やレポートの作成など仕事全般の成果物を仕上げるエージェントで、Codex はソフトウェア開発のためのエージェントです。同じ実行・権限の仕組みと利用枠を共有していて、GPT-6 Sol と Luna は Work と Codex 専用のモデルです。

ChatGPT Work の利用上限はどのくらいですか？

5時間ごとの上限があり、モデルとタスクの規模で変わります。Pro は Plus の5倍、Business のプレミアムシートは5時間ごとの上限がありません。上限は Codex と共有です。

エージェントモードと ChatGPT Work は違うものですか？

Work は、ChatGPT が自分で作業を進めるエージェント機能を、成果物の作成、Scheduled Tasks、連携アプリの横断まで広げたものです。デスクトップアプリでは Chat、Work、Codex を切り替えて使います。

ChatGPT Business は1人でも使えますか？

Business は従業員2〜200名のチーム向けのプランで、管理コンソール、SAML／SSO、業務データが既定では学習に使われない設定が最初から含まれます。1人で使う場合は Plus か Pro が基本で、学習に使わせない設定は個人プランでも行えます。

ChatGPT Plus と Business の違いは何ですか？

Work と Codex はどちらでも使えます。Business は業務データが既定では学習に使われないこと、管理コンソール、SAML／SSO／MFA、Google Workspace・Slack・Microsoft 365 との連携、利用状況の分析が加わり、Work や Codex の権限をワークスペース単位で設定できます。

ChatGPT を経理や営業の業務に使うのと、専用の AI ツールを使うのはどちらがいいですか？

1件ずつ頼んで自分で確認できる範囲なら ChatGPT で十分です。毎週同じ仕事が発生し、進捗の確認や「本当に終わったか」の判断まで任せたいなら、ChatGPT を実行役にして工程を管理する SIMY のような層を足すのが現実的です。

SIMY を使うと、AI の利用料が別にかかりますか？

SIMY はお使いの ChatGPT アカウントをつなぎ、Codex App Server 経由で仕事を進めます。Codex の利用は、お使いの ChatGPT プランの範囲で行われます。SIMY 自体の料金は料金ページをご覧ください。

ChatGPT 以外の AI でも SIMY を使えますか？

SIMY CLI の Delivery Loop は Codex と Claude Code の両方の会話を監督できます。Web の Autorun は ChatGPT アカウントの接続を前提にしています。
