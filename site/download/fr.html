Ouvrir SIMY dans le navigateur
INSTALL

Installation : ouvrir, puis cliquer sur « Connexion »

Mac .dmg

  1. Ouvrez le fichier .dmg téléchargé
  2. Faites glisser SIMY dans « Applications »
  3. Ouvrez SIMY et cliquez sur « Connexion »

Windows .exe

  1. Ouvrez le fichier .exe téléchargé
  2. Si un écran bleu de protection s'affiche : « Informations complémentaires » → « Exécuter quand même »
  3. Ouvrez SIMY et cliquez sur « Connexion »

En cliquant sur « Connexion » : le navigateur s'ouvre et, si vous êtes déjà connecté à SIMY, la liaison se fait toute seule. Si le navigateur affiche « Unauthorized », connectez-vous d'abord sur le Web, puis cliquez à nouveau sur « Connexion » dans l'application.

WHAT IT DOES

Ce que l'application change sur votre ordinateur

1 À partir des conversations La suite arrive

Dans vos conversations avec Claude Code ou Codex, le travail répété devient des « Suggestions de SIMY ».

2 Depuis SIMY Piloter l'IA locale

Avec votre propre connexion, Claude Code ou Codex avancent le travail sur votre ordinateur.

! Pour vous Juste la décision

Peut-on envoyer ? Ce prix convient-il ? Seuls les points à trancher vous reviennent.

Pour être tranquille : seuls les échanges de conversation sont lus, sur les 90 derniers jours par défaut. Les sorties des outils ne sont pas envoyées, et le contenu des conversations n'est pas stocké sur nos serveurs. Vous pouvez tout arrêter à tout moment dans les réglages.

FAQ

Questions fréquentes

Peut-on essayer gratuitement ?

Il n'y a pas d'offre gratuite. En choisissant une offre mensuelle à l'inscription, vous avez accès à l'application et au Web. Les tarifs sont sur la page d'accueil, section Tarifs.

Peut-on installer l'application avant de créer un compte ?

Oui, mais il faut un compte SIMY pour se connecter. Le plus rapide : créer le compte d'abord, puis cliquer sur « Connexion » dans l'application.

Que faut-il pour s'inscrire ?

Une adresse e-mail et une carte bancaire. L'identité est confirmée par un lien envoyé par e-mail : pas besoin de choisir un mot de passe. Le paiement se fait sur l'écran de paiement par carte.

J'ai cliqué sur « Connexion » dans l'application et « Unauthorized » s'est affiché.

Vous n'êtes pas connecté à SIMY dans le navigateur. Connectez-vous d'abord sur le Web (ou créez un compte si c'est votre première fois), puis cliquez à nouveau sur « Connexion » dans l'application.

L'application est-elle utile si je n'utilise ni Claude Code ni Codex ?

Repérer le travail dans les réunions et les discussions fonctionne avec le Web seul : l'application n'est pas indispensable. Si vous utilisez Claude Code ou Codex sur votre ordinateur, l'application transforme vos conversations en propositions, et SIMY peut faire travailler l'IA de votre ordinateur.

Faut-il un abonnement ChatGPT ou Claude ?

L'exécution dans le cloud de SIMY passe par votre compte ChatGPT (Codex). Pour faire travailler Claude Code sur votre ordinateur, votre propre connexion à Claude Code est utilisée telle quelle. Les tokens Claude ne peuvent pas être reliés à l'exécution dans le cloud. La liaison des tokens Gemini est en cours de développement.

Fonctionne-t-elle sur un Mac Intel ?

La version Mac actuelle est conçue pour les puces Apple (M1 ou plus récent). Sur un Mac Intel, utilisez SIMY depuis le Web.

Le fichier téléchargé s'appelle « SIMY-CLI ».

C'est bien la même application. L'application de bureau contient aussi la SIMY CLI, utilisable dans le terminal par les développeurs, d'où ce nom de fichier. Au quotidien, l'interface de l'application suffit.
