INSTALL

How to install: open it and click Log in

Mac .dmg

  1. Open the downloaded .dmg
  2. Drag SIMY into Applications
  3. Open SIMY and click "Log in"

Windows .exe

  1. Open the downloaded .exe
  2. If a blue protection screen appears, click "More info" → "Run anyway"
  3. Open SIMY and click "Log in"

When you click "Log in": your browser opens and, if you're already logged in to SIMY, connects automatically. If the browser shows "Unauthorized," log in on the web first, then click "Log in" in the app again.

FAQ

Frequently asked questions

Can I try it for free?

There is no free plan. Choose a monthly plan and sign up to use both the app and the web. See pricing on the home page.

Can I install the app before creating an account?

You can install it, but logging in requires a SIMY account. The fastest order is to create an account first, then click "Log in" in the app.

What do I need to sign up?

An email address and a credit card. You verify yourself through the link in the email we send, so there's no password to set. Payment happens on the card checkout screen.

I clicked "Log in" in the app and saw "Unauthorized."

You're not logged in to SIMY in your browser. Log in on the web first (or create an account if you're new), then click "Log in" in the app again.

Is the app worth installing if I don't use Claude Code or Codex?

Picking up work from meetings and chats works on the web alone, so the app is optional. If you use Claude Code or Codex on your computer, installing the app turns those conversations into suggestions and lets SIMY run the AI on your computer.

Do I need a ChatGPT or Claude subscription?

SIMY's cloud runs use your own ChatGPT account (Codex). When SIMY runs Claude Code on your computer, it uses your existing Claude Code login. Claude tokens cannot be connected for cloud runs. Gemini token support is in development.

Does it work on Intel Macs?

The current Mac version is for Apple silicon (M1 or later). On an Intel Mac, please use SIMY on the web.

The downloaded file is named "SIMY-CLI."

It's the same app. The desktop app also includes SIMY CLI, which engineers can use from the terminal, so the file carries that name. Day to day, you only need the app window.
